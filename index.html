AI-built mini tools

58 small browser tools. Each one runs offline from a single folder with no network requests, stores data only in your browser, and was built by AI coding agents from a one-page spec, with unit tests and a scripted browser check. Interfaces are in Simplified Chinese.

58 个纯前端小工具：不联网、不登录、数据只存在浏览器本地。源码、规格与测试见 GitHub。
