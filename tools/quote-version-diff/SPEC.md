# SPEC · 16 报价版本差异说明

目标用户:装修、设计、软件外包工作室的销售与项目负责人。付款人:工作室主理人。

## 核心任务(必须跑通)

1. 粘贴/导入「旧版」与「新版」两份报价表(CSV/TSV;列映射:项目编码(必选)、项目名称、数量、单位、单价、备注)。
2. 对比(按项目编码匹配;重复编码阻止计算并报行号):新增项、删除项、数量变更、单位变更、单价变更、名称变更(仅提示);每项显示旧值 → 新值与金额影响(数量×单价差)。总额:旧合计、新合计、差额、变化百分比。
3. 变更说明生成:按「新增 / 删除 / 调整」三段的 Markdown 文本,每条一句话(如「地砖铺贴:数量 80 → 95 ㎡,单价不变,增加 ¥1,500」),用户可编辑;可勾选「只列影响金额的项」。
4. 确认记录:保存一条版本对比记录(时间、版本名、差额、是否已向客户确认 + 确认日期);列表展示历史版本链。
5. 导出:差异表 CSV;变更说明 Markdown;JSON 备份。

## 不做

不解析 PDF/Excel 二进制、不做合同条款、不做电子签。

## core.js 暴露

`parseTable`;`guessMapping`;`normalizeNumber`;`diffQuotes(oldRows, newRows, mapping)` → `{added, removed, changed:[{code, name, fields:[{field, from, to}], deltaAmount}], totals}`;`explain(diff, options)`;`toCsv`;`validateImport`。金额四舍五入到分。

## 示例

合成装修报价两版各 14 行,含:2 新增、1 删除、3 数量变、1 单价变、1 单位变、1 仅改名、1 重复编码(在「错误示例」里切换);标注「合成示例」。

## 测试点(≥ 12)

新增/删除/各字段变更检测;deltaAmount 计算;名称变更只提示;重复编码阻止;合计与百分比(旧合计 0 不除零);explain 文案与「只列影响金额」过滤;normalizeNumber;CSV 公式防护;确认记录排序;validateImport。

## 视觉方向

工程报价感:炭灰 + 橙强调;差异行三色(新增绿、删除红、调整琥珀,AA);手机端表格横滑。

## 已知限制(写进 README)

依赖项目编码一致;不识别图片/PDF;百分比对 0 基数不计算。
