# 字幕术语校对

## 定位

给字幕做术语与时间轴校对的本机小工具:粘贴 SRT / WebVTT 和术语表,查出术语错写、大小写/全半角变体与时间轴问题,逐条接受替换,导出修正后的字幕和问题报告。只改文字层,时间轴与序号原样保留。

## 目标用户

做视频字幕的个人创作者与小团队(含做教学视频的教师)。付款人:创作者或内容团队负责人(来自 SPEC.md)。

## 核心任务

1. 粘贴或选择 SRT / WebVTT 文件(自写解析器,解析错误定位到行号)。
2. 填术语表,每行 `标准写法 | 错误写法1, 错误写法2`(认全角竖线与逗号);只写标准写法时检查大小写与全半角变体;可选大小写敏感。
3. 点「检查字幕」:术语问题 + 时间轴问题(开始不早于结束、与下一条重叠、时长 < 0.7 秒、> 7 秒、字速、单行字数、超过 2 行、序号不连续、空文本)。
4. 对术语问题逐条「接受 / 跳过」,或一键接受全部;预览里即时显示替换效果。
5. 导出修正后的 SRT(VTT 输入导出 VTT)、问题报告 Markdown / CSV。

## 如何打开

双击 `index.html`。纯前端,无需安装、联网、登录。字幕、术语表与选项存在当前浏览器 localStorage(键 `subtitleterms.v1`);写入失败时页面顶部会持续显示「未保存」提示。「载入示例」载入合成示例;「清空数据」先在页内确认。

## 功能说明

- 阈值默认:字速 20 字/秒;单行 20(含中文)/ 42(其他)。中文按 1 字 1 字符,标签 `<i>`、`{\an8}` 不计。
- 含中文的行按 20 字限制,其余按 42。
- 检查结果依赖「检查字幕」:输入或选项改动后结果标为过期,导出被禁用,重新检查后才可导出。字幕有解析错误时,「导出修正后的字幕」禁用(否则会丢掉无法解析的字幕),报告仍可导出。
- 导出的 CSV / Markdown 对以 `=`、`+`、`-`、`@` 开头的字段加单引号前缀(单独的 `-`/`+` 除外)。
- 所有用户输入渲染前转义(app.js 的 innerHTML 模板里,用户文本都经 `esc()`,其余插值是数字、布尔或固定枚举,本轮也统一包了 `esc()`);1440 与 390 宽均无横向溢出。

## 口径
- 检查选项(字速上限、单行字数含中文、单行字数其他)必须是大于 0 的数字;空、0、负数、非数字都会在输入旁报错并停止检查,不会悄悄改用默认值。CPS(每秒字符数)= 字符数 ÷ 时长(秒),中文按 1 字 1 字符,标签不计。
- 「没有发现问题」只在字幕和术语表都没有解析错误、且问题数为 0 时出现;有解析错误时汇总显示「检查未完成:N 处解析错误」,N 为字幕与术语表解析错误之和。
- 汇总里的「问题」计数含术语问题与时间轴问题;「已接受 X / Y 处术语修正」中 Y 为术语问题总数。
- 接受/跳过的选择与检查时的输入一起存进 localStorage,刷新后恢复;只有输入与上次保存时完全一致才恢复,改过输入后需重新检查。
- 载入示例前,只要有字幕、术语表、改过的选项或接受/跳过记录,就先在页内确认。合成示例的标记刷新后仍在,改动字幕或术语表后消失;示例状态下导出的问题报告(Markdown 与 CSV)带「数据来源:合成示例」。

## 已知限制

- 不支持 ASS/SSA;不做翻译、语音识别、时间轴自动调整(只报不改)。
- 字速与行长阈值是通用建议,不是平台规范。
- 术语按字面匹配,不做分词;术语跨越 `<i>` 等标签时匹配不到。
- 没有导入备份功能;存储失败时只能靠导出字幕/报告并另存文本框内容。
- VTT 的 NOTE / STYLE / REGION 块导出时不保留。
- 文件读取按 UTF-8,上限 5 MB。
