# 课表壁纸生成器

## 定位

填一次课表，导出能直接设成手机锁屏、电脑桌面、平板壁纸的课表图片。纯本地网页，不联网、不注册。

## 目标用户

- 每天要看课表的中学生、大学生：想把课表设成锁屏，抬手就能看到下一节课。
- 想把课表放在电脑桌面上的老师：不想再一格一格手填表格。

## 核心任务

把一周课表录入一次，挑一个好看的模板，导出一张尺寸正确、文字不出格的 PNG 壁纸。

## 如何打开

直接用浏览器打开本目录的 `index.html`（双击即可，无需安装、无需服务器）。打开后就是工作台；点「载入示例」可以先看效果。

- 运行测试：`node --test tests/`（纯逻辑单测，19 个用例）
- 重新截图与冒烟：`node shots.cjs`（需本机已装 Playwright 与 headless shell，路径写在脚本顶部）
- 展示页：`showcase.html`，截图 `showcase.png`

## 功能

- **课表编辑**：默认周一到周五，可打开周六、周日；默认上午 4 节 + 下午 4 节，可增删节次、改上下课时间（24 小时制，非法时间会被拒绝并提示）。点格子输入课程名，下方小字填教室（可不填）；回车跳到同一天下一节；已填课程名会出现在自动补全里。
- **同名同色**：按阅读顺序（先节次后星期）给每门课分配调色板颜色，同一门课所有格子颜色一致，结果确定、可复现（`core.assignCourseColors`）。
- **批量粘贴**：每行一格 `周几,第几节,课程,教室`，支持中英文逗号 / Tab / 分号；星期可写「周一 / 星期一 / 一 / Mon / 1」。看不懂的行逐行列出原因，其他行照常填入；出现周末课程会自动打开周末列。
- **四套模板**：深色极简、清爽网格、撞色色块、黑板风。配色、字重、圆角、间距集中在 `core.js` 的 `TEMPLATES` 一处。
- **三种尺寸**：手机 1170×2532（上方预留锁屏时钟区，预览可叠加时钟参考层，导出不含）、电脑 2560×1440、平板 2048×2732。
- **实时预览**：右侧 canvas 按比例缩放显示，标题、副标题可改。
- **长课程名自动适配**：先缩字号，再换到第二行，仍放不下则末尾加省略号（`core.fitText`）。返回的每行都不超过给定宽度；格子窄到连单个字都放不下时只能截掉文字（标记 `truncated`），绘制时另按格子裁剪兜底。当前三种尺寸的实际格宽远大于单字宽度。
- **导出 / 导入**：PNG 用 `canvas.toBlob` 下载，文件名含尺寸和日期，如 `课表壁纸-手机-1170x2532-20260930.png`；课表可导出 / 导入 JSON（`课表数据-YYYYMMDD.json`），坏文件会提示而不会覆盖现有数据；有效文件在替换已有课表前会弹确认，取消则当前课表不变。
- **本地保存**：每次编辑同步写入 localStorage（键 `kbwp:schedule:v1`），关页前最后一次输入也会保存；写入失败会提示且不显示成功。本地数据损坏时原文另存到 `kbwp:schedule:v1.corrupt-<时间戳>` 并在顶部持续提示；另存也失败则暂停自动保存，不覆盖原数据。「清空数据」需二次确认；「载入示例」和导入在已有任何数据（含隐藏的周末课程、标题、节次设置）时会先确认。
- **合成示例**：`sample-data.js` 是一份虚构的高二周课表（40 格、12 门课），明确标注「合成示例」，不对应任何真实学校。

分层：布局（`computeLayout`）、安全区、文字适配（`fitText` / `wrapText`，测宽函数由外部注入）、节次标签（`periodLabelLayout`）、颜色分配、批量解析、JSON 校验都是 `core.js` 里的纯函数，可在 Node 中单测；`app.js` 只负责 DOM 与 canvas 绘制。

设计 token：`styles.css` 顶部 `:root` 分两层（原始色阶 / 间距 / 字号 → 语义 token），组件只引用语义 token。运行时写入的值只有测量或数据类：设备框显示尺寸、锁屏参考层位置、课程色条与模板色块颜色（来自 `core.TEMPLATES`）、编辑表天数。壁纸模板的配色属于"壁纸设计数据"，集中在 `core.TEMPLATES`，不进界面 token，这是有意的例外。隐藏文件输入框的 `1px` 属于无障碍隐藏的结构性写法。

## 已知限制

- 只支持手填和按格式粘贴，不能从教务系统、截图、Excel 自动识别课表。
- 不支持单双周、按日期变化的课表，不做上课提醒。
- 锁屏时钟区按 iPhone 常见锁屏布局估算，其他机型需用预览里的时钟参考层自行确认；平板同理。
- 壁纸文字使用本机系统中文字体（PingFang SC 等），不同系统导出的字形略有差异；未内嵌字体。
- 编辑表格在窄屏（手机）上需要左右滑动；课程名在编辑框里过长时会显示省略，壁纸成品不受影响。
- 调色板 12 色，超过 12 门课时颜色会循环复用。
- 本地数据损坏时只做原文备份与提示，界面内不提供「从备份恢复」，需要自行从浏览器开发者工具取出备份键内容另存为 JSON 再导入。
- 覆盖确认用浏览器原生 `confirm`，没有撤销；替换前请先导出 JSON。
- 无账号、分享、付费、云同步；数据只在当前浏览器，换设备请用 JSON 导出 / 导入。
- Node 24 下 `node --test tests/` 把目录当模块解析，因此 `tests/package.json` 用 `"main": "core.test.cjs"` 指向测试文件；`node --test`（不带参数）同样可用。
