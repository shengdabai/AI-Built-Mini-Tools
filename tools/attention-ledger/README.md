# 注意力账本

## 定位
把一天的时间段记成一本账,看「黄金时段」(你自己定的、一天里注意力最好的时间,默认 09:00–12:00)到底给了生产、学习,还是消费。目标用户:创作者、自学者、自由职业者。付款人:本人。

## 核心任务
1. 录入时间段:日期、开始、结束、做了什么、大类(生产/学习/消费/杂务/休息,可加自定义类别名)。结束不晚于开始报错;同日区间相交会阻止保存(首尾相接不算);跨午夜的一段勾选「跨午夜」,拆成两天存;正好结束在 24:00 的勾选「结束于午夜 24:00」。
2. 一天视图:五类配色时间轴(手机端纵向)、生产+学习占比、黄金时段内各类分钟数与占比。
3. 周与月:每天生产+学习分钟、黄金时段利用率、连续利用率 ≥ 60% 的天数、类别占比对比上一期(最近 7 天 / 30 天,以「查看日期」为最后一天)。
4. 复盘:自动取当天最长的一段 + 一句话备注;周报 Markdown(时间统计、每天、最长 7 段、备注)。
5. 导出:记录 CSV、周报 Markdown、JSON 备份;导入 JSON 走「校验 → 预览数量 → 确认 → 写入」,不合法整份拒绝。

## 如何打开
双击 `index.html`(file://,无依赖、无联网)。地址后加 `?today=2026-10-20` 可固定「今天」。点「载入合成示例」载入 14 天合成数据(只要有记录、备注、改过的黄金时段或未提交的表单草稿,就先出现页内确认并列明会被替换的内容,确认前不改动任何内容),点「填入重叠的错误示例」再保存,可看到重叠被阻止。

## 口径
- 占比的分母是所选日期或区间内「已记录的总分钟数」,没有记录的时间不计入;分母为 0 时占比显示 0%。
- 黄金时段利用率 = 黄金时段内的生产 + 学习分钟 ÷ 黄金时段总分钟(默认 09:00–12:00 共 180 分钟)。周/月的平均利用率只统计有记录的天;连续天数要求每天有记录且利用率 ≥ 60%。
- 周/月是以「查看日期」为最后一天的最近 7 / 30 天,对比紧邻的上一个等长区间。
- 保存前,表单里的合法输入会作为虚线草稿预览进时间轴和当天统计(只影响「一天的账」页);草稿或备注未保存时,周报、CSV、JSON 导出全部禁用。
- 示例数据带 `sample: true`:数据区持续显示「合成示例」提示,导出的 JSON、CSV(多一列「数据来源」)、周报都会标注;清空或导入真实备份后消失。
- 地址带 `?today=` 且是真实日期时,页面顶部显示「基准日(由地址参数固定)」。
- 安全核对(2026-10-20):`app.js` 全部用 `textContent` / `createElement` 渲染,没有 `innerHTML` 拼接,用户输入不会被当作 HTML。

## 已知限制
- 手填本身消耗注意力(这正是李笑来方法的反证);不做自动采集、后台监控、自动分类,也不评分专注质量。
- 周/月视图是「最近 N 天」滚动窗口,不是自然周/月。
- 黄金时段是单一的每日固定区间,不能按星期设置不同区间。
- 黄金时段结束时间受浏览器时间控件限制,最晚 23:59。
- 数据只存在当前浏览器的 localStorage;换设备请用 JSON 备份。
- 删除单条记录前会在该条旁二次确认,但确认后没有撤销;跨午夜拆开的两段是两条独立记录,删除其中一条不会连带删除另一条。
- 草稿预览只覆盖「一天的账」页;周/月视图和周报只统计已保存的记录。
