# SPEC · 19 注意力账本

灵感:李笑来公开文章中的相关概念(本工具是作者的理解,不代表其本人观点)。目标用户:创作者、自学者、自由职业者。付款人:本人。

## 核心任务(必须跑通)

1. 录入时间段:日期、开始、结束、做了什么、类别(生产 / 学习 / 消费 / 杂务 / 休息,可自定义但必须归入这五大类之一)、是否「黄金时段」(用户自定的一天中注意力最好的时段,默认 09:00–12:00,可改)。结束 ≤ 开始报错;同日区间相交提示并阻止保存。
2. 一天视图:时间轴条(div 宽度=运行时数据),五类配色;当天生产 + 学习占比;黄金时段里生产/学习的分钟数与占比(核心指标:「黄金注意力给了谁」)。
3. 周/月视图:每天的生产+学习分钟、黄金时段利用率;连续「黄金时段利用率 ≥ 60%」的天数;类别占比变化(本周 vs 上周)。
4. 复盘:每天一句「今天注意力最大的一笔花在了哪里」(自动取当天最长的单段)+ 用户一句话备注;周报 Markdown(时间统计 + 7 条最长段 + 备注)。
5. 导出:记录 CSV;周报 Markdown;JSON 备份。

## 不做

不做后台监控、不自动分类、不评分「专注质量」。

## core.js 暴露

`validateEntry(entry, sameDayEntries)`;`daySummary(entries, goldenWindow)`;`goldenUsage(entries, goldenWindow)`;`rangeSummary(entries, fromISO, toISO, goldenWindow)`;`streak(days, threshold)`;`longest(entries, n)`;`weeklyReport(...)`;`toCsv`;`validateImport`。时间用分钟整数。

## 示例

合成 14 天记录(每天 5–8 段),刻意含:黄金时段被消费占满的两天、跨午夜一段(拆成两段存)、一段重叠(在「错误示例」里演示阻止);标注「合成示例」。

## 测试点(≥ 12)

结束 ≤ 开始拒绝;重叠检测(相邻不重叠);黄金时段交集分钟(部分重叠);占比不除零;rangeSummary 日期边界;streak 阈值;longest 排序;上周对比;CSV 公式防护;`?today`;validateImport 拒绝非五大类;空数据。

## 视觉方向

账本 + 时间轴:深蓝灰底、五类用柔和但可区分的色(AA 对比);手机端时间轴纵向。

## 已知限制(写进 README)

手填本身消耗注意力(李笑来方法的反证);不做自动采集。
