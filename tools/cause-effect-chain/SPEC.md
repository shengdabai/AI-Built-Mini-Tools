# SPEC · 47 因果复盘链

目标用户:家长(也可自用复盘);付款人:本人。

## 核心任务(必须跑通)

1. 复盘条目:日期、谁(孩子名/自己)、事件(一句)、链条:「因为 → 所以 → 然后」可多级(≥ 2 级,≤ 6 级),每级一句;谁提出的(孩子 / 家长)、情绪状态录入时(平静 / 有情绪);标签(安全 / 作业 / 社交 / 其他,可配)。
2. 规则提示(纯规则,可配词表):链条里出现「以后 / 将来 / 长大 / 找不到工作」等远期词 → 提示「空泛因果,换成今天看得见的」;录入时情绪=有情绪 → 提示「先冷静,复盘时再谈」并允许保存为草稿;链条只有 1 级 → 提示「再推一步」。
3. 可视化:每条复盘画成横向链(运行时 div 节点 + 连线);「谁提出」用颜色区分;孩子自己推演的比例随时间折线(SVG);标签分布条形。
4. 复盘时刻:固定两个提示时段(用户设,如 晚饭后)显示「今天的事」清单(当天未复盘条目);不做系统通知。
5. 回看:按孩子、按标签、按关键词检索;同一事件再次发生 → 关联旧条目(手动选)并显示「上次链条」。
6. 导出:Markdown 复盘册(按月)、CSV、JSON 备份;导入校验(级数 2–6、枚举、日期)。

## 不做

不评分孩子、不给教育建议、不联网。

## core.js 暴露

`checkChain(entry, config)` → `{issues}`;`childRatio(entries, days)`;`tagStats(entries)`;`todayPending(entries, today)`;`search(entries, q)`;`link(entries, id, prevId)`;`toMarkdown`;`toCsv`;`validateImport`;`?today`。

## 示例

合成 10 条(两个孩子名用「A 娃」「B 娃」),含 1 条远期词、1 条有情绪草稿、3 条孩子自己推演、1 对关联事件;标注「合成示例」。

## 测试点(≥ 12)

远期词提示;有情绪草稿;1 级提示;级数上下限拒绝;childRatio 除零;tagStats;todayPending 只取当天未复盘;search 中文子串;link 自指拒绝;Markdown 按月分组;CSV 公式防护;`?today`;写读校验同源。

## 视觉方向

暖白 + 深绿链;孩子提出 = 亮色,家长提出 = 灰;手机端链纵向。

## 已知限制(写进 README)

规则词表简单;不替代真实对话。
