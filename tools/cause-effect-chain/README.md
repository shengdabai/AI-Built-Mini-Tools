# 因果复盘链

## 定位

把孩子(或自己)的一件事推演成「因为 → 所以 → 然后」的可视化链条,在复盘时刻回看,不在情绪高点讲道理。纯前端,双击 `index.html` 即可使用。

## 目标用户与核心任务
目标用户:想帮孩子建立日常因果认知的家长(也可自用复盘)。核心任务:录入一条复盘(日期、谁、事件、2–6 级链条、谁提出、录入时情绪、标签)→ 看规则提示 → 链条随输入即时重绘 → 保存 → 在回看、统计、导出里使用。

## 如何打开
双击 `index.html`(file:// 可用,无依赖、不联网)。演示可加 `?today=2026-10-20` 固定「今天」;非法或不存在的日期(如 2026-02-30)回退真实今天。数据存在浏览器 localStorage(键 `causalchain.v1`)。

## 功能
- 复盘录入:链条输入框 1 到 6 个(正式复盘需 2—6 级,草稿可以暂不填写链条);删除已填写的最后一级先页内确认,空白一级直接删;增减一级时预览链条节点同步增减;孩子提出为亮绿节点,家长提出为灰色节点;手机端链条纵向。
- 规则提示(可在「导出与设置」改词表):链条含远期词 → 「空泛因果,换成今天看得见的」;录入时情绪=有情绪 → 「先冷静,复盘时再谈」,只提示,仍可保存为草稿,也不禁止保存正式条目;链条只有 1 级 → 「再推一步」。
- 复盘时刻:两个自设时段;「今天的事」列出当天的草稿(未复盘)条目,可「继续复盘」。不做系统通知。
- 回看:按人、标签、关键词(中文子串)检索;新条目可手动关联旧条目,卡片里显示「上次链条」。
- 统计:孩子自己推演的比例按周折线(运行时 SVG),没有记录的周不画点、折线在那里断开并标「无记录」(连续有数据的周才连线);标签分布条形(运行时 div)统计全部条目(含草稿和「自己」的条目),一条可计入多个标签,数量单位是“条”,最长条代表数量最多的标签。不用任何图表库。
- 表单里有未保存内容(新建填了事件/链条、编辑中有改动)时,Markdown / CSV / JSON 导出暂停并写明原因;存储失败提示里的“导出当前内存中的全部复盘 JSON 备份”不受影响,导出内存中已保存的全部条目与设置(不含表单草稿)。
- 示例条目(id 以 `sample-` 开头)在回看页顶部提示条、CSV(“数据性质”列,只在含示例条目时出现)和 Markdown(标题旁“合成示例”及开头说明)里持续标注;刷新后仍在,删除示例条目后消失。
- 地址加 `?today=` 生效时页面右上角持续显示“基准日 YYYY-MM-DD(由地址参数固定)”。导入入口在页面顶部始终可见。
- 载入示例、导入、清空的确认以“已有条目 + 自定义设置 + 表单未保存内容”为判据,文案写明替换数量;删除条目的确认写明有几条关联它。
- 导出:Markdown 复盘册(按月)、CSV、JSON 备份;可导入 JSON,校验级数 2–6、枚举、日期、id 唯一、关联合法,任一不合法整份拒绝。
- 「载入示例」与导入在已有条目或自定义设置(标签、远期词、时段与默认不同)时先出现页内确认;「清空数据」总是先确认;存储写入失败时显示持续可见的「未保存」提示并引导导出。

## 口径(SPEC 未规定,本实现的选择)
- 状态分「已复盘」与「草稿」:已复盘要求链条 2–6 级;草稿允许 0–6 级(为了先记下事件)。
- 比例统计只算已复盘、且「谁」不是「自己」的条目;草稿不计;无数据的周不画点,不画 0%。
- 「今天的事」= 日期为今天且状态为草稿。
- 导入时多余字段不会被保留(只读取已知字段);字符串不做截断或修剪。
- Markdown 用列表而非表格;仍对以 `=`、`+`、`-`、`@` 开头的用户字段加单引号前缀(单独的 `-`、`+` 除外)。
- 读取时校验失败的本地数据不会被覆盖:原文另存到 `causalchain.v1.rejected`,界面显示原因。
- 关联校验先确认所有 prevId 指向存在的条目,再查环;任何不合法(含 A→B、B→不存在)整份拒绝,写入与读取同一函数。
- 孩子名在示例中只用「A 娃」「B 娃」占位。

## 已知限制
- 规则词表简单,只做字面包含匹配,会漏判也会误判。
- 不替代真实对话;不评分孩子、不给教育建议。
- 复盘时段只是显示与提示,不发系统通知。
- 数据只在本机本浏览器;换设备请用 JSON 备份。不支持从 CSV 导入。
- 窄屏下统计折线按容器宽度重绘,极窄时横轴只显示部分日期。
