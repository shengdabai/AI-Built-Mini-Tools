# 委托契约卡

## 定位

一个纯本地的单页工具，在把任务交给 AI Agent 之前，先把边界写成一张「契约卡」；任务做完后用分钟数回填，算出这次委托的「净省时」。做完的委托记进台账，按任务类型提示「可以继续委托」还是「先别再委托这类」。

## 目标用户

已经在把真实工作交给 Claude Code、Codex 或其他 Agent 的个人和小团队。他们想放权，又怕越界；感觉省了时间，却说不清监督和返工吃掉了多少。

## 核心任务

1. **授权前：**写清任务包，包括目标结果、输入材料、逐条的完成标准、截止条件、卡住时怎么问。再把动作分进自主区、必问区、禁止区，并选定信任级别。
2. **授权后：**回填六项分钟数和验收结果，看这次委托是省还是亏。
3. **长期：**按任务类型累计结果，决定这类任务要不要继续委托。

## 如何打开

- 双击 `index.html` 就能用（file:// 协议）。不联网、不登录，也不需要安装任何依赖。
- 首屏就是起草工作区。点右上角「载入示例」会载入一张示例草稿和 7 条已回填的委托，这些都是合成示例。
- 数据只存在本机浏览器的 localStorage 里，键名为 `weituoqiyueka.v1`。「清空数据」要二次确认后才会删除。
- 存储异常的处理：
  - 只有写入成功后才会提交状态并提示成功。存入台账、回填记分、删除、载入示例、清空如果写入失败，页面数据保持原样，顶部显示持久的红色「未保存」提示（不会被后续 toast 盖掉），下次写入成功后自动消失。
  - 读到无法解析或结构不对的数据时，先把原始内容原样另存为 `weituoqiyueka.v1.corrupt-<时间戳>`，顶部持续显示「本机数据已损坏」及备份键名。如果连备份也写不进去，就暂停一切保存，避免覆盖唯一副本；确认不要后点「清空数据」重置。
- 在 URL 后加 `?today=YYYY-MM-DD` 可以固定「今天」的日期，用于复现截图。

## 功能

- **任务包五要素：**目标结果、输入材料、完成标准、截止条件、卡住时怎么问我，五项都是必填（另加任务名）。完成标准可以逐条添加或删除。缺任何一项都会被拒绝存入台账，并提示缺哪一项。
  - 四个长文本框（目标结果、输入材料、截止条件、卡住时怎么问我）每项最多 2000 字，输入框下方实时显示「已写 / 2000 字」，到上限时明确提示超出部分不会被输入。核心逻辑不再静默截断：超长内容会被校验拒绝存入和导出，而不是悄悄丢字。
- **三栏权限边界：**
  - 内置 10 个常见动作：读文件、联网检索、改文件、执行命令、安装依赖、发消息/外发、付款/花钱、发布/部署、删除数据、改权限/凭据。其中后 5 个标为高风险。
  - 移动动作有三种方式：点「自主 / 必问 / 禁止」，拖拽到另一栏，或聚焦动作名后按 ← → 键。
  - 高风险动作放进自主区时，会立即显示红色警示。
  - 可以添加自定义动作，并标注是否高风险。名称重复会被拒绝。
- **信任阶梯与一致性检查：**
  - 三个级别：L1 只建议 / L2 确认后执行 / L3 已授权范围内自主。
  - 按「级别 × 自主区里有几个高风险动作」套用 R1–R7 规则，给出一致 / 需注意 / 不一致的判定，并写明触发条件。
  - 预览卡上的印章会同步显示判定结果。
- **契约卡预览与导出：**
  - 实时生成文档式预览。
  - 可以复制为 Markdown（优先用剪贴板 API，不可用时退回 execCommand），或下载为 `委托契约卡-<任务名>.md`。
  - 用户填写的文字在导出时逐字符转义（反斜杠、`` ` ``、`*`、`_`、`[ ]`、`< >`、`#`、`|`、`~`、`&`，以及行首的 `-`/`+`/`=` 和 `1.`/`1)` 序号），因此无法伪造标题（含 `##` 多级标题）、引用、列表、代码围栏或原始 HTML，也改不了契约的章节结构。
- **净省时记分：**
  - 回填六项分钟数：手工基线、AI 流程人工执行、监督、返工、授权维护、学习。另外要选择验收是否合格，这是必填项。
  - 结果允许为负，为负时显示「这次委托是亏的」。
  - 页面画出 SVG 瀑布图，并写出算式和复核式。
- **委托台账：**
  - 四个指标：累计净省时、亏损任务占比、已回填委托数、验收合格率。
  - 按任务类型给出建议：
    - 同类少于 3 次：「样本不足」。
    - 平均净省时为负：「先别再委托这类」。正负按未舍入的同类总额判断，所以 −0.1、0、0 这种平均值四舍五入后显示为 0 的情况，仍判为负，表格里写「略低于 0 分」。
    - 合格率低于 2/3：「收缩」。
    - 同类总额正好为 0：「持平」。
    - 其余情况：「可继续委托，一次只扩大一个维度」。
  - 全部委托可以查看、回填或删除，删除要确认。
  - 可以导出 `委托台账-<日期>.csv`，文件带 BOM，Excel 打开不会乱码。

### 公式（以笔记为准）

笔记原文：

> 「假设同质人工基线为 240 分钟；采用 AI 后仍有 60 分钟必要人工执行，因此表面省时为 180 分钟。」
>
> 「净省时 ＝ 180 − 35 − 25 − 10 − 20 ＝ 90 分钟 复核：240 −（必要执行 60 ＋ 监督 35 ＋ 返工 25 ＋ 授权 10 ＋ 学习 20）＝ 90。 监督包含终验；各项用时互斥，避免重复扣减。」
>
> 「每周净省时 未采样 同质人工基线用时 − AI 流程中的全部人工用时，允许负值。」

对应的实现（`core.js` 里的 `computeNetSaving`）：

- 表面省时 ＝ 手工基线 − AI 流程人工执行，允许为负。
- 净省时 ＝ 表面省时 − 监督 − 返工 − 授权维护 − 学习。

**口径假设：**产品需求里的「AI 实际耗时」，我按笔记的「AI 流程中的必要人工执行」来实现，也就是你在 AI 流程里仍然必须亲手做的时间。机器独立运行的时间不计入，被迫守候、无法另作安排的时间要计入。如果需求方原意是「机器运行时长」，需要改这一项的定义。

## 已知限制

- 这是纯本地单机工具，不连接任何 Agent，也无法强制 Agent 遵守契约。契约卡只是一份写给人和 Agent 看的约定。
- 分钟数全靠使用者自报，没有计时器，也不自动采集。
- 「载入示例」里的 7 条台账全部是合成示例，界面上都带「合成示例」标记。它们不是真实使用数据。
- 两类规则都是按笔记口径做的简化，不是统计检验：
  - 台账阈值：同类满 3 次才下结论，合格率 2/3 以下收缩。
  - R1–R7 一致性规则。
- 数据只存在当前浏览器的 localStorage 里，不跨设备同步。清除浏览器数据会一并丢失，需要自己导出 CSV 或 Markdown 备份。
- 没有撤销操作。删除单条委托和清空数据都靠二次确认来防止误操作。
- 损坏数据的备份键 `weituoqiyueka.v1.corrupt-*` 不会自动删除，也没有界面内的恢复入口；需要用浏览器开发者工具手动查看、导出或删除。「清空数据」只删主键，不删这些备份。
- 编辑草稿时如果写入失败，输入框和预览仍显示你刚输入的内容（否则界面会和输入框不一致），但顶部会一直提示「未保存」，刷新会丢失这部分改动。
- 字数上限按浏览器 `maxlength` 口径（JS 字符串长度）计算，个别 emoji 等补充平面字符会按 2 个字计。粘贴超长内容时，浏览器会截到 2000 字，计数提示会显示「已达上限」。
- 拖拽只支持鼠标（HTML5 drag）。触屏请用「自主 / 必问 / 禁止」按钮，键盘请用 ← →。
