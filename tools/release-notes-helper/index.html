版本发布说明助手

把 git log(git 的提交记录)按约定式提交(Conventional Commits,一种提交标题写法:类型(范围): 说明)整理成发布说明和更新日志(CHANGELOG)。第一步:点右侧「载入示例」,或把 git log 粘贴到左侧。数据只留在本机,不联网。

未保存:浏览器拒绝写入本机存储(空间已满或被禁用)。 关闭或刷新页面后,这次的输入和勾选会丢失。请先在右侧导出 Markdown 备份。

确认载入合成示例?

git log 输入

确认清空? 输入的日志、版本号、勾选和手改的 Markdown 都会从本机删除,无法恢复。

合成示例,非真实仓库。下面的日志、仓库地址和版本号都是虚构的;改动日志文本或点「清空」后这个标记消失。

要不要写进发布说明

条目

勾选「需要用户操作」的条目,会在发布说明末尾单独列出。

    合成示例,非真实仓库。右侧的预览、更新日志和导出文件首行都会标注。

    输入已经改动,你手改过的 Markdown 还是基于旧输入。 确认前不能导出,避免导出内容和界面不一致。
    确认恢复为自动生成? 你手改的 Markdown 会被丢弃,无法撤销;勾选的「需要用户操作」不受影响。
