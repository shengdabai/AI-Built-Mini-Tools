# SPEC · 43 多维竞争力雷达

灵感:李笑来公开文章中的相关概念(本工具是作者的理解,不代表其本人观点)。目标用户:职业转型者、自由职业者、带孩子规划的家长;付款人:本人。

## 核心任务(必须跑通)

1. 维度录入:维度名、当前分(0–100)、目标分、一句证据(为什么给这个分)、投入每周小时(可选);维度 3–10 个;支持多「人/时期」档案(自己 2024 / 自己 2026 / 对标者)。
2. 雷达图:运行时生成内联 SVG 多边形(当前 vs 目标两层,或两档案叠加);悬停顶点显示分数与证据;维度数变化时轴自动重排;手机端图缩放不溢出。
3. 「面积」计算:多边形面积(按分数做半径)与「单维度满分」面积比较;给出「第一名维度」与「面积」两个口径的提示:只有 1 个维度 ≥ 80 且其余 < 30 → 提示「单维竞争,只有第一名有意义」;≥ 3 个维度 ≥ 60 → 提示「多维面积已成型」。
4. 投入建议(规则,不是 AI):把每周小时按「离目标差距 × 权重」给出分配表;用户可改权重;显示「这周把时间投到哪个维度面积增长最快」(边际面积 = 相邻两维度分数之和相关)。
5. 时间线:同一档案的历史快照(日期 + 分数)→ 面积随时间折线(SVG);本月 vs 上月。
6. 导出:档案 CSV(维度 × 分数)、雷达 SVG 文件、JSON 备份;导入校验(分数范围、维度数 3–10、名称唯一)。

## 不做

不打总分排名、不比较他人真实数据、不给职业建议。

## core.js 暴露

`polygonPoints(scores, size)`;`area(scores)`;`compareSingleVsMulti(scores)` → 提示列表;`allocate(dims, hours, weights)`;`marginalArea(scores, i)`;`timeline(snapshots)`;`toCsv`;`toSvg`;`validateImport`。

## 示例

合成档案「某英语教师 2026」6 维(教学、写作、产品、英语、编程、分发)+ 目标分 + 3 个历史快照;对标档案「单维高手」(1 维 95 其余 20);标注「合成示例」。

## 测试点(≥ 12)

polygonPoints 数量与闭合;area 对称性(全 50 与全 100 比例);单维/多维提示两种情况;allocate 总和 = hours 且差距 0 的维度分 0;marginalArea 最大维度选择;timeline 按日期排序;维度数 <3 或 >10 拒绝;分数越界拒绝;名称重复拒绝;toSvg 含 polygon 与维度名转义;CSV 公式防护;写读校验同源。

## 视觉方向

白 + 深青;雷达线细、面填充半透明(token 色);手机端单列。

## 已知限制(写进 README)

分数自评,无外部校准;面积只是一种直觉化口径。
