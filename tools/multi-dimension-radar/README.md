# 多维竞争力雷达

## 定位

把「竞争力」画成面积:记录各维度的自评分与证据,用雷达图比较当前分和目标分,图形面积由自评分计算。给自己的 3–10 个维度打分(当前分、目标分、一句证据),看雷达多边形和面积,再按规则决定这周把时间投到哪里。

## 目标用户

职业转型者、自由职业者、带孩子做规划的家长;付款人:本人(见选型报告第四批第 43 行)。

## 核心任务

1. 录入维度(名称、当前分 0–100、目标分、一句证据、每周小时可选),维度数 3–10;可建多个档案(自己 2024 / 自己 2026 / 对标者)。
2. 雷达图:运行时生成的内联 SVG(无图表库),当前与目标两层,可叠加另一个档案;改分数即时重绘;悬停或 Tab 聚焦顶点显示分数与证据;维度数变化时轴自动重排。
3. 面积:按分数做半径的多边形面积,与「单维满分」(多边形面积恒为 0)「满分多边形」对比;提示规则:仅 1 个维度 ≥ 80 且其余 < 30 → 单维竞争;≥ 3 个维度 ≥ 60 → 多维面积已成型。
4. 投入建议(规则,不是 AI):每周小时按「差距 × 权重」分配(权重可改);标出边际面积最大的维度。
5. 时间线:同一档案的快照(日期 + 分数)→ 面积折线;本月 vs 上月。
6. 导出 CSV(维度 × 分数)、雷达 SVG、JSON 备份;导入校验。

## 如何打开

双击 `index.html`(纯前端,无需安装、联网、登录)。数据存在浏览器 localStorage(键 `radar.v1`)。地址加 `?today=2026-10-20` 固定「今天」(用于快照默认日期与本月/上月对比;非法或不存在的日期如 `2026-02-30` 回退真实今天)。

## 口径(SPEC 未规定,本实现的约定)

- 雷达坐标:第 0 维在正上方,顺时针;半径 = 分数 / 100 × 半径上限。
- 面积 = ½·sin(2π/n)·Σ sᵢ·sᵢ₊₁(分数单位²);满分 n 维多边形为 100%。
- 「单维满分」用同一个多边形公式:一个维度 100、其余 0 的多边形面积恒为 0(退化成线段),界面直接展示这个事实,整体面积与 n 维满分多边形比较。
- 边际面积 = 把某维提高 1 分时面积的增量 = ½·sin(2π/n)·(相邻两维分数之和);「增长最快」只在还有差距(目标 > 当前)的维度里选,并列取靠前。界面只说「每提高 1 分图形面积增加最多」:没有计入提分所需小时数,不能据此判断每小时的提升效果。
- 面积依赖维度顺序(公式用相邻维度的分数):相同分数换序面积可能不同。比较面积时维度名称、数量、顺序必须一致;本月与上月快照的名称或顺序不同时停止比较并写明原因。
- 分配按输入的小数精度(至少 0.01 小时)为单位用最大余数法,不舍入输入,合计严格等于每周小时(0.001 也能分配),只在显示时按该精度取整;差距为 0 或权重为 0 的维度得 0;全部为 0 时不分配。
- 叠加对标档案时按维度名匹配,对标档案缺少的维度按 0 分画并提示。
- 快照按各自的分数条数计算面积;本月与上月快照维度数不同时不比较。同一天重复记录会更新该日快照。
- 导出 CSV 的以 `=`、`+`、`-`、`@` 开头的文本字段加单引号前缀(单独的 `-` / `+` 不加);CSV 开头带 BOM 以便 Excel 识别中文。
- 导入 JSON 整份校验(版本、字段类型、分数范围、维度数 3–10、名称唯一、id 唯一、快照日期为真实日期),任一不合格整份拒绝并给原因;保存前与读取时使用同一个 `validateState`。
- 输入框内容不合法时(红框)不改动已保存数据,同时禁用导出,避免导出内容与界面不一致。保存失败提示里的「导出当前内存中的全部档案 JSON 备份」导出当前内存中的有效数据(含尚未写入浏览器的合法修改,不含非法输入框内容),不会解除普通导出的禁用。
- 导出 CSV 增加「数据性质」列(合成示例 / 自评),导出 SVG 标题对合成示例加「(合成示例)」。
- 载入示例、导入、清空的确认以「任何档案 + 未提交的新档案名称草稿」为判据,确认文案写明替换的档案、快照数量。
- 地址加 `?today=` 生效时页面顶部持续显示「基准日 YYYY-MM-DD(由地址参数固定)」。

## 已知限制

- 分数自评,无外部校准;面积只是一种直觉化口径。
- 不打总分排名、不比较他人真实数据、不给职业建议。
- 只能导入 JSON 备份,不能导入 CSV。
- 导出的 SVG 不自动换行,很长的维度名可能超出画布。
- 不同浏览器 / 设备的数据不互通,靠导出导入迁移。
- 快照只能「记录当前分数」或删除,不能直接编辑历史分数。
