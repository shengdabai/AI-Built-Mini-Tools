# 四层对照卡

## 定位
把「Chinese / Pinyin / Word-by-Word / English」四层逐字对照的教学材料,从手工排版变成可复用的卡片生成器。纯前端,双击 `index.html` 即可使用,无登录、无联网、无埋点。

## 目标用户

## 核心任务
1. 输入中文句子(每行一句),点「生成」,每句一张卡:分词 + 每个词块的拼音(词典拼音优先,字表回退)。
2. 手填每个词块的英文 gloss 与整句英文;填过的「词 → gloss」自动记入个人词典,下次同词自动预填并标「来自词典」。
3. 选中相邻两格「合并」,或选中一格「拆分」成单字;拼音自动重算,gloss 清空等待重填。
4. 导出:单卡 PNG(canvas 绘制,2x)、全部卡 Markdown、制表符纯文本(复制)。

## 如何打开
双击 `index.html`(file:// 下可用)。数据存在浏览器 localStorage:`fourlayer.glossary.v1`(个人词典)、`fourlayer.cards.v1`(当前卡片)。「清空数据」会先在页内确认。

## 口径
- 名词:gloss = 英文词义,即某个中文词块对应的英文解释,由教师手填;界面统一写作「英文词义」。
- **卡片学习次数**:在对照卡里记入或改写某个词的英文词义时 +1;从词典预填不算;在「个人词典」页修改英文词义只改文字,不增加次数(以前列名「使用次数」,容易误读为预填也算)。
- 载入合成示例:数据区持续显示「合成示例」标记(按输入框内容是否等于示例判断,刷新后仍在);导出的 Markdown 与纯文本开头、PNG 底部脚注、导出文件名都带「合成示例」。个人词典 JSON 的格式是纯「词 → 词条」对象,没有地方放标记,所以词典 JSON 不带标记。
- 替换确认:已有卡片、输入框内容或词典词条时,载入示例前先页内确认,写明替换的卡片数,以及词典现有词条全部保留(同词不改)、只补充示例里没有的词条;确认前保持原状。导入词典 JSON 走「校验 → 预览新增/覆盖/保留数量 → 确认 → 合并写入」。
- 导出与输入框一致:输入框里有尚未点「生成」的改动时,导出 Markdown、复制纯文本、导出 PNG 都禁用并提示先生成;导出的预览是点击导出那一刻的内容。
- 保存状态:对照卡和个人词典分别跟踪是否写入成功,只要有一份失败,「未保存」提示就持续显示并点名是哪一份;备份提示同时给出卡片(导出全部卡片 Markdown)和词典(导出词典 JSON)两条路径。
- 删除对照卡、删除词典词条都先在该处页内确认;删除卡片会一并删除手改的拼音、英文词义和整句英文,词典不受影响。
- 本产品不涉及日期,没有 `?today` 参数。

## 功能
- 载入示例(合成示例:3 句例句 + 6 条词典预填)、空状态引导、清空数据(页内确认)。
- 拼音可逐格手改;标点保留为无拼音格子。
- 个人词典页:可改、可删、导出/导入 JSON(导入时同词以文件为准)。
- 卡片学习次数的定义见「口径」。

## 已知限制
- 不自动生成英文 gloss 或整句翻译(无本地词典,不编造),不调 AI,不做繁体。
- 多音字用词典读音或最常用读音,可能需手改。
- PNG 导出字体随系统中文字体,不同电脑字形略有差异。
- 词块较多的句子在桌面宽度下卡片内会横向滚动(页面本身不溢出)。
- 导出文本里以 = + - @ 开头的字段会加一个单引号前缀,防止粘贴进表格软件被当公式;单个 + 或 - 不加。
- 个人词典导入为合并而非替换(同词以文件为准,确认前会预览数量);没有撤销。
- 对照卡本身没有 JSON 备份格式,卡片只能靠 Markdown / PNG 导出留存;「未保存」时请两路都备份。

## 设计 token
`styles.css` 顶部 TOKENS 段:primitive(`--p-*`)→ semantic 两层;断点 760px 写在该段注释。PNG 导出的颜色、字号、边距由 `app.js` 从 `--export-*`、`--row-*`、`--t-*` 读取。
