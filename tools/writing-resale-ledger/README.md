# 写作复售账本

## 定位

记录每部作品的创作耗时和每一次「再售」,看同一段时间被卖了几次。“再售”指把同一作品再发布或再利用一次(换渠道、改写、合集等),每条记录计 1 次,包含原发;次数只是分发记录,不代表有人付款。热力格、散点、渠道条形全部由运行时数据生成(div / 内联 SVG),不用图表库。

## 目标用户与核心任务
写作者、课程作者、独立开发者;付款人是本人。核心任务:录入作品 → 记再售 → 看热力格 / 散点 / 渠道条形即时变化 → 看规则提示与月报 → 导出。

## 如何打开
双击 `index.html`(file://,无依赖、不联网)。`?today=2026-10-20` 可固定「今天」;非法日期(含 2026-02-30 这类自动进位)回退真实今天。

## 功能
- 作品:标题、类型(文章/课/书/视频/代码库)、首次耗时、创作日期;再售:日期、渠道(可新增)、形式、额外耗时、触达(可选)、收入(可选,元,存为整数分)、交易引用(可选 ASCII 订单代号,不要填客户信息)。
- 交易引用只接受可打印 ASCII 字符,会去掉首尾空格。同一作品、同一渠道内按 ASCII 大小写不敏感判定唯一;冲突会拒绝保存或导入。中文说明应写在其他笔记里,不要塞入交易引用。不同作品或不同渠道可以复用相同代号。旧备份导入后交易引用为空,不会虚构订单。没有交易引用的旧记录,只有日期、渠道、形式、额外耗时、触达、收入全部相同时才提示疑似重复。
- 指标:被售次数、累计耗时、每小时被售次数;有收入记录才显示每小时收入,否则「无收入记录」。
- 可视化:作品 × 最近 12 个月热力格;耗时 vs 次数散点(点大小 = 触达);渠道条形。
- 规则提示、月报(对比上月)、作品表 CSV / 月报 Markdown / JSON 备份、校验导入。
- 编辑:作品表「编辑」把作品载入表单,修改标题/类型/创作日期/首次耗时,作品 id 与全部再售记录保留;再售记录列表里「编辑这条」修改日期/渠道/形式/额外耗时/触达/收入。
- 载入示例(合成示例,金额虚构)与清空,均有页内确认。存储失败显示持续可见的「未保存」,并提供“导出当前内存中的全部账本 JSON 备份”。

## 口径(SPEC 未规定,本实现的选择)
- 被售次数 = 再售记录条数(「原发」也是一条)。
- 每小时收入 = 已填收入合计 ÷ 累计耗时,四舍五入到整数分;只有部分记录填了收入时,只计已填部分。没有任何收入记录显示「无收入记录」;已有收入但累计耗时为 0 显示「耗时为 0,无法计算」,两种文案不同(界面与 Markdown 一致)。
- 「载入示例」与导入在账本不是初始状态时先确认;初始状态 = 没有作品且渠道是默认 7 个。
- 月报每小时被售次数 = 当月再售数 ÷(当月新作品首次耗时 + 当月再售额外耗时);无耗时则不计算。
- 「重做」规则按单条记录:该条额外耗时 > 首次耗时。「>90 天」按 today 与创作日期的天数差。
- 不设业务上限(标题长度、渠道数量、小时数大小都不限),只校验类型、枚举、非负有限数、整数分与安全整数范围(超过 2^53 的数字会被拒绝);至少保留 1 个渠道。写入与读取用同一个校验。
- 热力格显示最近 12 个月(以 today 所在月为终点);更早的记录不在热力格里,但计入其他指标。
- 月报月份与导出月份共用一个状态:账本页和导出页的月份输入互相同步,下载按钮写明月份(如“下载 2026-10 月报 Markdown”),导出文件名含该月份。
- 示例标记 `sample` 随账本保存(JSON 备份里也有):页面持续显示“合成示例,金额虚构”提示条,刷新后仍在;作品表 CSV 加“数据性质”列,月报 Markdown 写明“合成示例,金额虚构”;清空、导入非示例备份或删光作品后消失。
- 左侧表单(新增/编辑作品、记再售、新增渠道)有未提交或未保存的内容时,三种导出暂停并说明;载入示例、导入、清空的确认以“作品 + 表单草稿 + 自定义渠道”为判据并写明替换的作品数与再售记录数。
- 地址加 `?today=` 生效时页面持续显示“基准日 YYYY-MM-DD(由地址参数固定)”;导入入口在页面顶部始终可见。
- CSV 带 BOM 以便 Excel 识别中文;以 = + - @ 开头的文字加单引号前缀。

## 已知限制
- 触达与收入自填;「被售」只是记录次数,不证明有人付费。
- 不接平台数据,不估算流量价值。
- 渠道只能新增,不能改名/删除;编辑再售记录时不能把它挪到另一部作品。
- 示例日期固定在 2026 年;不加 `?today` 且真实日期较晚时,热力格窗口会移出示例月份。
- 浏览器清除站点数据会丢失账本,请定期导出 JSON。
