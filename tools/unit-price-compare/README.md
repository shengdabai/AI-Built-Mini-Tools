# 采购单位比价

## 定位
把「一箱、一袋、一桶」规格不同的报价换算成同一基准单位(质量 kg、体积 L、计数 件),按单位价比较各家,并提示涨价。纯前端,断网可用。

## 目标用户
小餐饮店、烘焙店、工作室的采购人员(付款人:店主)。

## 核心任务
1. 录入报价(单条表单或批量粘贴 `供应商 | 品名 | 包装价 | 每包件数 | 每件净含量 | 单位`;批量粘贴任一行有错就整批不导入,并指出错误行号)。
2. 换算:单位价 = 包装价 ÷ (每包件数 × 每件净含量 → 基准单位);缺参数的行不排名,标「缺参数」。
3. 比价:同规格组按单位价升序,显示相对最低价百分比;不同币种、不同量纲分开排名。每家(供应商+品名)在每个「币种 × 量纲」分区内各取最近一条报价参与排名;历史涨跌幅按币种和量纲分别对比上一条有效报价,按未舍入的涨幅判断阈值。
4. 历史价格:同供应商同品名按日期排列,显示相对上次涨跌幅,涨幅大于阈值(默认 10%)警示。
5. 导出:比价表 CSV/Markdown、全部报价 CSV、JSON 备份(也可导入,不合法整份拒绝)。

## 如何打开
双击 `index.html`。第一步:点「载入合成示例」查看合成数据,或到「录入报价」页添加第一条报价。地址后加 `?today=2026-10-20` 可固定「今天」。数据存在浏览器 localStorage(键 `procure.v1`);写入失败会显示持续的「未保存」提示。

## 口径
- 单位价 = 包装价 ÷ (每包件数 × 每件净含量 → 基准单位),计算保留 4 位小数、显示 2 位。
- 「相对最低价」写作「占最低价的百分比(最低价 = 100%)」:最低价 10、另一家 12,显示「120%(比最低价贵 20%)」。导出的比价表 CSV / Markdown 同时有「占最低价的百分比%(最低价=100)」和「比最低价贵%」两列。
- 涨跌幅 = (本次单位价 − 上一条单位价) ÷ 上一条单位价;「上一条」只取同供应商、同品名、同币种、同量纲的有效报价,币种或量纲不同的不参与;「需要留意的涨价」里显示的「上次→本次」就是计算该涨幅用的那一条(例:CNY 10 → USD 2 → CNY 12,显示 10.00 → 12.00 CNY,+20%)。空结果会写明已检查多少个供应商 + 品名、其中多少个有可比的上一条。
- 缺参数的行不排名;每行有「补齐参数」,打开编辑表单并聚焦缺失字段,保存后回到当前规格组。
- 删除一条报价先在该条旁确认,文案写明会影响比价排名和后续涨跌幅的哪些地方;确认前报价与统计不变。
- 载入示例、导入备份、清空前的确认判据:已保存报价、偏离默认(10%)的涨幅阈值、录入表单草稿、批量粘贴框草稿;确认文案写明会被替换的范围。导入先显示条数和阈值再确认。
- 录入表单、批量粘贴框里有未保存内容(或正在编辑)时,普通导出和顶部备份按钮禁用并说明原因;保存失败面板里的备份按钮不受影响,导出当前内存里的全部报价。
- 示例标记刷新后仍在;导出的 JSON(`sample:true`)、CSV(多一列「数据来源」)、Markdown 都标注「合成示例」;清空或导入真实备份后消失。
- 地址带合法的 `?today=` 时,页面持续显示「基准日(由地址参数固定)」。
- 安全核对(2026-10-20):`app.js` 全部用 `textContent` / `createElement` 渲染,没有 `innerHTML` 拼接。

## 已知限制
- 不考虑运费、账期、损耗;不换汇率,不同币种分别排名。
- 不评品质、不推荐供应商。
- 排名只用每家在各币种/量纲下的最近一条报价;旧报价只在历史页出现。
- 数据只在本浏览器,换设备需 JSON 备份/导入。
- 示例数据为合成,价格不代表真实行情。
