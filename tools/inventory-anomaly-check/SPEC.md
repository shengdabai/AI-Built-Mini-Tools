# SPEC · 21 库存异常检查

目标用户:小型零售运营、店主。付款人:店主。

## 核心任务(必须跑通)

1. 导入库存表(CSV/TSV/粘贴;列映射:商品编码(必选)、商品名、期初、入库、出库、期末、单位、安全库存(可选)、单价(可选))。
2. 标准化:数字格式(千分位、全角、空值视为 0 但标「空值按 0」警告);单位映射表(用户可编辑:`个=件=pcs`、`箱`、`kg=千克`、`g=克`),只做同义归一,不做换算。
3. 规则(每条带行号、级别):
   - 阻断:期初 + 入库 − 出库 ≠ 期末(容差 0);期末为负;编码重复;编码为空;数字非法。
   - 警告:同编码单位不一致;期末 < 安全库存;期末 = 0 且本期有入库;出库 > 期初 + 入库(先出后入);名称相同编码不同;单价为空但有出库。
4. 汇总:行数、异常数、各规则命中数、按单位分组的期末合计、库存金额(有单价时)。
5. 修复辅助:对「期末不等」行给出「按公式应为 X」;一键「采用公式期末」(只改选中行)。
6. 导出:异常清单 CSV/Markdown(含原行号);修正后库存表 CSV。

## 不做

不做盘点、不预测、不换算未知单位。

## core.js 暴露

`parseTable`;`guessMapping`;`normalizeNumber`;`normalizeUnit(u, map)`;`check(rows, mapping, options)` → `{issues, stats, rows}`;`applyFormula(rows, indexes)`;`toCsv`;`issuesToMarkdown`。

## 示例

合成 25 行库存表,含:3 行不等、1 行负库存、1 对重复编码、单位 `个/件/pcs` 混用、2 行低于安全库存、1 行先出后入;标注「合成示例」。

## 测试点(≥ 12)

公式校验与容差;负库存;重复/空编码;单位同义归一与不一致;安全库存;先出后入;空值按 0 警告;applyFormula 只改选中行;汇总分组;CSV 公式防护;空表;非法数字。

## 视觉方向

仓储表格感:浅灰 + 深绿;表格横滑;异常行左侧色条;手机端卡片。

## 已知限制(写进 README)

不处理多仓;单位只归一不换算;规则不替代实物盘点。
