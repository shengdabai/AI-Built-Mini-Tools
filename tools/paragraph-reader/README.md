# 逐段精读器

## 定位

一次只显示一段(或一句)的精读工具:记录每段停留秒数,把不懂的词连同上下文句记进生词表,把不同意/存疑的话记进批注清单;按天汇总阅读耐力。纯前端,数据只在本机。

## 目标用户

自学者、家长与孩子、学中文/英文的学生。付款人设想为本人或家长(未验证)。

## 核心任务

1. 粘贴或打开 .txt/.md,按空行分段、按中英文句末标点分句,分别统计中文字数与英文词数。
2. 精读:一次一段(可切成一句),「下一段」推进;选中文字加入生词表或批注;看不懂可「先读过去」并打标。
3. 会话计时(开始/暂停/继续/结束并记录),每 25 分钟(可配)提示休息;显示字数、分钟、字/分钟、标记数。
4. 耐力记录:按日汇总、连续达标天数、最长单次会话、本周对上周、近 7 天目标完成率(目标默认 30 分钟,可改)。
5. 复习:生词表按「最近添加」或「出现次数」排序;批注清单。
6. 导出:生词 CSV、批注 Markdown、阅读记录 CSV、JSON 备份;多篇文本保存在本机并记住进度位置。

## 如何打开

双击 `index.html`(无需安装、联网、登录)。数据存在浏览器 localStorage,键 `reader.v1`。地址加 `?today=2026-10-20` 可固定「今天」;非法或会被进位的日期(如 2026-02-30)回退真实今天。「载入示例」「导入备份」「清空」在已有数据时先在页内确认。

## 口径(SPEC 未规定,由本实现决定)

- 阅读量(界面单位,原称「字数」)= 中文字数 + 英文词数。只在点「下一段/句」或「先读过去」时,把离开的那一段(句)记入会话;回退后再次推进同一段(句)会再记一次,不去重。会话「分钟」只计计时中的时间;阅读量/分钟 = 阅读量 ÷ 分钟,分钟为 0 时为 0。标记数 = 加入生词、批注和「先读过去」的次数。
- 「最近 14 天」每行显示当天分钟和阅读量(同上口径),只含已「结束并记录」的会话。
- 删除生词、批注、文本都先在页内确认;确认前数据不变,确认文案写明将删除的词(及上下文条数)、批注摘要或文本。
- 字数:中文按汉字个数;英文按词(含词内连字符/撇号),数字串也算一词;总数 = 二者之和。
- 一次会话归入开始当天;跨午夜不拆分。
- 周从周一算起;本周含尚未到来的天数。「连续达标」在今天还没达标时从昨天往回数。
- 目标完成率 = 含今天的最近 7 天里达标天数 / 7;达标 = 当天累计秒数 ≥ 目标分钟 × 60。
- 只有「结束并记录」之后的会话才计入耐力记录与阅读记录 CSV;进行中的会话刷新后停在最后一次保存的时刻(约每 15 秒保存一次)。
- 阅读中切换到另一篇文本(打开、新增、删除当前篇)时,原会话先结束并记入阅读记录,归属原文本;新会话归属新文本。
- 点「下一段」时若没在计时会自动开始计时。
- 「先读过去」同时记一条类型为「先读过去」的批注和一个标记。
- 分句:引号内的句末标点不在引号中间断开;`e.g.`、`Dr.`、单字母缩写、小数不当句末;省略号后接小写英文不断句。
- 休息间隔与每日目标接受任何大于 0 的数。

## 已知限制

- 分句规则对特殊标点可能不准(如「1. 条目」会被当作一句;未配对的引号会让后面的句子并在一起)。
- 不解释词义、不联网查词、不朗读、不评分理解;不替代词典。
- 打开文件按 UTF-8 读取;其他编码会乱码(出现无法识别字符时会提示)。
- 会话计时按时间戳算,不检测离开;忘记暂停会一直计时。
- 数据只存在当前浏览器,换设备靠 JSON 备份;localStorage 约 5MB 上限,写入失败会持续提示「未保存」。
- 本 MVP 未经他人试用。
