# AI 提问规格生成器

## 定位
把一个任务分五步写成带限定条件和验收标准的提示词,并附「第一轮先问」版本(对应三步提问法的第 1、2 步)。不调用模型、不评价答案、不做提示词「优化」。

## 目标用户
所有用 AI 干活的人。付款人:本人。

## 核心任务
1. 分步表单:任务一句话 / 限定条件 / 验收标准(带「如何检验」)/ 输出结构 / 角色与语气。
2. 质量检查:任务句缺「给谁用」、验收为空或含不可观察词、限定与验收冲突、总字数超 1500。
3. 生成:完整提示词(角色与语气若填写则放最前,然后任务 / 限定 / 验收 / 输出格式 / 交付前自检清单)与「第一轮先问」,一键复制。
4. 规格库:多份规格、标签、搜索;内置 6 个通用模板(调研、写稿、代码评审、数据分析、翻译、学习计划)。
5. 导出:提示词 Markdown、当前规格 JSON、全部规格 CSV;备份与导入 JSON。

## 如何打开
双击 `index.html`(file:// 即可,无需安装、无需联网)。地址后加 `?today=2026-10-20` 可固定更新日期;非法日期(含 `2026-02-30`)回退真实今天。点页头「载入示例」看完整流程;已有数据时会先在页内确认。

## 口径(SPEC 未规定,本实现的选择)
- 「给谁用」判断:任务句含「给……」「面向」「供……」「受众」「读者」或 for/to the 之一即视为已写;只看任务句,不看「受众」类限定条件。
- 默认模糊词表:优秀、高质量、专业、优质、合适、恰当、合理、漂亮、地道、全面、到位、满意、有深度、清晰、好;按子串匹配(「好」会命中含「好」的任何词)。`vagueWords(text, list)` 可传自定义词表,界面暂不提供编辑入口。
- 冲突检测:取「禁止项」文本,去掉否定词与通用动词(不要、禁止、使用、包含……)后按标点和空白切成关键词;关键词若出现在其他限定条件或验收标准中(这些条目自己以「不要/不出现」等否定开头的除外)即报冲突。属于启发式,可能漏报也可能误报。
- 总字数 = 任务、限定、验收(含检验方式)、输出结构、角色、语气的字符数之和,超过 1500 才建议精简。
- 提示词里用户文本行首的 `#`、`>`、分隔线与三个反引号会加反斜杠转义,避免伪造标题或围栏。
- CSV 里以 `=`、`+`、`-`、`@`(及制表、回车)开头的用户字段加单引号前缀,单独的 `-`、`+` 不加;CSV 带 BOM、CRLF 换行。
- 两种数据格式:本机存档(localStorage 键 `aispec.v1`)是内部格式 `{specs:[…]}`,不带 `app` 和 `version`;「导出全部规格 JSON 备份」导出的外部备份文件是 `{app:"ai-spec", version:1, specs:[…]}`。
- 导入文件只接受外部备份格式:缺少 `app: "ai-spec"` 或 `version: 1` 就整份拒绝并说明;此外任何字段类型、日期格式、枚举(限定条件类别)、ID 唯一性问题也整份拒绝并列出原因。本机存档读取与写入前共用同一个 `validateState`。导入与载入示例都会替换现有数据,故先在页内确认。
- 「下载提示词 Markdown」和「一键复制」都按当前选中的版本:完整提示词(文件名带「完整提示词」)或「第一轮先问」(文件名带「第一轮先问」),按钮上也写明版本。
- 删除限定条件或验收标准:空白行直接删除;有内容的先在页内确认,并列出被删的内容(含检验方式)。
- 本机存档读取失败(格式不对或校验不通过):页面持续显示失败原因,按空白库打开,但旧存档保留在浏览器里。在你点「放弃旧存档并开始新库」(并确认)之前,新改动不会写入,避免覆盖旧存档;「下载原始存档 JSON」可以把旧数据原样取走。

## 文件
`core.js` 纯逻辑,`app.js` 界面,`sample-data.js` 合成示例(4 份,标注「合成示例」),`styles.css` 样式(顶部 `:root` 为设计 token,断点登记在 TOKENS 注释;进度条宽度是运行时数据),`tests/core.test.cjs` 单元测试,`shots.cjs` 截图与端到端脚本,`showcase.html/png` 展示图。数据存 localStorage,键 `aispec.v1`。

## 已知限制
- 模板是结构不是答案;提示词质量仍取决于你写的限定与验收。
- 质量检查是关键词与规则,不理解语义:漏报、误报都可能发生。
- 模糊词表界面不可编辑;不做语言识别,英文规格只能匹配 for/to the 与词表。
- 复制依赖浏览器剪贴板权限,被拒时会选中文本并提示手动复制。
- 导入为整份替换,不做合并;外部备份必须是本工具导出的格式;浏览器清除站点数据会丢失规格,请定期「备份全部 JSON」。
