# HSK 分级改写检查器

## 定位
成人中文教师的备课小工具:贴入一段中文材料,按目标 HSK 级别给每个词着色,列出超纲词,改写后马上重新检查并对比。纯前端,双击 `index.html` 即可使用,不联网、不登录、不收费、不埋点。

## 目标用户

## 核心任务
1. 左侧贴入原文,选目标级别(HSK 1–6、7–9),点「检查」。
2. 右侧按词着色:目标级内正常显示;高出 1 / 2 / 3 级以上用三档颜色加不同下划线样式;词表外汉字用蓝底虚线。下方有统计、超纲词清单(词 / 级别 / 拼音 / 次数,按级别降序、次数降序,点词在正文里定位)和词表外汉字串。
3. 在「改写区」(初始为原文副本)改写,点「重新检查」,得到改写版统计和「改写前 → 改写后」对比条。
4. 导出 Markdown 报告(两版统计 + 超纲词表 + 改写后全文)和超纲词 CSV。导出同时在页内显示预览,便于直接复制。

## 如何打开
双击 `index.html`(file:// 下可用)。数据保存在浏览器 localStorage,键名 `hskcheck.v1`;「清空数据」先出现页内确认区。

## 口径
- 汉字数:文本中的汉字个数,不含标点、字母、数字。
- 词数:分词后词表内的词(按出现次数累计)+ 词表外汉字串(相邻词表外汉字合并为一串,算 1 个词)。
- 目标级内词占比 = 目标级内词数 ÷ 词数;词数为 0 时显示 0.0%。
- 超纲词数:级别高于目标级别的词,按出现次数累计;清单里同一个词只列一行并给出次数。「超纲词」即 SPEC 里的「超级词」(文案改名,逻辑不变)。
- 平均句长 = 汉字数 ÷ 句数;句子按 。！？；(含英文 ! ? ;)和换行切分。
- 结果过期:原文或改写文相对上次检查有改动(含第一次改写、尚无改写后结果时),导出按钮禁用并持续提示。点「检查」只检查原文;保留的改写文若与原文不同,须点「重新检查」后才能导出。
- 「合成示例」标记按原文是否等于示例文本判断,刷新后仍在;改动原文或清空后消失;导出的 Markdown 加「数据来源」行,CSV 加「数据来源」列,文件名带「合成示例」。
- 载入示例前的确认判据:原文、改写文非空,或目标级别不是 HSK 3(示例刚载入且未改动时不再确认)。
- `?today=YYYY-MM-DD`:按真实日历校验,`2026-02-30` 之类回退真实今天;生效时页面顶部显示「基准日 …(由地址参数固定)」。

## 功能与规则
- 统计:汉字数、词数(词表内词 + 词表外汉字串)、目标级内词占比(目标级内词 / 词数)、超纲词数、词表外词数、句数、平均句长(汉字数 / 句数)。
- 超纲词:词表命中且级别高于目标级别;目标 7–9 时没有超纲词。
- 分句:按 。！？；(含英文 ! ? ;)和换行切分,末尾无标点的尾句也算一句。
- 分词:共享的最大匹配分词(`../_shared/cn-segment.js`)。
- 用户输入一律用 textContent 渲染;不使用 alert / confirm / prompt。
- 演示和测试可在地址后加 `?today=2026-10-20` 固定导出文件中的日期(见「口径」)。
- 用户输入只用 `textContent` 渲染,代码里没有 `innerHTML` 模板插值,审计脚本的该项无命中(2026-10-20 核对)。

## 词表来源与数据说明
- 词表:`../_data/hsk-words.js`,由官方 HSK 考试大纲(2025-11 发布,2026-07 实施)PDF 文本层解析生成,共 11000 行、10896 个不重复词;各级词数 1:300 / 2:200 / 3:500 / 4:1000 / 5:1600 / 6:1800 / 7–9:5600。
- 级别取该词出现的最低级别,大纲括注的其他级别未保留(`HSK_META.levelNote`)。
- **拼音由 pypinyin 0.54 生成(Style.TONE,不/一 变调),不是大纲原文拼音;多音词可能取错读音**(`HSK_META.pinyinNote`)。单字拼音表 `../_data/pinyin-map.js` 同样由 pypinyin 生成。

## 已知限制
- 不给同义词替换建议(本地没有同义词数据,不编造);不调用 AI;不做简繁转换,不处理繁体。
- 分词是最大匹配,遇到歧义(如「学生活动」类)可能切错,进而影响级别判断。
- 多义词只取最低级别;个别词拼音缺失时显示「—」。
- 人名、地名等专有名词不在词表内,会按词表外汉字串标出,这是预期行为。
- 词表外汉字串只合并相邻汉字,中间有标点或空格会断开。
- 只检查词汇级别,不检查语法点难度。
- 没有 JSON 备份导入:本产品只存最近一次原文、改写文和级别,恢复靠浏览器本机存储;SPEC 未要求备份导入,未新增。
- 数据只存在当前浏览器;存储满或被禁用时页面会提示「未保存」,需手动导出。换浏览器或清除站点数据后需要重新贴入。
