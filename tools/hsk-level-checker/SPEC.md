# SPEC · 01 HSK 分级改写检查器


## 核心任务(必须跑通)

1. 教师把一段中文材料贴进左侧文本框,选目标级别(HSK 1 / 2 / 3 / 4 / 5 / 6 / 7–9)。
2. 点「检查」:右侧按词着色显示全文(目标级内 = 正常;超级 = 按高出级别着色;词表外汉字 = 另一种标记),下方给出:
   - 统计:总字数(汉字)、词数、目标级内词占比、超级词数、词表外词数、句数、平均句长(按 。！？；分句)。
   - 超级词清单:词 / 级别 / 拼音 / 出现次数,按级别降序、次数降序;点击清单项,正文里该词高亮滚动到位。
   - 词表外清单(单字回退的汉字串,合并相邻 char 为一串显示)。
3. 教师在「改写区」(第二个文本框,初始为原文副本)改写,点「重新检查」:显示改写版的同样统计,并给「改写前 → 改写后」对比条(超级词数、目标级内占比)。
4. 导出:Markdown 报告(两版统计 + 超级词表 + 改写后全文);CSV(超级词表)。

## 不做

- 不给同义词替换建议(无本地同义词数据;不编造)。
- 不调用 AI。不做简繁转换。不处理繁体。

## 数据与算法

- 词表:`../_data/hsk-words.js`(`HSK_WORDS[词] = {l, p}`,l 为最低级别,7 = 7–9 级)。字表:`../_data/pinyin-map.js`。
- 分词:`../_shared/cn-segment.js` 的 `CnSegment.segment(text, HSK_WORDS, PINYIN_MAP)`,不要自己写分词。
- 「超级」定义:token.kind === 'word' 且 level > 目标级别;目标级别 7 表示 7–9 级,此时无超级词。
- 保存:localStorage 键 `hskcheck.v1`,存最近一次原文、改写文、目标级别;「清空数据」页内确认。
- `core.js` 暴露:`analyze(text, targetLevel, dict, charMap)` → `{tokens, stats, overLevel:[{word, level, pinyin, count}], outOfList:[...]}`;`compare(before, after)`;`toMarkdown(...)`;`toCsv(...)`;`splitSentences(text)`。

## 示例(载入示例)

一段约 120 字的合成短文(HSK 3 水平日常话题),刻意含 4–6 个 HSK 5–6 级词;标注「合成示例」。

## 测试点(≥ 10)

最长匹配;目标级别边界(level 等于目标不算超级);7–9 级无超级词;词表外汉字进 outOfList;超级词计数与排序;句子切分(中英文标点、无结尾标点的尾句);空输入;纯英文输入;compare 的差值方向;Markdown/CSV 含表头与转义(逗号、引号)。

## 视觉方向

教师备课工具感:深青 + 米黄高亮不是奶油底;正文着色用 3 档可区分且 AA 对比的色阶;字号 ≥ 16px。

## 已知限制(写进 README)

词表来自官方 2025 大纲 PDF 文本层解析,–11000 连续,但个别拼音缺失;多义词取最低级别;分词是最大匹配,遇到歧义(如「学生活」)可能切错。
