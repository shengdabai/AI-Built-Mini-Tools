# SPEC · 02 课时账单核对台


## 核心任务(必须跑通)

1. 维护学员:姓名、课时单价、币种(CNY / USD / EUR / GBP / 其他自填)、课包总课时(可为 0 表示按次结算)、课包开始日期、取消规则(学员提前 N 小时内取消是否计费,N 默认 24;缺席是否计费,默认计费)。
2. 录入课记录:日期、开始时间、学员、时长(分钟)、状态(已上 / 学员取消 / 教师取消 / 缺席)、取消提前小时数(状态为学员取消时填)、备注。两种录入:单条表单;批量粘贴,每行 `日期 | 学员 | 分钟 | 状态`(也认全角 `｜`;状态可省略默认已上),实时预览识别结果和格式错误行。
3. 录入收款:日期、学员、金额、币种、备注。
4. 生成对账:选学员 + 月份 → 对账单:每条课的计费判断(计费 / 不计费 + 原因)、本月应计课时与金额、累计课包消耗与余额(总课时 − 历史所有计费课时)、本月收款合计、累计应收 − 累计已收 = 差额。
5. 异常列表(全局):同一学员同一日期时间重叠;课包余额为负;状态缺失;学员名在课记录里出现但未建档;收款币种与学员币种不一致。
6. 导出:对账单 Markdown(可直接发给学员,含计费规则说明);全部课记录 CSV;JSON 备份与导入(校验字段)。

## 不做

- 不接日历 API、不发送邮件、不做支付。不做多教师。

## 规则(core.js 必须按此实现并测试)

- 计费课时 = 时长分钟 / 60,保留两位小数。
- 状态「已上」计费;「教师取消」不计费;「缺席」按学员规则;「学员取消」:提前小时数 < N 则计费,否则不计费;未填提前小时数视为 0。
- 课包余额 = 课包总课时 − 所有计费课时之和(所有月份,不只本月);课包总课时为 0 时不显示余额,显示「按次结算」。
- 重叠判断:同一学员,区间 [开始, 开始+时长) 相交。
- 日期解析支持 `2026-10-20`、`2026/10/20`、`10-20`(年取当前年,`?today` 固定)。
- `core.js` 暴露:`parseBatch(text, students)`;`billable(lesson, student)` → `{hours, billable, reason}`;`statement(student, lessons, payments, month)`;`anomalies(students, lessons, payments)`;`toMarkdown(statement)`;`toCsv(lessons)`;`validateImport(json)`。

## 示例(载入示例)

3 位合成学员(不同币种、1 位按次结算、1 位课包),本月 12 条课记录(含 1 条学员提前 3 小时取消、1 条教师取消、1 条缺席、1 对重叠),4 条收款;标注「合成示例」。

## 测试点(≥ 12)

四种状态计费;取消提前小时数边界(恰好等于 N 不计费);课包余额跨月累计;按次结算不显示余额;重叠检测(相邻不重叠、相交重叠);月份过滤含月初月末;差额计算;批量解析全角分隔与错误行;币种不一致异常;未建档学员异常;导入校验拒绝缺字段;Markdown 含规则说明。

## 视觉方向

账本感:墨蓝 + 暖灰,表格为主;金额右对齐、等宽数字(`font-variant-numeric: tabular-nums`,不是等宽字体标签);手机端表格纵向堆叠成卡片。

## 已知限制(写进 README)

无日历导入;时区按浏览器本地;不处理跨日课。
