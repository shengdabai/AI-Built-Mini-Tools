# 课时账单核对台

## 定位
给独立语言教师用的一对一课时对账工具:把出勤、取消、缺席、课包消耗和收款放在一张账上,选学员和月份,生成能直接发给学员的对账单。

## 目标用户

## 核心任务
1. 建学员档案:单价、币种、课包总课时(0 为按次结算)、课包开始日期、取消规则(默认提前 24 小时内取消计费)、缺席是否计费(默认计费)。
2. 录课记录:单条表单,或批量粘贴(每行 `日期 | 学员 | 分钟 | 状态`,支持全角「｜」,日期后可加开始时间,状态可省略)。
3. 录收款。
4. 选学员和月份生成对账单:逐条计费判断与原因、本月应计课时和金额、课包余额、本月收款、累计应收减累计已收的差额。
5. 全局异常列表:课时间重叠、课包余额为负、状态缺失、学员未建档、收款币种不一致。
6. 导出:对账单 Markdown(含计费规则说明)、课记录 CSV、JSON 备份与带校验的导入。

## 如何打开
双击 `index.html`(file:// 即可,无需安装、无需联网)。地址后加 `?today=2026-10-20` 可固定「今天」。点页头「载入示例」可看完整流程。

## 口径
- 计费课时 = 时长分钟 ÷ 60,保留两位小数。
- 已上:计费。教师取消:不计费。缺席:按学员设置。学员取消:提前小时数小于 N 计费,恰好等于或大于 N 不计费;未填视为 0。
- 课包余额 = 课包总课时 − 所有月份的计费课时之和,**不随所选月份变化**(设了课包开始日期则只统计该日及之后的课);总课时为 0 显示「按次结算」。
- 课包余额旁注明「统计课包开始日起全部已录入课程,不受所选月份影响」;差额旁注明「累计至所选月份月底,只计与学员币种相同的收款」。单位:课时为小时,金额为学员币种。
- 合成示例标记:载入示例后写入存档(刷新后仍在),数据区持续显示「合成示例」;导出的对账单 Markdown 有「数据来源」行,课记录 CSV 多一列「数据来源」,JSON 备份带 `sample: true`,文件名带「合成示例」。清空或导入不带该标记的备份后消失。
- 替换确认:载入示例前,只要有任何学员、课记录、收款或未提交的表单草稿就先显示页内确认(写明替换数量);导入 JSON 备份一律走「校验 → 预览数量 → 确认 → 写入」,校验失败整份拒绝并在页面上持续显示原因。
- 删除课记录、收款、学员都先在该行旁确认;删除学员时写明其课记录和收款会保留并变成「未建档」异常。
- `?today=YYYY-MM-DD` 按真实日历校验(`2026-02-30`、`10-20` 都被拒绝并回退真实今天);生效时页头显示「基准日 …(由地址参数固定)」。
- 累计应收、累计已收的口径不同:只统计到所选月份月底。已收只计与学员币种相同的收款,币种不一致的收款进入异常并不计入差额。

## 已知限制
- 无日历导入;时区按浏览器本地;不处理跨日课。
- 不发邮件、不做支付、不支持多教师。
- 批量粘贴不写开始时间的课无法参与重叠检测。
- 重叠检测包含所有状态的课(含已取消),改期后需手动删除旧记录。
- 学员姓名是唯一标识,不支持改名(需删除重建):编辑学员时姓名为只读并在旁说明原因。
- 浏览器清除站点数据会丢失记录,请定期「备份 JSON」。
