课时账单核对台

给一对一语言教师对账用:先点「载入合成示例」看完整流程,或到「学员」页建档,再录课记录和收款,最后在「对账单」页选学员和月份。数据只存在这台电脑的浏览器里。

确认清空所有学员、课记录和收款?现有 会全部删除,此操作不能撤销,建议先点「导出 JSON 备份」。

合成示例:当前数据含虚构的学员、金额和课记录。导出的对账单、CSV、JSON 备份都会标注「合成示例」;清空或导入真实备份后此标记消失。

未保存:浏览器拒绝写入本地存储,刚才的改动只在当前页面里,关闭页面就会丢失。请立即导出 JSON 备份。

还没有数据

第一步:点「载入合成示例」看一遍完整流程;已有备份就点「导入 JSON 备份」。也可以按顺序操作:

  1. 到「学员」建档:单价、币种、课包、取消规则。
  2. 到「课记录」录入课,或批量粘贴多行。
  3. 到「收款」记每一笔收款。
  4. 回到这里选学员和月份,生成对账单。
