# SPEC · 49 定投耐力模拟器

灵感:李笑来公开文章中的相关概念(本工具是作者的理解,不代表其本人观点)。目标用户:想在真投钱前看清「自己扛不扛得住回撤」的人;付款人:本人。**页面必须显著标注:合成价格序列、数学演示、不是投资建议;李笑来关联项目存在争议(见 README)。**

## 核心任务(必须跑通)

1. 价格序列生成:用户设年数、年化漂移、年化波动、随机种子(确定性伪随机,可复现)、可插入 1–3 次「崩盘」(某月起连续 N 月跌 X%);也可粘贴自己的月度价格 CSV(只校验格式,不联网)。
2. 定投模拟:每月固定金额(整数分)、起始月、可设「中断规则」:回撤 ≥ D% 时停止 / 回撤 ≥ D% 时卖出 / 从不停止(只买不卖);输出份额、成本、市值、最大回撤、最长水下月数、最终倍数。
3. 情景对照:同一价格序列下「从不停止」「跌 30% 停投」「跌 30% 清仓」三条资金曲线(SVG)并排,显示终值差与「清仓后再也没回来」的月数。
4. 耐力测验(可交互):逐月播放价格(按钮前进 / 自动播放),每到回撤超过阈值时弹页内选择「继续 / 停投 / 清仓」,记录用户每次选择;结束给「你的行为曲线」vs「规则曲线」;历史测验记录保存(日期、种子、结果)。
5. 「全部押上」反证:可设一次性全投 vs 定投,在同一序列下比较最大回撤与终值。
6. 导出:序列 + 曲线 CSV、测验记录 JSON、Markdown 小结;导入校验。

## 不做

不接行情、不推荐标的、不出现任何真实资产名称;不给收益预期。

## core.js 暴露

`genPrices({years, drift, vol, seed, crashes[]})`;`dca(prices, {amount, startMonth, rule})` → `{curve, shares, cost, value, maxDrawdown, underwaterMonths, multiple}`;`lumpSum(prices, amount)`;`drawdown(curve)`;`compareRules(prices, amount)`;`replayStep(state, choice)`;`toCsv`;`toMarkdown`;`validateImport`。金额整数分;伪随机用自实现 mulberry32 之类,种子相同结果相同。

## 示例

内置 2 个种子序列(10 年,含 1 次 -45% 崩盘 / 含 2 次崩盘)+ 1 份用户 CSV 样例;标注「合成示例」。

## 测试点(≥ 12)

genPrices 同种子可复现;崩盘段单调下跌;dca 份额与成本累计;从不停止 vs 停投 vs 清仓三者在示例上终值不同;maxDrawdown 与 underwaterMonths;lumpSum 与 dca 回撤比较;replayStep 状态机(继续/停投/清仓后不可再买);CSV 价格导入格式校验(非正价格拒绝);金额整数分;CSV 公式防护;Markdown 含免责声明;写读校验同源。

## 视觉方向

白 + 深蓝 / 橙 / 红三条规则线;回撤区用浅红背景;手机端单列,播放控件固定底部(含安全区)。

## 已知限制(写进 README)

合成序列不等于市场;模拟不含手续费与税;李笑来关联项目(BOX / XIN / Mixin)有公开争议,本工具与之无关,只做数学演示。
