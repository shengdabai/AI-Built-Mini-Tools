# 定投耐力模拟器

**合成价格序列 · 数学演示 · 不是投资建议。** 本工具不接行情、不推荐标的、不出现真实资产、不给收益预期。

## 定位

在真投钱之前,先在合成价格序列上演练“跌了怎么办”:同一条价格曲线下比较三种应对(从不停止 / 跌 D% 停投 / 跌 D% 清仓),再逐月走一遍耐力测验,看自己的行为曲线与规则曲线差多少。

## 核心任务

1. 生成价格序列:年数、年化漂移、年化波动、随机种子(mulberry32,同种子逐字符一致)、1–3 次崩盘;或粘贴自己的月度价格 CSV(只校验格式,不联网)。
2. 定投模拟:每月金额(整数分)、起始月、中断规则(从不停止 / 回撤≥D% 停投 / 回撤≥D% 清仓);输出份额、成本、期末资产、最大回撤、最长水下月数、最终倍数。
3. 情景对照:三条资金曲线(内联 SVG,运行时生成,不用图表库)、回撤区浅红背景、终值差、清仓后空仓月数。
4. 耐力测验:“前进一月”或自动播放逐月揭晓价格;回撤达到提醒阈值时弹页内选择区(继续 / 停投 / 清仓);结束对比行为曲线与规则曲线,自动记入历史记录。
5. 全部押上反证:同总投入下一次性全投 vs 每月定投,比较最大回撤与终值。
6. 导出:序列与曲线 CSV、测验记录 JSON、Markdown 小结;导入价格 CSV 与记录 JSON(校验不通过整份拒绝)。

## 如何打开

双击 `index.html`(纯前端,无依赖、无联网、无登录)。数据存在本机浏览器 localStorage(键 `dcaendure.v1`);写入失败时页面顶部持续显示“未保存”并引导导出。地址加 `?today=2026-10-20` 固定记录日期。三个“载入合成示例”按钮:A(10 年含 1 次 -45% 崩盘)、B(含 2 次崩盘)、C(自备 CSV 样例);已有数据时先在页内确认才替换(测验记录保留)。

## 口径(SPEC 未规定,本实现的约定)

- 月序号从 1 起;价格序列起点为 100;年数×12 个月度价格点。
- 漂移、波动以百分数输入;月收益为对数正态,崩盘月按“累计跌 X% 平均分摊到 N 个月”的固定比例下跌(崩盘月仍消耗随机数,崩盘之前的月份不受崩盘设置影响)。
- 两种“回撤”分开:价格回撤 = 价格相对“起始月之后的价格高点”的跌幅,达到阈值(≥)即触发停投/清仓/测验提醒;结果里的“最大资产回撤”= 资产曲线(持仓市值 + 清仓后的现金)相对资产历史高点的最大跌幅,“最长水下月数”= 资产连续未回到历史高点的最长月数,“最终倍数”= 终值 ÷ 累计投入。界面与 Markdown 小结在结果旁都写明了这一区分。停投与清仓触发后不再买入;清仓按当月价格变现为现金,现金不再投入。
- 曲线 = 持仓市值 + 清仓现金,不含因停投而没有投入的钱;“最大资产回撤/最长水下”按这条曲线相对自身历史高点计算;“最大浮亏”相对累计成本。
- 清仓后“再也没回来”的月数 = 清仓后价格已回到清仓价以上、却仍空仓的月数。
- 全部押上:总投入取每月定投的累计投入,在起始月一次性买入。
- 测验:一次回撤只提醒一次,价格回到阈值以内再跌破才会再提醒;规则曲线使用当前设定的中断规则;测验提醒阈值与规则阈值分开设置。
- 本实现自加的工程限制:漂移 -50% 到 100%、波动 0–150%、种子 0–4294967295、崩盘跌幅 0.01%–99.99%、每月金额 ≤1 亿元、阈值 1–99。年数与崩盘持续月数没有业务上限,只受技术上限约束:月度价格点 ≤100000;价格须在 0.0001 到 1e12 之间(过小的价格会让份额溢出为 Infinity,CSV 导入时整份拒绝;合成序列指数增长溢出或崩盘使价格低于 0.0001 时,生成会报错并说明原因)。任何计算得出非有限数时,页面停止绘制、导出与历史写入并显示原因。
- 绘图:一条曲线超过 600 个点时只抽样绘线(保留首尾点),表格、统计、CSV 导出仍使用全部数据。
- 导入价格 CSV 会替换当前价格:已有价格序列或进行中的测验时先在页内确认,文案写明价格将替换、未完成测验将丢弃、已完成记录保留。载入示例的确认判据 = 已生成的序列 + 导入的价格 + 测验记录 + 尚未生成的自定义参数。
- 示例标识:载入示例后存档里记 `sample`(示例名),页面持续显示“合成示例”提示(刷新后仍在),序列 CSV 加“数据性质”列,Markdown 小结写明“合成示例”;修改任何设定、导入价格或清空后标记消失。测验记录 JSON 只含测验记录(不含设定与价格),按钮名已写明。
- 地址加 `?today=` 生效时页面持续显示“基准日 YYYY-MM-DD(由地址参数固定)”;“导入价格 CSV / 记录 JSON”入口在页面顶部始终可见。
- 价格 CSV 只接受 1 列(价格)或 2 列(月,价格);首行只有“每个单元格都含字母或汉字、且不是数字”时才当作表头,否则首行按数据校验;引号闭合后只允许逗号或行尾;空行忽略;月列不参与计算、不校验;任何一行出错整份拒绝。

## 已知限制

- 合成序列不等于市场;模拟不含手续费与税。
- 李笑来关联项目(BOX / XIN / Mixin)存在公开争议,本工具与之无关,只做数学演示。
- 测验的自动播放用计时器,自动化验证只覆盖开关,逐月结果由“前进一月”路径验证。
- 记录不能单条删除,只能“清空全部数据”;不同浏览器的数据不互通,靠导出导入迁移。
- 导入的价格 CSV 不保留原始文件,只保留解析后的价格数组。
