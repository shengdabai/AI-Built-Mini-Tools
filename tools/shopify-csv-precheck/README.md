# 商品 CSV 上架预检

## 定位
批量上架前,在本机把 Shopify 商品 CSV 里会导致导入失败或被跳过的行找出来,再决定怎么改。纯前端,文件不上传。

## 目标用户
用 Shopify 一类平台批量上架的中小商家、电商运营(付款人:商家或运营负责人)。

## 核心任务
粘贴或选择 CSV → 预检 → 按阻断/警告看问题并点击定位到单元格 → 应用安全修复 → 导出修复后的 CSV 或问题清单。

## 如何打开
双击 `index.html`(file:// 可用,无依赖、无联网、无登录/支付/埋点)。输入文本保存在浏览器 localStorage(键 `csvcheck.v1`);写入失败时页面顶部持续显示「未保存」横幅。「清空数据」会先在页内确认。

## 口径
- 数据行:表头之后的每一行(含空行);行号以表头为第 1 行。
- 商品数:按不同 Handle(商品在店铺里的唯一网址名)计。
- 变体数:同一商品的不同规格;按含 SKU(库存单位编号)、价格、库存或选项值的数据行计。
- 阻断数、警告数:按问题条数计,同一个单元格触发多条规则会各算一条;统计旁的「统计口径」折叠区列出同样的说明。
- 结论:「没有发现阻断问题,也没有警告」只在检查完整完成(有表头、没有解析错误)且无任何问题时显示;有解析错误时显示「检查未完成：N 处解析错误」,出错位置之后的内容可能没有被检查,问题清单 Markdown 里也有同样的标注。
- 保存范围:本机浏览器只保存输入框里的原始文本(键 `csvcheck.v1`)。安全修复的结果只在当前页面的内存里,刷新后恢复成原文;修复区会显示「修复结果尚未保存」,页头的保存提示写作「原始输入已保存」,请用「下载预览中的商品 CSV」留存修复结果。
- 替换确认:输入框有内容,或已应用安全修复时,点「载入合成示例」先页内确认(写明将替换的字符数,以及修复结果只在内存里、替换后找不回);输入框已经是示例且没有修复时不再确认。
- 合成示例标记:输入框内容等于示例时持续显示「合成示例」(刷新后仍在;改动输入或清空后消失);问题清单 Markdown 有「数据来源」行,问题清单 CSV 多一列「数据来源」,下载文件名带「合成示例」。商品 CSV 本身要保持 Shopify 的列格式,不能加列,只在文件名上标注。
- 公式前缀:导出商品 CSV 时,以 `=`、`@` 开头的单元格,以及以 `+`、`-` 开头且长度大于 1 的单元格加单引号前缀;因此 `-3` 这样的负数也会变成 `'-3`(页面导出区同样写明)。

## 功能
- 自写 RFC 4180 解析器(引号内逗号与换行、`""` 转义、BOM、CRLF);未闭合引号、单元格内裸引号定位到行号。
- 规则表在 `core.js` 的 `RULES`:阻断 12 条(含解析类 2 条)、警告 8 条,每条有 id、级别、说明。覆盖:缺 Handle/Title 列、列数不一致、Handle 为空或格式不合法、首行缺 Title、价格/库存/Published 不合法、Option 组合重复、U+FFFD;警告:SKU 重复、非 http(s) 图片、`<script`、Tags 前后空格、Title/Vendor 不一致、价格高出同款其他变体 10 倍以上、Grams 非数字、空行。
- 统计:数据行、商品数、变体数、阻断数、警告数,计数条件见「口径」。
- 安全修复:去单元格首尾空白;Handle 转小写并把空白换成连字符;Published 的 true/false 转大写;删除空行。修复前显示将改动的单元格数与删除的空行数,修复后自动重新预检。
- 导出:修复后 CSV(任何以 `=`、`@` 开头,或以 `+`、`-` 开头且长度大于 1 的单元格都加单引号前缀,包括 `-3`、`+0012` 这类数字样式的字符串;因此负库存等数值导出后会带前缀,导入平台前需自行留意)、问题清单 CSV、问题清单 Markdown。输入框改动但未重新预检时,导出与安全修复停用。
- 修复只作用于预览与导出的数据,输入框里仍是原文。

## 已知限制
- 规则来自 Shopify 公开帮助文档的常见导入问题,不是官方校验器,不保证通过平台导入。
- 列名以英文官方模板为准(不区分大小写);不连平台 API,不校验类目与图片是否可访问,不做跨平台字段映射。
- 大文件(>5MB)未优化;预览默认只渲染前 500 行(点问题会展开到对应行)。
- Handle 规则按 `[a-z0-9-]` 判定,非英文 Handle 会被报为阻断。
- Tags 只检查整个单元格的首尾空格,不检查逗号分隔后的各项。
- Published 列存在但某行为空也报阻断(按 SPEC 只允许 TRUE/FALSE),Shopify 变体行常留空,请留意。
- 有引号解析错误的文件不能导出修复后的 CSV(会丢行),只能导出问题清单。
- 价格「高 10 倍以上」指不低于同 Handle 其他变体最高价的 10 倍。
