# 证据台账

## 定位

个人研究者的「主张—证据—反证」台账。先写一句话主张,再逐条挂证据(类型、立场、强度、来源、摘录、局限);主张状态由规则自动判定,不能手选。导出的「依据与局限」Markdown 可以直接贴进研究报告的依据段。

## 目标用户

- 定位为自用工具,不对外。

## 核心任务

1. 新建项目 → 写主张 → 给主张挂证据。
2. 看列表上的状态徽章与警示(缺一手证据 / 仅 AI 生成证据),按状态、警示过滤,搜索。
3. 「检查」页一键列出:无证据的主张、只有 AI 证据的主张、非个人观察却没 URL 的证据。
4. 「导出与数据」页下载 Markdown / JSON 备份,导入备份。

## 如何打开

- 双击 `index.html`(纯前端,无需安装、联网、登录)。
- 数据只存在当前浏览器的 localStorage(键 `evidence.v1`)。
- 「载入示例」加载 1 个**合成示例**项目(5 条主张、9 条证据,URL 全部指向 example.com)。
- 「清空全部数据」会先在页面内要求确认。
- 地址加 `?today=2026-10-20` 可固定新建项目的默认日期(演示与测试用)。

## 口径
- 单位:主张、证据、项目都按条/个计数;列表上的「支持 N · 反对 M」只数该主张下立场为支持/反对的证据(不分强弱)。
- 主张状态、缺一手证据、仅 AI 的判定规则见「功能」;状态由规则自动算,删除或加证据后立即重算。
- 检查页范围:当前项目的全部主张;「非个人观察却没有来源链接」按证据类型判定(个人观察以外的类型缺链接都算)。来源链接在所有类型里都允许留空,缺链接时只在检查页提醒。
- 未保存的主张修改:主张文字或备注改了没点「保存主张」时显示「尚未保存」;切换主张、切换项目、新建项目、载入示例、导入、清空前先给 保存并继续 / 放弃修改并继续 / 取消;加证据、改项目名不会吞掉未保存的输入;有未保存修改时导出 Markdown 与 JSON 备份禁用并提示(导出的是已保存内容,不然和屏幕不一致)。
- 删除证据前在该条旁确认,并预告主张状态是否变化(例如「已支持」→「待验证」);删除主张、项目、清空前的确认写明会一并删除的主张与证据数量。
- 载入示例:示例项目 ID 固定为 `sample-project`;如果当前已有同 ID 项目(例如上次载入后被你改过),先列出会被替换的项目名与它现有的主张/证据数,确认后才替换;没有同 ID 项目时直接新增。导入备份一律走「校验 → 预览新增/替换/保留的项目与数量 → 确认 → 写入」,校验失败整份拒绝。
- 合成示例标记:示例项目带 `sample: true`,项目栏持续显示「合成示例」,下拉里项目名后带「（合成示例）」,导出的 Markdown 有「数据来源：合成示例」一行,JSON 备份保留该标记;导入后标记不丢。
- 保存失败:出现持续可见的警告条并带「导出 JSON 备份」按钮(导出内存里的全部项目);任何一次写入成功后警告条解除并提示「已恢复保存」。
- `?today=YYYY-MM-DD` 按真实日历校验,`2026-02-30` 回退真实今天;生效时页面显示「基准日 …(由地址参数固定)」。它只决定新建项目的默认日期。

## 功能

- 证据类型:官方文档 / 一手数据 / 二手转述 / 个人观察 / AI 生成;立场:支持 / 反对 / 不相关;强度:强 / 中 / 弱。
- 状态规则(`core.js` 的 `status`):无证据 → 待验证;任一强反对 → 已反驳;否则任一非 AI 支持 → 已支持;否则 → 不确定。
- 警示(`flags`):缺一手证据 = 没有官方文档或一手数据;仅 AI = 证据非空且全部为 AI 生成。
- AI 生成证据在列表里用虚线边框标记;支持 / 反对用左侧色条区分。
- 检查(`audit`):四类问题;其中「有强反对却仍标已支持」按规则恒为 0,页面仍显示并写「本项目未发现状态冲突」(只说明这个项目当前没有冲突,不是规则被测试过的证明);空项目的每一组都写「暂无主张可检查」。
- Markdown 导出含每条主张的状态、警示、备注和证据表(类型 / 立场 / 强度 / 来源链接 / 摘录 / 局限);JSON 导入会校验版本、字段与枚举值,非法文件整份拒绝。
- 所有用户输入经转义后渲染;桌面 1440 与手机 390 宽均无横向溢出;键盘焦点可见;尊重 `prefers-reduced-motion`。

## 已知限制

- 不验证 URL 可达、不抓网页、不调 AI、不做多人协作。
- 不同浏览器 / 设备的数据不互通,靠导出导入迁移。
- 证据不能编辑,只能删除后重加(删除前有确认)。
- 「导入 JSON 备份」按项目 ID 合并:同 ID 项目被文件内容替换,其余项目保留;不会清空现有数据。
- 只接受 http:// 与 https:// 链接;其他协议的来源请把地址写进「来源标题」或「摘录」。
