# SPEC · 45 半秒脚本练习器

目标用户:想改掉一个坏习惯或第一反应的人;付款人:本人。

## 核心任务(必须跑通)

1. 脚本编辑器:一句话脚本 + 可选四维(身份 / 情境 / 理由 / 情绪);规则检查(纯规则):必须含动作动词(可配词表,默认含「做、说、看、深呼吸、停、写、走、回应、不」等)→ 缺则警告;含情绪词(「平静、开心、不焦虑」等可配)作为目标 → 警告「动作目标,不是情绪目标」;含条件从句「如果/当」→ 标为情境型,否则通用型;长度 > 40 字 → 提示「脊干要短」。
2. 练习计时:按下「开始」→ 页面大字显示脚本 → 用户朗读 → 点「结束」;本次 < 5 秒 → 不计入并提示;≥ 5 秒计一次;记录时间戳。
3. 频次计数器:今日次数、累计次数、连续天数;热力日历(运行时 div 格子,按次数深浅);每周次数柱状(div 高度)。
4. 触发记录:记一笔「刚才的情境 + 第一反应 + 执行了脚本吗」;统计「执行率」趋势(近 7 天 / 近 30 天)。
5. 多脚本并行(最多 5 条),各自计数;一键「大声版」:切换第三人称(自动把「我」替换为用户填的名字 + 「你」)。
6. 导出:练习记录 CSV、脚本卡 Markdown、JSON 备份;导入校验。

## 不做

不录音、不播放音频、不给医疗/心理建议;页面写明「来自公开书稿的方法,不是治疗」。

## core.js 暴露

`checkScript(text, config)` → `{type:'universal'|'situational', issues[]}`;`thirdPerson(text, name)`;`recordPractice(state, scriptId, seconds, now)`;`streak(records, today)`;`heatmap(records, days)`;`executionRate(triggers, days)`;`toCsv`;`toMarkdown`;`validateImport`;`?today`。

## 示例

合成 2 条脚本:「我从不刷短视频」(通用,30 天练习记录,中间断 3 天)、「当孩子大声说话时,我先看着她的眼睛再回答」(情境,12 条触发记录);标注「合成示例」。

## 测试点(≥ 12)

动作动词缺失警告;情绪目标警告;条件从句判情境型;长度提示;thirdPerson 替换;< 5 秒不计入;streak 断档归零与当天未练仍保留昨日连续;heatmap 天数与计数;executionRate 除零;多脚本独立计数;`?today` 拒进位;CSV 公式防护;validateImport 秒数非负;写读校验同源。

## 视觉方向

极简:白底、深色大字(练习态 ≥ 40px);热力格用 token 色阶;手机端练习按钮占满宽。

## 已知限制(写进 README)

计时靠用户按键,不验证真的朗读;规则检查是词表匹配。
