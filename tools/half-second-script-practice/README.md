# 半秒脚本练习器

## 定位

把一句描述动作的现在时脚本(「我从不刷短视频」「我回应,不反应」,也可以先写触发情境,如「当……时,我……」)读满 5 秒,记录次数,并记录触发时有没有执行。来自公开书稿的方法,不是治疗,不给医疗或心理建议。

## 目标用户

想改掉一个坏习惯或第一反应的人;付款人:本人。

## 核心任务

1. 脚本编辑器:一句话脚本 + 可选四维(身份 / 情境 / 理由 / 情绪),输入时实时规则检查。
2. 练习计时:开始 → 大字显示脚本 → 朗读 → 结束;< 5 秒不计入,≥ 5 秒计一次并记录时间戳。
3. 今日 / 累计 / 连续天数;热力日历(近 12 周,运行时 div 格子)与每周次数柱状(近 8 周,div 高度)。
4. 触发记录:情境 + 第一反应 + 是否执行;近 7 天、前 7 天、近 30 天执行率。
5. 最多 5 条脚本并行,各自计数;「姓名/你版本」(原“大声版”)把屏幕上的「我」换成你填的名字,并给出「你」版。它只改显示文字,不改变声音,请自己大声朗读。
6. 导出练习记录 CSV、脚本卡 Markdown、JSON 备份;导入整份校验。

## 如何打开

双击 `index.html`(无依赖、不联网、无登录)。数据存在 localStorage(键 `halfsec.v1`)。地址加 `?today=2026-10-20` 可固定今天;非法或会进位的日期(如 2026-02-30)回退真实今天。「载入示例」载入合成示例(已有数据时先在页内确认)。

## 功能说明与口径(SPEC 未规定处)

- 计时用 `performance.now()`,`core.js` 只接收秒数。恰好 5 秒计入;按原始秒数判断,保存时四舍五入到 0.1 秒。
- 连续天数:今天已练则算到今天;今天未练则保留到昨天为止的连续;昨天也没练则归零。按所选脚本单独计算。
- 热力格级别:0 次 / 1 / 2 / 3 / ≥4 次共 5 档。每周按周一起算。
- 类型判定:文字含「如果」或「当」即判情境型(「应当」之类也会命中)。动作词、情绪词是子串匹配,词表可在左侧改。
- 姓名/你版本:所有「我」换成名字(「自我/忘我/无我」除外);名字留空时换成「你」。
- 执行率按所选脚本统计;窗口为含今天的最近 N 天,「前 7 天」是再往前 7 天。
- 校验(保存前、读取后、导入时同一个 `validateState`):字段类型必须正确;脚本文字非空;文字长度不设上限(只有超过 40 字会提示「脊干要短」);练习秒数必须在 5–86400 之间;ID 全局唯一;练习与触发必须指向存在的脚本;日期与时间必须真实存在。
- 计数资格 = 秒数 ≥ 5:不足 5 秒的练习不会入库,导入含 < 5 秒练习记录的备份会整份拒绝,所以今日 / 累计 / 连续天数与图表只会数到合格记录。
- CSV / Markdown 表格里以 `=` `+` `-` `@` 开头的文字加单引号前缀(单独的 `-`、`+` 不加)。
- 热力日历每格是一个 `button`(单一 Tab 停靠点,方向键:左右 ±7 天、上下 ±1 天、Home/End 首尾),点击或聚焦时在日历下方的读数区显示日期与次数;图例标出 0、1、2、3、≥4 次。格子 32px 见方,手机上热力日历在自己的容器里横向滚动。
- 今日 / 累计 / 连续天数、热力、每周柱状只统计所选脚本里满 5 秒的练习,统计旁写明口径;没有合格练习时写明原因。
- 脚本编辑器、触发记录表单、词表、名字框有未保存内容时,CSV / Markdown / JSON 导出暂停并写明原因;存储失败提示里的“导出当前内存中的全部数据 JSON 备份”不受影响。
- 载入示例、导入、清空的确认以“已保存数据 + 未提交草稿 + 名字与词表设置”为判据,确认文案写明将替换的数量。导入入口在页面顶部始终可见。
- 示例数据在 CSV(“数据性质”列)与 Markdown 里标注“合成示例”;页面的合成示例提示条刷新后仍在。
- 地址加 `?today=` 生效时页面持续显示“基准日 YYYY-MM-DD(由地址参数固定)”。
- 存储写入失败时显示持续的「未保存」提示并引导导出;本机数据校验失败时不载入,原文另存为 `halfsec.v1.rejected`。

## 已知限制

- 计时靠用户按键,不验证真的朗读;不录音、不播放音频。
- 规则检查是词表匹配,不理解语义。
- 数据只在当前浏览器;换设备靠 JSON 备份。
- 触发记录列表只显示最近 30 条(统计仍用全部记录)。
