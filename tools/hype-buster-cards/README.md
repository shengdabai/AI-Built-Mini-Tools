# 伪概念照妖镜 · 反智商税决策卡

> 把任何热门概念放到鉴定台上,用「专业 > 工具 > 技巧」框架照一照,
> 看它到底是真功夫,还是用焦虑包装抬价的智商税。

一个**纯前端、完全离线、零 AI 调用**的批判性思维工具。双击 `index.html` 即可在浏览器运行,无需后端、无需联网、无需安装任何东西。

---

## 一、产品来源:关联的李笑来观点

本产品的判断逻辑直接来自李笑来反复强调的几个方法论:

| 观点 | 在产品中的体现 |
|------|----------------|
| **「专业 > 工具 > 技巧」权重排序** | 拆解工坊的三维滑杆;规则引擎给「底层专业」加分、给「技巧话术」扣分;方法论页的金字塔图解 |
| **「提示工程师是伪概念」** | 内置案例题 case-003,以及概念输入的默认示例 |
| **「快捷键工程师」类比** | 「类比器」把任意输入概念套进「X = 快捷键工程师?」的反讽结构,生成一句话对照 |
| **判断力训练 / 反智商税** | 整体定位:在被速成班、焦虑营销收割之前的那一秒,多一道甄别 |
| **相关 ≠ 因果**(「阳了能不能洗澡」) | 批判练习的 `causation` 类案例题 |
| **幸存者偏差的正确用法**(返航飞机弹孔) | 批判练习的 `survivorship` 类案例题 |

> 核心隐喻:**底层专业是发动机,工具是放大器,技巧是放大器上的旋钮。把旋钮当成发动机,是这个时代最常见的智商税入口。**

## 二、功能

### 1. 拆解工坊(主页)
- **概念输入**:输入任何概念(提示工程师 / 全栈增长黑客 / AI 时代必学元技能……),含快捷示例 chip。
- **三维滑杆**:为「底层专业占比 / 工具熟练度占比 / 纯技巧话术占比」打分,三者**自动归一为 100%**。
- **依附性追问**:5 道决策树式问题(去掉真专业还成立吗?去掉话术能一句话说清吗?工具换代会作废吗?……),答案直接影响最终判定分数。

### 2. 结论卡 / 鉴定书
- 三色对照**条形图**(专业=金 / 工具=钢蓝 / 技巧=暗红),纯 CSS 动画绘制。
- **红黄绿判定**:值得学(绿) / 谨慎甄别(黄) / 别交学费(红)+ 健康度评分(0–100)。
- **一句话理由** + **快捷键工程师类比**。
- 做成可「盖章」的**鉴定书版式**(双线边框、纸纹、印章)。
- **存入档案库** / **导出 PNG**(原生 Canvas 绘制,无任何外部库)。

### 3. 档案库(历史)
- 列出所有已鉴定概念,迷你条形图 + 判定徽章 + 评分。
- 点击任意一条可重新查看鉴定书;可单条删除。
- 数据存于 `localStorage`,**不上传任何服务器**。

### 4. 横向对比
- 把多个已保存概念**并排**对比堆叠条形图,一眼看出谁的技巧话术虚高。

### 5. 批判思维微练习
- 8 道真实案例题(相关≠因果 / 幸存者偏差 / 伪概念识别)。
- **翻牌交互**:选完即翻转卡片,给出即时拆解反馈。
- 含「阳了能不能洗澡」「二战返航飞机弹孔」「提示工程师」等经典题。

### 6. 方法论说明页
- 「专业 > 工具 > 技巧」金字塔图解 + 四张要点卡(快捷键类比 / 依附性测试 / 相关≠因果 / 幸存者偏差)。

## 三、如何使用

### 存档损坏恢复

鉴定档案无法解析或含非对象记录时，应用停止写入，并在页面上方显示恢复面板。

- 如果列表仅含部分无效成员，可点「只保留有效记录」。应用先请求下载完整原文，再移除 `null`、数组、字符串等无效成员，保留其他对象及其字段，并提示保留和丢弃的数量。此操作不检查对象字段是否完整，不能处理无法解析或不是列表的存档。
- 如需完整清空，先点「导出原始文本」，检查 `hb-evaluations-recovery.json` 已保存，再勾选确认、点「重置鉴定档案」并确认。重置只清空鉴定档案，不自动导入备份。

下载文件的 `raw` 字段保留原始存档字符串，供人工恢复。应用只能请求下载，不能确认文件已保存。浏览器拒绝读写、下载失败或存档已变化时，操作停止；修复存档后可点「重新读取」，无需清空。

复制工具时请一并保留相邻的 `../shared/` 恢复脚本和样式。缺少共享目录时基本功能仍可启动，但不会提供恢复面板。在产品集根目录运行 `node --test tests/runtime.test.cjs` 可检查恢复与存档保护，全部使用合成数据。浏览器下载、键盘操作与窄屏显示需另行验收。

### 运行
**直接双击 `index.html`** —— 在任意现代浏览器(Chrome / Safari / Edge / Firefox)中打开即可,`file://` 协议下完全可用。

> 案例库已**内嵌**在 `index.html` 中(`window.HB_EMBEDDED_CASES`),因此双击离线打开时无需读取 `cases.json` 也能正常练习。
> 若通过本地服务器(`http://`)访问,则会优先 `fetch('cases.json')` 加载,方便你单独维护案例库。

可选:用本地服务器运行(任选其一)
```bash
# Python
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

### 典型流程
1. 在「拆解工坊」输入一个概念,拖动三维滑杆,回答追问 → 点「生成鉴定书」。
2. 在「结论卡」查看判定,「存入档案库」或「导出 PNG」分享。
3. 多存几个后,去「横向对比」并排看。
4. 累了就去「批判练习」做几道题,练判断力。

## 四、技术栈

- **Vanilla JS**,零依赖、零构建步骤、零 npm。
- **原生 Canvas** 导出 PNG;**纯 CSS** 绘制页内条形图与动画。
- **`rules-engine.js`**:纯函数规则引擎,无持久状态,`输入 -> 输出` 确定性可测。
- **`cases.json`** + 内嵌兜底:静态案例库。
- **`localStorage`**(键 `hb:evaluations`)持久化鉴定历史。
- 无网络请求、无 AI API、无付费服务。仅引用 Google Fonts CDN(离线时自动降级为系统衬线/无衬线字体)。

### 文件结构
```
hype-buster-cards/
├── index.html        # 单页入口(内嵌案例兜底,双击即跑)
├── styles.css        # 侦探/鉴定所风格样式
├── app.js            # UI 控制层(视图、滑杆、追问、导出、历史)
├── rules-engine.js   # 纯函数规则引擎(评分/判定/类比)
├── cases.json        # 静态案例库(http 模式下加载)
├── tests/
│   └── rules.test.cjs  # 规则引擎 + 案例数据测试(node:test,无需浏览器)
└── README.md         # 本文件
```

### 测试
```bash
node --test tests/rules.test.cjs
```
覆盖:三维归一化(滑杆全部 0–100 整数组合不出现负占比、总和恒为 100)、评分与红黄绿阈值、理由与类比模板、`cases.json` 每题恰好一个正确选项、内嵌兜底案例与 `cases.json` 内容一致(两者只允许弯引号/直引号写法不同)。

## 五、设计方向

侦探 / 鉴定所风格,呼应「照妖镜」隐喻:
- 深墨蓝 `#1a2238` 主背景 + 黄铜金 `#c89b3c` 强调色。
- 衬线大标题(Noto Serif SC)营造「鉴定证书」的仪式感。
- 条形图三色对照:**专业=金 / 工具=钢蓝 / 技巧=暗红**。
- 结论卡做成可盖章的「鉴定书」版式;练习题用翻牌交互。
- 整体克制、锐利、冷峻,避开 AI 工具站常见的明亮渐变与圆胖插画。
- 桌面 + 手机响应式。
