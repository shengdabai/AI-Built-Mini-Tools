# SPEC · 13 时间出售三模式试算

灵感:李笑来公开文章中的相关概念(本工具是作者的理解,不代表其本人观点)。目标用户:自由职业者、独立教师、咨询顾问、创作者。付款人:个人。

## 核心任务(必须跑通)

1. 输入「现状」:目标月收入;每月可售工时;空置率(约不到课/没单的比例);平台抽成 %;每小时备课/交付外的隐性时间(备课、沟通,按比例);税费 %。
   → 模式一「卖一次」:反推最低时薪 = 目标收入 ÷ (可售工时 × (1−空置率)) ÷ (1−抽成) ÷ (1−税费),并给「每多 10% 空置率,时薪要涨多少」的敏感性表。
2. 模式二「卖很多次」:输入一件可复制产品(课程/模板/电子书)的制作工时、单价、预计月销量、平台费、退款率 → 月收入、回本销量、每小时等效时薪随销量变化曲线;与模式一比较:达到相同月收入需要的销量。
3. 模式三「买别人的时间」:输入外包/助理时薪、你的时薪、可外包比例 → 腾出的工时 × 你的时薪 − 外包成本 = 净增;给「外包划算的临界时薪」。
4. 情景比较:保存 3 个情景并列(表格 + 简单条形,div 宽度=运行时数据),显示每种模式的月收入、工时、等效时薪。
5. 导出:情景表 Markdown / CSV;JSON 备份。

## 不做

不给市场价、不联网、不做税务申报口径(税费只是一个百分比)。

## core.js 暴露

`modeOne(input)`;`sensitivity(input, field, steps)`;`modeTwo(input)` → `{monthlyIncome, breakEvenUnits, curve:[{units, hourly}]}`;`modeThree(input)`;`compare(scenarios)`;`toMarkdown`;`toCsv`;`validateImport`。所有金额四舍五入到分;百分比输入以 0–100 校验。

## 示例

合成情景:独立教师(目标 2 万/月,可售 80 小时,空置 20%,平台抽成 15%,隐性时间 30%)、一门录播课(制作 60 小时,单价 299,月销 30,退款 5%)、请助理(助理 60/时,自己 300/时,可外包 25%);标注「合成示例」。

## 测试点(≥ 14)

modeOne 公式与除零保护(空置率 100%);敏感性表步长与单调性;modeTwo 回本销量上取整、退款率、曲线单调;modeThree 临界时薪与净增正负;百分比校验(>100 拒绝);compare 排序;四舍五入;Markdown/CSV 内容;validateImport;公式防护;空情景不报错。

## 视觉方向

计算器 + 商业感:深灰蓝与琥珀强调;三模式用三栏卡片;手机端纵向;数字 `tabular-nums`。

## 已知限制(写进 README)

只是算术,不是市场预测;销量是用户假设;不含社保等固定成本(可用隐性比例近似)。
