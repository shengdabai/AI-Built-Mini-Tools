# 时间出售三模式试算

## 定位
把「出售时间」的三种做法放在同一张表里算:卖一次、同一份时间卖很多次、买别人的时间。填几个假设,比较月收入、工时和等效时薪。

## 目标用户
自由职业者、独立教师、咨询顾问、创作者(付款人为个人)。

## 核心任务
1. 现状:目标月收入、每月可售工时、空置率、平台抽成、隐性时间比例、税费。模式一反推最低时薪 = 目标收入 ÷ (可售工时 × (1−空置率)) ÷ (1−抽成) ÷ (1−税费),并给「空置率每增加 10 个百分点,最低时薪涨多少」的敏感性表(敏感性表:只改一个假设,看结果怎么变)。
2. 模式二:制作工时、单价、预计月销量、平台费、退款率 → 月净收入、回本销量、等效时薪随销量变化表,以及达到模式一目标收入所需销量。
3. 模式三:外包时薪、你的时薪、可外包比例 → 腾出工时、净增、外包划算的临界时薪。
4. 情景比较:最多保存 3 个情景,表格加条形(条形宽度是运行时数据)并列显示。
5. 导出:Markdown、CSV、JSON 备份(导入整份校验,不合法就拒绝并说明原因)。

## 如何打开
双击 `index.html`(file:// 即可,无需安装、无需联网)。点页头「载入示例」看完整流程。数据存 localStorage,键 `timesell.v1`;写入失败会显示持续可见的「未保存」提示。

## 口径
- 隐性时间比例:每个收费小时另加的备课、沟通时间比例,总工时 = 收费工时 × (1 + 比例)。
- 模式二回本销量 = 制作工时 × 估值时薪 ÷ 单份到手,上取整;估值时薪填 0 时用模式一最低时薪。单份到手 = 单价 × (1−平台费) × (1−退款率) × (1−税费)。
- 模式二的等效时薪 = 累计净收入 ÷ 制作工时(不含后续运营时间)。
- 模式三的工时 = 模式一总工时 − 腾出工时 + 再次出售腾出时间所需工时(腾出工时 × 可售比例);「涉及的月工时」不能超过模式一总工时,超过时该情景被拒绝、不能保存、比较表不显示。
- 模式二没有单独的税费输入,单份到手使用「现状」里的税费;结果旁显示单份到手公式、实际税费和回本公式。
- 导入 JSON 备份:校验通过后先显示当前与备份文件的情景数量,页内确认后才替换;取消则现有数据不变。
- 编辑区有未保存改动时,情景表 Markdown/CSV 导出禁用(JSON 备份包含编辑区,不受影响)。
- 载入合成示例后,页面持续显示「合成示例」标记,清空或导入真实备份后消失。
- 「载入示例」在已有数据时先显示页内替换确认,确认前不改动原数据。
- 模式三净增 = 腾出工时 × 可售比例 × 你的时薪 − 腾出工时 × 外包时薪;临界时薪 = 外包时薪 ÷ 可售比例。税费只用于模式一和模式二。
- 金额四舍五入到分;百分比按 0–100 校验。

## 已知限制
- 只是算术,不是市场预测;销量、退款率等都是用户假设。
- 未计入社保等固定支出,收入结果没有扣除这些费用;隐性时间比例只增加工时,不能当作固定成本的近似;不给市场价、不联网、不是税务申报口径。
- 情景最多 3 个,按位置保存,不能跳位。
- 模式一、二、三的工时口径不同(见上),并列比较的等效时薪只作量级参考。
- 浏览器清除站点数据会丢失记录,请定期「备份 JSON」。
