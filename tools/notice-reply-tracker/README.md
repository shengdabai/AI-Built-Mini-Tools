# 通知回执核对

## 定位

发完通知后,粘贴成员名单和群聊回执,立刻看到谁回了(按分类)、谁没回、哪些昵称无法识别,并一键生成催回名单。纯前端,双击 `index.html` 即可使用,无联网、无登录、无支付、无埋点;数据只存在本机浏览器 localStorage(键 `noticereceipt.v1`)。

## 目标用户

班主任、培训班老师、社群管理员、活动组织者。

## 核心任务

1. 名单:每行一个姓名,或「姓名, 备注」;别名写成「张三=张三妈妈, 三三」。
2. 回执:粘贴「昵称: 内容」逐行文本,或微信导出的「名字 时间 / 内容」格式(自动识别,可混合)。
3. 匹配:精确(姓名/别名)→ 归一化(全角半角、空白、大小写)→ 包含匹配;同时命中多人则进入「无法识别」;同一人多次回复取最后一次。
4. 分类:已读/收到、同意、不参加、有问题、其他;关键词可改。
5. 结果三栏:已回(按分类)、未回、无法识别;催回名单文本可按模板生成并复制。
6. 多轮:「追加一批回执」,状态累加。
7. 导出:回执表 CSV、催回文本 TXT、JSON 备份(可导入,校验不通过整份拒绝)。

## 如何打开

双击 `index.html`。点右上角「载入示例」可看到合成示例(30 人,两批回执,姓名均为虚构)。手机宽度下界面改为分段切换(输入/已回/未回/无法识别/导出)。

## 口径(SPEC 未规定、由实现选定)

- 分类判断顺序:有问题 > 不参加 > 同意 > 已读/收到,都不命中为「其他」。因此「不参加」不会被「参加」抢走,「可以参加吗?」归「有问题」。
- 纯字母数字的关键词(如 `ok`、`1`)按整词匹配,所以「10:30到」不会命中「1」;全角字符先做 NFKC 归一化。
- 名单按 CSV 解析:支持双引号包裹和 `""` 转义(`"张三","备注"`);引号未闭合、引号后有多余字符、非别名行超过两列时整份拒绝名单并写明行号,不会半截导入。别名行 `张三=别名1, 别名2` 不受两列限制。
- 昵称解析:先找第一个「不是时间冒号」的冒号(`:` 或 `:`),没有则按第一段空白切分。微信格式的消息内容持续到空行或下一个「名字 时间」行为止;微信格式正文已有内容后,紧接的带冒号的「昵称: 内容」行视为新回执(无需空行);没有分隔符、又不属于微信格式内容的行会被忽略并在界面提示。
- 催回模板:`{姓名}` 每人一行,`{名单}` 合并为「@A @B」;模板两者都没有时,把「@A @B」放在模板前面。
- 名单里同名(或别名冲突)的成员会给出提示,带该名字的回执进入「无法识别」。
- 名单表头:首行第一列是「姓名/名字/学生姓名/成员/成员姓名/name」,且没有第二列或第二列是「备注/说明/班级/年级/别名/note/notes/remark」时,识别为表头,不计入成员,并在名单下方提示。其他首行一律当成员。
- 已回列表每条显示「姓名匹配」方式(完全一致 / 归一后一致 / 昵称里包含姓名)和「分类依据」(命中的关键词,没有命中则归「其他」)。匹配方式是「昵称里包含姓名」、或分类是「不参加」时,额外显示「请人工确认」。
- 「无法识别」列表界面只显示前 200 条(显示上限,不影响统计与 CSV 导出)。
- CSV 以 `=`、`+`、`-`、`@`(及制表符、回车)开头的字段加单引号前缀;单独的 `-` 或 `+` 不加。CSV 带 BOM 方便 Excel 打开。

## 已知限制

- 姓名匹配是启发式,同名同姓无法区分。
- 分类靠关键词,「其他」要人工看;「不用担心」等含「不」的回复会被判为「不参加」,需改关键词或人工复核。
- 不接微信/钉钉 API、不自动发消息、不做签到二维码。
- 表头只识别上面口径里列出的词;其他写法的表头会被当作一个成员。
- 读取本机存档失败且另存也失败时,只能靠页面上的「下载原始存档」按钮保住原数据;关闭页面前不点就不能再取回。
- 微信格式的多行正文里,如果某一行恰好写成「某词: 内容」,会被当成新的一条回执;这类正文请用空行与下一条隔开并避免冒号。
- 「载入示例」/导入前的替换确认:名单、标题、回执、关键词、催回模板、批次名称或批次数与默认值不同,都算已有数据。
- 浏览器 localStorage 容量有限;写入失败时页面会显示「未保存」并引导导出 JSON。
- 「复制催回名单」依赖浏览器剪贴板权限,file:// 下可能需要手动 Ctrl/Cmd+C(页面会提示)。
