# 北极星提示词工厂 · AI 使用质量自检器

> 用 AI 督促 AI。把模型从「迎合者」重新配置成「对手」,并追踪你的评价判断力是否在变强。

一个**纯前端、零模型 API、双击即用**的工具,面向严肃的 LLM 用户。它把「构造对抗性提示词」和「使用质量自检」合成一个闭环:前者训练你**怎么用** AI,后者训练你**评价** AI 输出的能力——而后者,正是 AI 时代最容易退化、也最值钱的能力。

---

## 一、为什么做这个(关联的李笑来近期观点)

大模型被训练得「讨人喜欢」,默认顺着你说。于是越用越爽,却也越用越退化——你以为在借力,其实在悄悄外包自己的判断。本产品直接针对李笑来近期反复强调的几个观点:

- **「用 AI 督促 AI」 / 把模型当对手(treat me as a rival）**
  → 工厂把模型角色设定为「对手/陪练/评审/魔鬼代言人」,内置三档对抗强度,核心提示语就是「如果一路顺着我,你就失败了」。

- **「思考变多还是变少」是判断 AI 用得好不好的根本标尺**
  → 自检打卡把它做成可量化的评分项,趋势页用一条发光曲线长期追踪。

- **独立性 / 校准 / 第一性原理 三原则**(对抗 AI 迎合的具体抓手)
  → 每条原则旁都注明「它在抵抗 AI 的哪一种迎合行为」,而不只是一句口号。

- **探询 vs 委派,两种模式不能搞混**
  → 动手前的模式切换卡:把本该自己思考的「探询」当成「委派」一键交出去,正是思考变少的起点。

- **从「生产」转向「评价」**
  → 自检给出「生产 vs 评价倾向」评分,趋势页可视化你的评价判断力是否在长期变强。

> 注:本产品是基于上述公开观点的**衍生工具**,文案为独立创作的再表达,非原文摘录。

## 二、功能

### 北极星提示词工厂(主页)
- 选 **专业领域底板**:写作 / 编码 / 投资 / 研究,切换即换底层措辞。
- 勾选 **三原则**:独立性 / 校准 / 第一性原理,每条旁注明它抵抗的迎合行为。
- 填 **你最容易被 AI 顺着说的弱点**:提示词会专门叮嘱模型盯住这里。
- 选 **对抗强度**:温和提醒 / 对手陪练 / 冷酷拷问。
- **探询 vs 委派模式切换卡**:动手前提示当前该用哪种模式。
- 实时拼出约 200–300 token 的提示词,呈现在「终端/控制台」卡片里。
- **本地 token 估算**(按 CJK / ASCII / 标点近似,无任何 API)+ 字符数。
- **一键复制**(`navigator.clipboard`,自动兜底 `textarea + execCommand`)。

### 我的提示词库
- 多套 **fork** 保存:针对不同场景存多版提示词。
- 行内 **重命名** / **载入到工厂**(回填整张表单)/ **复制** / **删除**。

### 使用质量自检
每次重要 AI 协作后回答一组校准问题:
1. 你最后亲自核查过的一个具体主张是什么?
2. 这次思考变多还是变少?(1–5)
3. 模型有没有真正挑战过你?(1–5)
4. 你更像在「生产」还是「评价」?(1–5)
→ 即时算出 **生产 vs 评价倾向(0–100)** 并给出判词。

### 趋势视图
- 原生 SVG 绘制的极简发光双曲线:**思考变多/变少**(青)与 **生产 vs 评价倾向**(暖金)。
- 统计卡:累计次数、最近一次评分、平均评价倾向、相对首次的变化(▲/▼)。

### 原理说明页
三原则、探询/委派、反退化判据的科普,可作为随手回顾的理念锚点。

## 三、如何使用

1. **双击 `index.html`** 即可在浏览器打开(无需后端、无需构建、无需联网)。
2. 在「工厂」里选领域、勾原则、填弱点、选强度,右侧实时预览提示词与 token 数。
3. 点「复制到剪贴板」,粘进 ChatGPT / Claude / 任意 LLM 对话框,让它当你的对手。
4. 满意的版本点「存为 fork」,在「提示词库」里管理多版。
5. 每次重要协作后,去「自检打卡」记一次;长期在「趋势」看自己的判断力曲线。

> 所有数据(提示词 fork、自检记录)只存在你**本机浏览器的 localStorage**,不上传任何服务器。换浏览器 / 清缓存会清空。

### 存档损坏时

无法解析的存档或含非对象记录的列表会停止写入，页面上方显示恢复面板。提示词库与自检记录分别处理：

1. 点「导出原始文本」，检查下载的 `*-recovery.json` 文件已保存。
2. 如果列表仅含部分无效成员，可点「只保留有效记录」。应用先请求下载完整原文，再移除 `null`、数组、字符串等无效成员，保留其他对象及其字段，并提示保留和丢弃的数量。此操作不检查对象字段是否完整。
3. 如需完整清空，勾选已保存备份，再点对应存档的重置按钮并确认。只有这一份存档会清空。
4. 如果浏览器拒绝读写、下载失败或存档已变化，操作会停止；点「重新读取」后再处理。无法解析或不是列表的存档不能用「只保留有效记录」处理。

备份的 `raw` 字段保留原始存档字符串，包括无法解析的内容；不是可以直接导入的正常数据。应用只能请求下载，不能确认文件已保存，因此重置前需要本人检查。修复原始存档后也可点「重新读取」，无需清空。

共享恢复脚本与样式在相邻的 `../shared/`，复制工具时请一并保留该目录。缺少共享目录时基本功能仍可启动，但不会提供恢复面板。

## 四、技术说明

- **纯 Vanilla JS**,模板字符串拼装提示词,无框架、无打包。
- **本地 token 估算函数**:CJK 字符约 1 token/字,ASCII 约 4 字符/token,标点折中——只给量级感,不追求精确,**不依赖任何外部 tokenizer 包或 API**。
- **原生 SVG** 画趋势折线(含 glow 滤镜),无图表库。
- **localStorage** 持久化,`navigator.clipboard` + `execCommand` 双通道复制。
- **离线可跑**:模板底板内嵌在 `app.js`,不通过 `fetch` 读取,因此 `file://` 直接打开也完全可用(`templates.json` 仅作数据规格留存)。
- 仅引用 CDN 字体(JetBrains Mono / Noto Serif SC / Noto Sans SC);断网时自动回退系统字体,功能不受影响。

### 数据结构

```
localStorage['ppf:prompts']    // fork 列表
  = [{ id, name, domain, principles:[], weakness, intensity, mode, compiled, tokenEst, ts }]

localStorage['ppf:selfchecks'] // 自检记录
  = [{ id, date, lastVerifiedClaim, thinkMoreScore:1-5, challengedScore:1-5, prodVsEvalScore:0-100, ts }]
```

`templates.json` = `{ writing, coding, investing, research: { label, baseText, principleSnippets } }`

### 测试

```bash
node --test tests/data.test.cjs   # 数据约定,无需浏览器
node tests/ui.cjs                 # 需要 Playwright 与 chrome-headless-shell
```

在产品集根目录运行 `node --test tests/runtime.test.cjs` 可检查存档恢复、读写失败与原始数据保护；测试使用合成 DOM 和存储，不读取浏览器真实存档。浏览器下载、键盘操作与窄屏显示需另行验收。

`tests/ui.cjs` 默认使用 `~/.local/bin/chrome-headless-shell`,可用环境变量 `CHROME_HEADLESS_SHELL` 指定其他无头浏览器路径;页面以 `file://` 打开,外部字体请求一律拦掉。

## 六、设计

极客深空风 + 北极星隐喻。近黑深蓝(`#0b1020`)底,一抹星辉青(`#7fd6e8`)与暖白文字,等宽字体呈现提示词与 token 计数,衬线标题做权威感。提示词预览区是「终端/控制台」卡片质感;趋势曲线是极简单色发光线。整体冷静、专业,刻意避开消费级 AI 产品的彩色渐变和拟人吉祥物——这是一件属于内行的工具。响应式,桌面与手机均可用,深色模式优先。
