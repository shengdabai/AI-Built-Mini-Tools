## 核心任务
1. 新建线索(姓名、渠道、首次联系、时区文本、学习目标、阶段、最近联系、下一步与日期、报价与币种、备注)。
2. 在看板上用卡片的「推进到…」改阶段;流失必须选原因(价格 / 时间冲突 / 没回复 / 选了别人 / 其他)。
3. 顶部「今天要跟」列出超期线索,按逾期天数降序。
4. 看各阶段数量、漏斗转化率、渠道线索与付款、流失原因分布。
5. 导出周报 Markdown、CSV、JSON 备份,并可导入 JSON。

## 如何打开
- 双击 `index.html`(file:// 下可用,无需联网或安装)。
- 固定「今天」用于演示或测试:`index.html?today=2026-10-20`。
- 第一次打开是空状态,点「载入示例」可载入 14 条合成线索。

## 口径
- 单位:线索数(条);天数为按本地日期差的整数天。
- 「各阶段当前数量」:每条线索只算在现在所处的阶段,各阶段之和 = 线索总数。
- 转化率 = 曾到达后一阶段的线索数 ÷ 曾到达前一阶段的线索数(咨询→试课取「已试课」÷「咨询中」,试课→付款取「已付款」÷「已试课」,整体取「已付款」÷「咨询中」),依据 `stageHistory`;直接跳级的线索也计入被跳过的中间阶段;分母为 0 时显示「暂无数据」。
- 按渠道:线索 = 该渠道全部线索(含流失);付款 = 曾到达「已付款」的线索,按历史阶段统计,已开课的线索也算,所以可能比「已付款」列里的卡片多。
- 流失原因分布:只统计当前阶段为流失的线索。
- 待跟进 = 距最近联系超过 N 天(页头「超过几天未联系时提醒」,默认 3)或下一步计划日期已过;已付款、已开课、流失不算。周报的待跟进沿用同一个 N,并在周报末尾「口径」段写明。
- 周报预览随数据与阈值自动重新生成,不会出现旧预览配新数据;表单里有未保存编辑时,周报下载与复制、线索表 CSV、JSON 备份都禁用并提示先保存或取消。
- JSON 备份包含线索、超期阈值 N 和示例标记;导入校验 N 为 1–60 的整数,旧备份没有 N 时保留当前阈值。
- 合成示例标记:载入示例后写入存档(刷新后仍在),页面持续显示;周报 Markdown 有「数据来源」行,线索表 CSV 多一列「数据来源」,JSON 备份带 `sample: true`,文件名带「合成示例」;清空或导入不带标记的备份后消失。
- 替换确认:载入示例前,只要有线索、阈值偏离默认值 3 或表单里有未保存的输入就先页内确认(写明现有与待载入的数量);导入 JSON 备份一律走「校验 → 预览数量与阈值 → 确认 → 写入」,校验失败整份拒绝并持续显示原因。载入示例会把阈值重置为 3 天。
- 删除线索前页内确认,写明该线索的阶段记录会一并删除、统计和周报计数会随之减少。
- `?today=YYYY-MM-DD` 按真实日历校验,`2026-02-30` 回退真实今天;生效时页头显示「基准日由地址参数固定」。

## 功能与规则
- 阶段:咨询中 → 已约试课 → 已试课 → 已报价 → 已付款 → 已开课;流失可从任何阶段进入。推进下拉只列更靠后的阶段;流失线索可「恢复到…」(记为显式回退)。不做拖拽。
- 超期 = 距最近联系 > N 天(默认 3,页头可改)或下一步计划日期已过;已付款、已开课、流失不算。「今天已联系」会把最近联系设为今天,并清除已过期的下一步日期。
- 转化率分母是「曾到达该阶段的线索数」,依据每条线索的 `stageHistory`;跳级(如直接到已付款)视为经过中间阶段。咨询→试课按「已试课」计,试课→付款按「已付款」计。
- 周报的「本周」= 今天往前 7 天,含两端(第 7 天算,第 8 天不算)。
- CSV 对逗号、引号、换行转义,并给以 `= + - @` 开头的文本加前缀以防表格公式注入。
- 用户输入一律用 textContent 渲染;清空和删除使用页内确认区,不用 `alert/confirm/prompt`。

## 已知限制
- 无提醒推送;无多人协作。
- 时区只是文本记录,不换算。
- 不接日历、不发消息、不做拖拽、不做多教师。
- 数据只在当前浏览器的本机存储里;换浏览器或清除站点数据会丢失,请定期「备份 JSON」。
- 「导入 JSON 备份」确认后会替换当前全部线索(同时恢复备份里的超期阈值)。
- 报价金额不做跨币种汇总。
- 剪贴板复制在部分 file:// 环境可能被浏览器拒绝,此时可手动选中周报预览或用「下载周报 Markdown」。
