# SPEC · 41 AI 订阅成本账本

目标用户:重度 AI 用户、小团队负责人。付款人:本人。

## 核心任务(必须跑通)

1. 订阅录入:服务名、档位、币种、金额、周期(月/年/一次性/按量)、开始日、续费日、状态(在用/暂停/已退)、用途标签(编码/写作/调研/图像/其他)、谁在用(自己/团队 N 人)。按量项目可录每月实际账单。
2. 月成本:把年付折算到月;一次性按用户设的摊销月数;按量取当月实际;多币种各自汇总,不换汇(用户可填一个「折算汇率」只用于总览,标「估算」)。
3. 产出挂接:每月记录「硅基产出」:按用途标签填「本月用 AI 完成的工作量估计(小时当量)」+ 一句证据(交付物);算「每小时当量成本」= 月成本 ÷ 小时当量;与用户的「机会成本时薪」比较,给「低于/高于」提示;不填产出则只显示成本,不显示比值。
4. 提醒:续费日 ≤ 7 天;连续 2 个月产出小时当量为 0 的「在用」订阅 → 「考虑暂停」;同一用途 ≥ 3 个订阅 → 「重叠」提示。
5. 趋势:近 12 个月成本柱(div 高度=运行时数据)与产出小时当量折线(纯 DOM 点 + 线段用 div,或 SVG 内联由运行时生成);本月 vs 上月。
6. 导出:订阅表 CSV;月报 Markdown;JSON 备份。

## 数据兼容与恢复（2026-10-29）

v2 保存 `snapshots`，兼容 v1 JSON 和浏览器键。有效 v2 优先；损坏 v2 可回退有效 v1，旧键保留。覆盖损坏存档前必须成功归档并回读原文；失败时只保存有效内存，不覆盖旧原文。原始恢复包和有效内存备份分开导出。导入先整份校验，确认后替换。

## 不做

不接账单 API、不换汇、不评价模型优劣。

## core.js 暴露

`monthlyCost(sub, month)`;`totals(subs, month, fxRate?)`;`costPerHour(total, hours)`;`alerts(subs, outputs, today)`;`trend(subs, outputs, months)`;`compare(thisMonth, lastMonth)`;`toCsv`;`toMarkdown`;`validateImport`;`?today`。金额整数分。

## 示例

合成 9 个订阅(USD/CNY 混合、年付 2、按量 1、一次性 1、暂停 1、重叠用途 3)、6 个月产出记录(其中 1 个订阅两月为 0);标注「合成示例,金额虚构」。

## 测试点(≥ 12)

年付折月;一次性摊销;按量取实际;暂停/已退不计;多币种分列;估算汇率标注;costPerHour 除零与未填产出;续费提醒边界(当天、7 天、8 天);两月零产出;重叠用途;trend 月序;compare;`?today`;CSV 公式防护;validateImport 周期枚举。

## 视觉方向

账本感:白 + 深绿;柱状/折线用 token 色;手机端单列。

## 已知限制(写进 README)

产出小时当量是自估;汇率估算只用于总览。
