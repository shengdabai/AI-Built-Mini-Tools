# SPEC · 18 题库答案核对

目标用户:线上课程制作人、出题教师。付款人:独立教师或培训机构。

## 核心任务(必须跑通)

1. 导入题库:CSV/TSV(列映射:题号、题干、选项 A–D(或更多列)、答案、知识点/章节、难度)或粘贴纯文本块(格式:`1. 题干` / `A. …` / `B. …` / `答案:B`,空行分题)。
2. 检查规则(每条带题号、级别):
   - 阻断:答案不在选项范围;答案为空;选项数 < 2;题干为空;题号重复;同一题选项文字重复。
   - 警告:正确答案长度明显长于/短于其他选项(> 1.6 倍或 < 0.6 倍,即「最长选项是答案」陷阱);答案字母在题库中分布失衡(某字母占比 > 40%);题干含「以下哪项不」却答案为肯定句(仅提示);题干与另一题高度相似(归一化后相同);知识点为空;选项含「以上都对/都不对」。
   - 统计:题数、各答案字母分布、各知识点题数、难度分布。
3. 修复辅助:一键「打乱选项并同步答案」(按确定性随机种子,可重复);导出打乱后的题库。
4. 导出:问题清单 CSV/Markdown;打乱后题库 CSV;可直接打印的 Markdown 试卷(题 + 选项,答案另页)。

## 不做

不判断题目对错、不出题、不处理图片。

## core.js 暴露

`parseCsvBank(parsed, mapping)`;`parseTextBank(text)`;`check(questions)` → `{issues, stats}`;`shuffle(questions, seed)`;`toExamMarkdown(questions)`;`toCsv`;`issuesToMarkdown`。

## 示例

合成 16 题 HSK 词汇选择题,刻意含:答案越界、重复题号、最长选项即答案、答案分布 B 过多、两题重复、一题选项重复;标注「合成示例」。

## 测试点(≥ 12)

文本块解析(含多行题干、缺答案);答案越界;选项数;题号重复;选项重复;长度陷阱阈值;分布失衡阈值;题干相似(归一化空白/标点);shuffle 同种子可复现且答案同步;试卷 Markdown 答案分页;公式防护;空题库。

## 视觉方向

教研工具感:浅灰底 + 墨蓝;题卡列表 + 右侧问题面板;手机端单列。

## 已知限制(写进 README)

只支持单选;相似度只做归一化全等;「陷阱」规则是启发式提示。
