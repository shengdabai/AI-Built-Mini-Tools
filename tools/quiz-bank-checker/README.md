# 题库答案核对

给选择题题库做确定性质检的纯前端小工具:导入题库,查出答案越界、重复题号、选项重复、答案字母失衡等问题,按种子打乱选项并同步答案,导出问题清单、打乱后题库和答案另页的试卷。

## 定位
选择题题库的确定性质检：阻断问题必须先修复，警告问题建议人工复核；不判断题目对错，不出题。

## 目标用户
线上课程制作人、出题教师;付款人为独立教师或培训机构。

## 核心任务
1. 导入:CSV/TSV(第一行列名,可调列映射)或粘贴纯文本块(`1. 题干` / `A. 选项` / `答案:B`,空行分题)。
2. 检查:阻断(答案越界/为空、选项不足、题干为空、题号重复、选项文字重复、选项文字为空)与警告(答案长度陷阱、答案字母占比 > 40%、「哪项不」配肯定答案、题干重复、知识点为空、「以上都对/都不对」、题号为空);统计题数、答案字母、知识点、难度分布。
3. 修复辅助:「打乱选项并同步答案」,同种子结果可复现;含「以上都对」的选项固定在末位;答案或选项有阻断问题的题保持原样。
4. 导出:问题清单 Markdown/CSV、原题库 CSV(含知识点与难度,无需先打乱)、打乱后题库 CSV、Markdown 试卷(答案在分页之后)。

## 如何打开
双击 `index.html`(file:// 可用,无依赖、无联网)。点「载入合成示例」可看完整流程。数据存在浏览器 localStorage(键 `qbcheck.v1`);写入失败会显示持续可见的「未保存」提示。

## 口径
- 导入统一为「解析 → 预览 → 确认 → 写入」：CSV/TSV（用逗号或制表符分隔列的表格文本）和纯文本块都先显示解析出的题数、其中的阻断问题数，以及将被替换的现有题数和打乱结果；点「确认导入」才替换，取消不改动题库；选择文件也只触发预览。任何一处解析错误整份拒绝。
- 载入合成示例前的确认判据 = 现有题库 + 粘贴框里尚未导入的内容 + 偏离默认值的随机种子，确认文案逐项写明替换范围。
- 导出区持续显示当前所见版本的阻断问题数和警告数，并写明「打乱选项不会修复答案越界、答案为空、题号重复等问题，需回到源文件修改后重新导入」。导出试卷、原题库 CSV、打乱后题库 CSV 时，若该版本仍有阻断问题，先在页内确认；问题清单不需要确认。
- 「导出原题库 CSV」始终导出原题库（含知识点与难度），不依赖打乱结果；存储写入失败时，它导出的是当前内存里的全部题目。
- 载入合成示例后页面持续显示「合成示例」标记（保存在本机数据里，刷新后仍在），导出文件名带「合成示例-」，Markdown 与 CSV 内容里带一行说明；清空或导入自己的题库后消失。
- 「没有发现问题」只在检查完整完成且问题数为 0 时显示；解析失败时显示错误原因，不显示「没有发现问题」。
- 单选框和复选框视觉尺寸 24 像素，配套标签点击区高度 32 像素。

## 已知限制
- 只支持单选；答案必须是单个字母。
- 题干相似度只做归一化（忽略空白、标点、全半角、大小写）后全等。
- 「最长选项是答案」「否定题干」等规则是启发式提示，不判断题目对错；答案字母占比按有效答案计算，无最少题数限制（题很少时占比天然偏高，请结合题量判断）。
- 不出题、不处理图片、不支持在页面内逐题编辑（改完源文件重新导入）。
- 纯文本块里选项必须按 A、B、C 顺序且每项独占一行。
- 导入与「载入合成示例」都是替换而非追加当前题库，都先页内确认。CSV 引号未闭合会整份拒绝。
