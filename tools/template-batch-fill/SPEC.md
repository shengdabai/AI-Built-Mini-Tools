# SPEC · 24 模板批量填充

目标用户:教师(通知/评语)、小团队运营(邮件/合同抬头)、活动组织者(证书/名牌)。付款人:本人或工作室主理人。

## 核心任务(必须跑通)

1. 模板编辑:纯文本模板,占位符 `{{字段}}`;支持默认值 `{{字段|默认}}` 与简单条件块 `{{#if 字段}}…{{/if}}`(只判断非空)。
2. 数据:粘贴 CSV/TSV,首行为字段名;自动识别分隔符;显示模板用到但数据缺的字段、数据有但模板没用的字段。
3. 预览:逐行渲染,左右切换;空值且无默认值的占位符高亮并计入「未填」;条件块按行求值。
4. 批量输出:
   - 合并为一个文本(每条之间用用户设定的分隔线);
   - 每条一个文件打包下载(zip 自写:store 模式,不压缩,只做本地 zip 结构;若实现成本过高,退而为「逐条下载按钮 + 合并文本」,README 写明);
   - 文件名模板 `{{姓名}}-通知.txt`。
5. 校验:占位符未闭合、条件块不配对、字段名含非法字符、数据行列数不等于表头列数 → 带行号报错。
6. 导出:渲染结果 CSV(字段 + 渲染文本列);JSON 备份(模板 + 数据)。

## 不做

不做富文本、不发邮件、不生成 PDF/图片、不做循环语法。

## core.js 暴露

`parseTemplate(text)` → `{tokens, fields, errors}`;`parseData(text)` → `{headers, rows, errors}`;`render(tokens, row)` → `{text, missing}`;`renderAll(template, data)`;`fieldDiff(templateFields, headers)`;`fileName(pattern, row)`(去掉路径分隔符与控制字符);`toCsv`;`validateImport`。

## 示例

合成「家长通知」模板 + 12 行学生数据(含 2 行缺字段、1 行多列、1 个条件块用到的「补课时间」字段半数为空);标注「合成示例」。

## 测试点(≥ 12)

占位符解析(含默认值、条件块、嵌套不支持报错);未闭合报错位置;分隔符识别;列数不等报错;缺字段高亮与计数;条件块真/假;fileName 清洗(`../`、`/`、控制字符);renderAll 行数;CSV 公式防护;字段差异;空模板;空数据。

## 损坏存档恢复验收

1. `tplfill.v1` 不存在仅指读取结果为 `null`。0 字节字符串、无法解析的内容或任一必需字段类型不合法时,整份拒绝,不能部分载入。
2. 恢复提示持续可见,损坏原文可以逐字下载。
3. 每次覆盖主键前,必须确认独立归档键仍存在且读回内容逐字一致。归档键碰撞时不能覆盖旧归档;已核对归档后来被清除时必须重建。任一步失败时,旧主键不变。
4. 当前有效状态即使无法保存也要保留在页面内存中,并可导出带明确范围的恢复 JSON。页面不能把内存状态称为已保存,也不能声称恢复文件包含浏览器全部数据。
5. 首次读取主键抛错时,本次页面生命周期内禁止所有主键写入与清除。输入、导入和清空可以更新内存,但旧主键字节必须保持不变。

## 视觉方向

文档工具感:白底 + 深墨绿;左模板右预览;手机端上下堆叠。
