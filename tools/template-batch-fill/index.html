        名词解释
        • 占位符:模板里写成 {{字段}} 的位置,输出时被每一行数据里的值替换。
        • 条件块:{{#if 字段}}…{{/if}},字段不为空时才输出中间的文字。
        • CSV / TSV:逗号 / 制表符分隔的表格文本,可以直接从 Excel 或 WPS 复制粘贴。
        • ZIP:把每一条输出打包成一个压缩包(本工具只打包不压缩),每条一个文本文件。

        这些数字怎么算的

        「条」= 数据里除表头外的每一行,一条输出一个文件。「未填」= 模板里没有值也没有默认值的占位符个数,同一个字段在模板里出现几次就算几处;条件块没有输出的部分不计。文件名里的空字段另算(见「检查」)。模板、数据或文件名模板任何一处有错误时,预览和输出都会停用,没有输出清单。
