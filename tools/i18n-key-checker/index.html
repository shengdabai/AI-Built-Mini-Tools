多语言文案键核对

导入各语言的文案文件(多语言界面用的翻译文件),选一个源语言,查缺键、多键、占位符(文案里的 {name}、%s 这类待替换片段)和 HTML 标签,再生成待翻译表。第一步:点「载入示例」,或在下方粘贴一份文件。文件只在这台电脑的浏览器里处理。

口径:分母都是源语言的键数。覆盖率 = 目标语言里有非空译文的源键数 ÷ 源语言键数;未译率 = (缺键 + 值为空 + 与源相同且未被「允许相同」豁免的疑似未译)的源键数 ÷ 源语言键数。两者不是互补关系:译文非空但与源相同时,同一个键同时计入覆盖率和未译率。复数组里目标语言不需要的形式(例如日语没有 _one)缺失时,不算缺键;只要该复数组有任一非空形式,就算已覆盖。整体 = 所有目标语言合计。
