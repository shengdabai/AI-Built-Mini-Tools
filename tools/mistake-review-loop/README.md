# 错题回环

## 定位

教师带动的中文错题复习工具：老师课后把学员**真实说错的中文句子**录进来，学员每天只复习今天到期的那几条。卖点是「教师少整理、学员的真实错误被跟踪」，不是又一个通用 SRS。

## 目标用户

- 付款人 / 录入者：教英语母语者（含企业高管）中文的老师、小班运营者。
- 使用者：他们的成人英语母语学员。

## 核心任务

1. 老师：课后 1 分钟录入或粘贴错句 → 自动归类错误类型。
2. 学员：每天几分钟，先自己写出正确句 → 看逐字差异 → 四档自评，按 SM-2 安排下一次。
3. 老师：看哪类错误最多、忘得最多；导出 Anki CSV 或 JSON 备份。

## 如何打开

- 双击 `index.html` 即可（纯前端，无需安装、无需联网、无登录）。
- 数据只存在当前浏览器的 localStorage（键 `cuotihuihuan.v1`）。
- 首次打开点「载入示例」可看到 14 条**合成示例**数据；「清空数据」会先弹确认。
- 演示或测试可在地址后加 `?today=2026-09-30` 固定「今天」。

## 功能

- **录入**：单条表单（错句 / 正确句 / 英文 / 老师备注）；批量粘贴，每行 `错句 | 正确句 | 英文`（也认全角 `｜`），实时预览每行识别结果和格式错误行。
- **规则打标签**（确定性、不调 AI）：量词、语序、了/过/着、的/地/得、缺字、多字、错别字、其他。老师可在录入时或错题本里改。
- **复习**：大字显示错句与英文 → 写答案后检查，或直接显示答案 → 显示「你的答案 / 错句 / 正确句」三行逐字差异（删除为红色划线，补上为绿色下划线；纯标点差异不算错）→ 自评：忘了、吃力、想起、很熟（键盘 1–4），按钮上预告下一次间隔。
- **统计**：总数、今日到期、已掌握（间隔 ≥ 21 天）、今天已复习；按错误类型的条形图和累计「忘了」次数。
- **导出 / 备份**：Anki CSV（正面 = 错句 + 英文，背面 = 正确句 + 错误类型，带 `#separator` / `#html` / `#columns` 头）；JSON 备份导出和导入（按 id 合并，导入时校验、清洗字段）。
- 所有用户输入经转义后渲染；桌面 1440 与手机 390 宽均无横向溢出；键盘焦点可见；尊重 `prefers-reduced-motion`。

## 已知限制

- 与笔记「第一版只交付 100 个易混淆汉字」不同，本版做的是**句子级错题**，没有内置汉字内容包，也没有前后测。
- 规则打标签是启发式的，每条只给一个标签；混合错误会落到「其他」或按优先级取其一，需要老师手动改。
- SM-2 变体：自评映射为 忘了=1、吃力=3、想起=4、很熟=5；「忘了」重置为 1 天后，当天不会再次出现；间隔按日计，不做小时级重学步骤。
- 单浏览器单用户：没有师生同步和账号，老师与学员之间靠 JSON 文件或 Anki CSV 传递；换浏览器或清缓存会丢数据，需要自行备份。
- CSV 字段首字符为 `= + - @` 时写成 HTML 实体（Anki 显示不变，电子表格不会当公式执行）。
- 存储损坏时原始数据另存为 `cuotihuihuan.v1.corrupt-<时间戳>` 键并常驻提示；浏览器存储写入失败时不提示成功。
- 导入备份：缺失或重复的卡片 ID 按内容重新编号，复习日志按 日期+卡片+自评 去重，重复导入不会放大统计。
- Node 24 的 `node --test tests/` 不会展开目录，所以放了 `tests/index.js` 作为入口去加载 `core.test.cjs`。
- `?today=` 只用于演示和测试，会固定到期计算与复习日志日期；不带参数时每次取本地日期，跨午夜自动切换。

`shots.cjs` 用 Playwright 真实操作界面，完整路径如下：

1. 从空状态开始，载入示例（14 条）。
2. 单条录入（识别为「多字」），再批量导入（含 1 行错误格式）。
3. 复习：错答、显示答案、键盘 4、答对，共三条，确认队列递减。
4. 在错题本里改标签。
5. 核对统计数值。
6. 下载 Anki CSV 与 JSON，校验内容和行数。
7. 清空后从 JSON 恢复。
8. 在手机 390 宽下走一遍复习，并检查各视图溢出。
