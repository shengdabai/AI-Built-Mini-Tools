链接参数预检

发布前检查链接中的推广来源参数(UTM),找出漏填、重复和格式问题。本工具不访问链接,只在本机浏览器里计算。第一步:点「载入示例」,或把链接粘贴到下方。

确认清空链接、设置和构建参数?此操作不能撤销。

载入示例会替换当前的链接、规则设置和构建参数。现有内容会被覆盖且不能撤销,建议先导出。

未保存:浏览器拒绝写入本地存储,刚才的内容只在当前页面里,关闭页面就会丢失。请先导出检查结果或规范化链接再离开。

检查规则设置(检查和构建共用)

这组规则同时用于「检查链接」和「批量构建」。

粘贴链接 合成示例

每行一条链接;也可以粘贴带「url」或「链接」列表头的 CSV。无协议的链接按 https:// 补全并给出警告。

还没有检查结果

先点「载入示例」看一遍完整流程,或者按顺序操作:

  1. 把要发布的链接粘贴到上面的框里,每行一条。
  2. 需要时展开「检查规则设置」,改必填项、命名规则、允许域名。
  3. 点「检查」,逐条看阻断和警告,再采用建议链接。
  4. 在下方导出检查结果或规范化后的链接列表。
