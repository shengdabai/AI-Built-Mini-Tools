# 链接参数预检

## 定位
投放前批量检查 UTM 链接:逐行给出阻断与警告,生成规范化的建议链接,并能按参数表批量构建链接。不访问链接、不缩短链接、不查点击数据。

## 目标用户
运营、投放、内容发布者。付款人假设为运营负责人(未验证)。

## 核心任务
1. 粘贴链接(每行一条,或带 `url` / `链接` 列表头的 CSV)。无协议补 `https://` 并警告。
2. 检查规则(每条带行号与级别)
   - 阻断:无法解析;协议非 http(s);UTM 必填项缺失(默认 utm_source / utm_medium / utm_campaign,可配);同一参数重复且值不同;参数名或值含未编码空格/中文(给出编码后值)。
   - 警告:UTM 参数名大小写混用;UTM 值含大写(可关);utm_campaign 不符合命名正则(默认 `^[a-z0-9_-]+$`,可配);`#` 片段出现在参数之前;重复链接(规范化后相同);域名不在允许列表(可配,子域自动允许);同一域名下 UTM 参数顺序与多数链接不一致(可关);同值重复参数。
3. 规范化:UTM 键小写、值编码与小写、去重、按参数名字母排序,非 UTM 参数的键值保持原样,`#` 片段移到最后。可单条或全部采用,采用后自动重新检查。值冲突的重复参数不会被静默丢弃,仍保留并继续阻断。
4. 批量构建:基础链接 + CSV 参数表(source, medium, campaign, content, term)。格子里用 `|` 写多个取值,每行展开为取值的笛卡尔积;基础链接里已有的同名 UTM 会被覆盖;表格单元格按原始值编码(字面 `+` 编为 `%2B`、`%` 编为 `%25`);任一行缺必填值、CSV 引号未闭合或组合数超过 5000,都整份拒绝并说明原因,不提供部分结果。
5. 导出:检查结果 CSV / Markdown、规范化链接 CSV / TXT、构建结果 CSV。

## 如何打开
双击 `index.html`(file:// 即可,无需安装、无需联网)。点页头「载入示例」看完整流程(16 条合成链接 + 3×2 参数表,域名全是 example.com)。数据存 localStorage,键 `urlcheck.v1`(含是否为合成示例);写入失败时页面顶部持续显示「未保存」提示。本产品不涉及日期计算,没有 `?today` 参数。

## 口径
- 「片段位置」按「`#` 出现在 `?` 参数之前,导致参数被浏览器当成片段」判断;`#` 在参数之后属正常,不警告。
- 值小写与大写警告只针对 `utm_*` 参数;非 UTM 参数不改动。
- 导出的 CSV/Markdown 中以 `=`、`+`、`-`、`@`(及制表符、回车)开头的字段会加单引号前缀;单独的 `-` 或 `+` 不加。CSV 带 UTF-8 BOM,便于 Excel 打开中文。
- 参数名先做百分号解码再检查必填与重复,`%75tm_source` 等同 `utm_source`;规范化也会把它还原成 `utm_source`。
- 「检查规则设置」是检查页和构建页共用的一组规则,放在两个分区之上,任何分区点「检查」「生成链接」遇到非法规则都会就地显示原因并聚焦出错输入。
- 「合成示例」标识显示在输入区、检查结果、批量构建、生成结果标题旁,并保存在本机存档里,刷新后仍在;导出文件名带「-合成示例」,Markdown 与 TXT 导出首行带说明。清空,或在输入框里自己修改链接 / 基础链接 / 参数表后,标识消失(视为已换成真实数据)。
- 「清空链接、规则和构建参数」同时删除本机存档;存档删除失败时页面持续显示原因,不会说已清空。
- 「载入示例」会替换当前输入、规则设置和构建参数;已有内容时先出现页内确认。
- 导出和采用建议前,若输入或规则在检查后被改动,导出按钮禁用并提示重新检查。
- 本机存储中的设置若字段类型、枚举不合法,整份忽略并提示,不会静默修正。

## 文件
`core.js` 纯逻辑,`app.js` 界面,`sample-data.js` 合成示例,`styles.css` 样式(顶部 `:root` 为设计 token,断点登记在 TOKENS 注释),`tests/core.test.cjs` 单元测试,`shots.cjs` 截图与端到端脚本,`showcase.html/png` 展示图。

## 已知限制
- 规则按常见约定,不替代各平台(广告平台、统计工具)的实际要求;不做短链,不访问链接,发现不了失效链接。
- 主机名只做基本合法性校验,不检查 TLD 是否真实存在。
- 参数顺序规则以同域名多数顺序为准,链接少于 2 条或 UTM 参数少于 2 个的不比较。
- 规范化会对所有参数重新排序(包括已通过检查的链接),因此「通过」的链接也可能出现仅调整顺序的建议。
- 结果卡片最多显示 300 条,导出包含全部。
- 浏览器清除站点数据会丢失输入,请及时导出。
