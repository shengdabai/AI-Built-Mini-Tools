# 应收账款跟进清单

恢复保护：旧存储校验失败时保留未改动的原始字符串，并提供下载；金额上限调整不会自动清空旧账。只有明确导入、载入示例或清空才解除这类保护。若主存储根本无法读取，本页面始终禁止写入与清空，避免覆盖未知旧数据。当前内存仍可导出 JSON。`node tests/recovery-ui.cjs` 4/4 合成场景通过，覆盖空字符串、超旧金额、读取失败及汇总超限。

## 定位
把"谁欠了多少、欠了多久、今天该催谁"放在一张表上:按账龄分五档汇总,按逾期天数排出跟进顺序,每条账单生成可复制的提醒草稿。

## 如何打开
双击 `index.html`(file:// 即可,无需安装、无需联网)。地址后加 `?today=2026-10-20` 可固定「今天」,格式非法时回退真实今天。点页头「载入示例」可看完整流程。

## 核心任务
1. 录入账单:单条表单、批量粘贴(`客户 | 账单号 | 到期日 | 应收 | 已收`,支持全角「｜」和制表符)、CSV 导入(自动猜列映射,可手动改)。新建时的已收和最近跟进表示迁移前起点,不会伪造事件。
2. 账龄汇总:余额 = 应收 − 已收,只统计余额 > 0;未到期 / 逾期 1–30 / 31–60 / 61–90 / 90 天以上;按币种分开汇总金额与笔数。到期日当天算未到期。
3. 跟进清单:按逾期天数降序;「今天要跟」= 逾期且(从未跟进,或距最近跟进 ≥ N 天,N 默认 7);提醒模板可改,占位符 `{客户}{账单号}{金额}{到期日}{逾期天数}`,一键复制;记录跟进;有争议的账单单独标记并排除出「今天要跟」清单。
4. 收款登记:加一笔已收,余额重算;已收合计超过应收会被拒绝。
5. 导出:账龄表 Markdown、账龄汇总/明细 CSV、跟进清单 CSV(含提醒草稿)、JSON 备份与带校验的导入。导出内容每次都由当前数据实时生成。

## 口径
- 账龄(应收款已逾期多少天的分档):余额 = 应收 − 已收,只统计余额 > 0;到期日当天算未到期;逾期天数 = 基准日 − 到期日;各币种分开汇总,不换算汇率。
- 「今天要跟」:未争议、逾期、且从未跟进或距最近跟进 ≥ N 天(N 默认 7,在「提醒设置」里改)。争议账单不进入「今天要跟」清单,由人工处理;产品不会自动发送任何提醒。
- 空结果:所有余额为 0 时写明「没有需要跟进的应收」;没有逾期账单时写明原因。
- 页面持续显示「基准日」;地址带合法 `?today=` 时写明「由地址参数固定」。
- 载入示例、导入 JSON、清空前先页内确认。载入示例的判据 = 已保存账单 + 偏离默认值的提醒模板或跟进间隔 + 录入页未提交的表单、批量粘贴、CSV 文本;确认文案写明会替换的范围。导入先校验,再显示现有与备份文件的账单、收款、跟进记录数量,确认后才写入。
- 载入示例后页面持续显示「合成示例」标记,备份 JSON 带 `sample` 标记,导出的文件名与内容(Markdown、CSV)带「合成示例」;清空或导入真实备份后消失。
- 录入页有未保存内容(正在编辑的账单、批量粘贴、CSV 预览)时,账龄与跟进清单导出暂停;JSON 备份只含已保存数据。
- 收款、跟进、争议备注各自在本区显示错误,出错控件用 aria-describedby 关联错误行并获得焦点;录入表单同理。
- 已收汇总 = 迁移前已收 + 收款记录合计。最近跟进 = 迁移前日期和跟进记录中的最晚日期。编辑账单时这两个汇总只读,新事件必须在账单详情登记。
- JSON v2 显式保存迁移前起点。导入 v1 时,收款记录合计不能大于已收汇总,跟进记录最晚日期不能晚于最近跟进汇总;否则整份拒绝且不改现有数据。

## 已知限制
- 不自动发送邮件或消息,提醒草稿需手动复制发出。
- 汇率不换算,各币种分开;不接银行;不算利息和违约金。
- 争议处理靠人工;争议账单不进「今天要跟」。
- CSV 导入是整份通过或整份拒绝;批量粘贴仍可只加入识别成功的行。
- 客户名 + 账单号是唯一标识,重复行在批量/CSV 导入时被跳过。
- 币种只接受 3 位字母代码。迁移前已收不生成收款记录;之后的收款必须逐笔登记。退款或冲销不支持负数收款,需要先在外部核对后再更正账单。
- 单个金额与单币种账龄总额上限均为 9,000,000,000,000.00。金额按整数分运算，超限、非有限值和超过两位小数会被拒绝。汇总超限会显示错误，Markdown/CSV 也拒绝导出，不生成“空账龄”文件。
- 浏览器清除站点数据会丢失记录,请定期「备份 JSON」。
- 一键复制依赖浏览器剪贴板权限,被拒时草稿会被选中,需手动 Ctrl/⌘+C。
