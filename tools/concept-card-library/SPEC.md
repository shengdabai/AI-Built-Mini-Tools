# SPEC · 29 概念卡片库

灵感:李笑来公开文章中的相关概念(本工具是作者的理解,不代表其本人观点)。目标用户:自学者、教师、写作者。付款人:本人。

## 核心任务(必须跑通)

1. 卡片字段:概念名、一句话定义(必填,≤ 60 字,超出警告)、「不是什么」(反例/易混淆,至少 1 条)、能回答的问题(至少 1 条:这个概念让我能判断什么)、关联概念(引用其他卡片名,自动双向)、来源(书/文章/笔记 ID,文本)、状态(草稿/可用/已重写)、创建与最近重写日期。
2. 质量门(李笑来式「清晰、准确、必要」三问,可自评):清晰(定义里没有未定义的新词:自动检测定义中出现的其他卡片名,若引用了「草稿」状态卡片则标「依赖未定义概念」);准确(有反例);必要(有能回答的问题)。三项全过才允许切到「可用」。
3. 关系图:关联以列表 + 简单「邻接视图」(当前卡片居中,一跳邻居列两侧,纯 DOM,不用 canvas);找「孤岛」(无关联)与「枢纽」(关联最多)。
4. 复习:按「最久未重写」排序取 5 张;每张显示定义 → 用户点「还清晰」或「要重写」;重写后记录日期与旧版本(保留最近 3 版)。
5. 搜索:名、定义、反例全文。
6. 导出:单张/全部 Markdown(可直接贴进笔记软件);CSV;JSON 备份;导入 JSON 校验。

## 不做

不做间隔重复算法、不联网查定义、不做富文本。

## core.js 暴露

`validateCard(card, allNames)`;`qualityGate(card, cards)` → `{clear, accurate, necessary, reasons}`;`linkGraph(cards)` → `{adjacency, islands, hubs}`;`reviewQueue(cards, n, today)`;`rewrite(card, newDef, today)`(版本保留 3);`search(cards, q)`;`toMarkdown`;`toCsv`;`validateImport`。

## 示例

合成 18 张卡(注意力、复利、元认知、出售时间、最少必要知识、践行、概念、刚需…),含 3 张草稿、2 张孤岛、1 张引用草稿概念、2 张超长定义;标注「合成示例,定义为示意不代表原文」。

## 测试点(≥ 12)

定义长度警告;反例/问题必填;关联双向与去重;自引用拒绝;引用不存在卡片提示;qualityGate 三项与草稿依赖;islands/hubs;reviewQueue 排序与 n 截断;rewrite 版本上限;search;CSV 公式防护;validateImport 状态枚举与重复名;`?today`。

## 视觉方向

卡片库感:白底 + 深靛蓝;卡片网格;手机端单列。
