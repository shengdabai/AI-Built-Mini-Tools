# 概念卡片库

## 定位
把每个概念写成一张卡:一句话定义、反例、能回答的问题、双向关联、来源、状态。用「清晰、准确、必要」三问把关,并按「最久未重写」复习。

## 目标用户
自学者、教师、写作者。付款人:本人。

## 核心任务
1. 建卡:概念名、一句话定义(≤ 60 字,超出警告不阻止)、不是什么(≥ 1 条)、能回答的问题(≥ 1 条)、关联概念(自动双向)、来源、状态(草稿/可用/已重写)、创建与最近重写日期。
2. 质量门:清晰(定义里提到的其他卡片名若是草稿,标「依赖未定义概念」)、准确(有反例)、必要(有问题)。三项全过才能设为「可用」。
3. 关系图:关联列表 + 邻接视图(当前卡居中,一跳邻居分列两侧,纯 DOM),找孤岛与枢纽。
4. 复习:最久未重写的 5 张,「还清晰」或「要重写」;重写保留旧定义与日期,最近 3 版。
5. 搜索:名、定义、反例。
6. 导出:单张/全部 Markdown、CSV、JSON 备份;导入 JSON 带校验。

## 如何打开
双击 `index.html`(file://,无需安装、无需联网)。地址后加 `?today=2026-10-20` 固定「今天」;非法或不存在的日期(如 2026-02-30)回退真实今天。「载入示例」载入 18 张合成卡片。

## 口径(SPEC 没规定、实现时定的)
- 反例与问题对所有状态都必填(包括草稿),保存前校验。
- 「依赖未定义概念」用子串匹配定义里的其他卡片名,长名优先并遮住已匹配片段,避免「复利效应」同时命中「复利」;不设最短名长度。
- 枢纽 = 关联数最多的前 3 张(第 3 名并列的一并列出,关联数至少 1);孤岛 = 关联数 0。
- 关联不存在的卡片名只提示,不拒绝(允许先写后建);自引用与重复关联拒绝。
- 复习排序键 = 最近重写日期(没重写过用创建日期),同日按创建日期再按名字。「还清晰」只记录复习日期并让当天不再出现,不改变排序规则;重写后状态变为「已重写」(草稿被重写也会变)。
- 导入:来源文本里出现非 http(s) 的「协议://」(如 file://、javascript://)整份拒绝。导入或载入示例时若已有数据,先出现页内替换确认。
- 质量门对「可用」状态始终生效:设为可用/编辑保存时拦截;导入备份时,状态为「可用」但没通过质量门(如定义引用草稿概念)的卡片会让整份被拒,提示是先在原端把它降为草稿或补全后再导出。
- 为保证备份往返不被拒:任何操作(新建、改名、改状态、重写)让某张「可用」卡不再通过质量门时,它会自动退回草稿,并在提示里说明。
- 已有卡片的定义只要变化(无论从编辑页还是复习/重写入口),都由同一套重写逻辑处理:旧定义进历史(最近 3 版)、记录最近重写日期、状态变「已重写」;若同一次编辑里明确改了状态则保留所选状态。
- CSV 公式防护:以 = + - @ 开头的字段加单引号前缀(单独的 - 或 + 不加)。CSV 只导出,不提供 CSV 导入。
- 保存前与读取后使用同一个校验函数;没有长度上限。
- 编辑表单里有尚未保存的修改时:页头三个导出按钮停用并提示;切换分区、再点「新建卡片」、载入示例、导入、清空、取消编辑前,先在页内确认是否放弃这些修改(草稿也算用户数据)。保存失败的备份按钮导出内存里的全部卡片,不含表单里未保存的内容。
- 保存卡片失败时,错误会写在对应输入框旁(aria-describedby 关联、标红),焦点移到第一个出错控件;表单顶部保留汇总。
- 「合成示例」标识:来源以「合成示例」开头的卡片在卡片库里持续有提示条(刷新后仍在),导出的 Markdown / CSV / JSON 里带着同样的来源文字;清空或删掉这些卡后提示消失。
- 地址带有效 `?today` 时页头持续显示「基准日 YYYY-MM-DD(由地址参数固定)」。

## 文件
`core.js` 纯逻辑,`app.js` 界面,`sample-data.js` 合成示例,`styles.css`(顶部 `:root` 为 token,断点登记在 TOKENS 注释),`tests/core.test.cjs`,`shots.cjs`,`showcase.html/png`。数据存 localStorage,键 `conceptcards.v1`;存储失败显示持续「未保存」提示。

## 已知限制
- 质量门是自评,只检查结构,不验证内容正确;示例定义为示意,不代表原文。
- 不做间隔重复、不联网查定义、不做富文本。
- 卡片名是唯一标识;改名会同步其他卡的关联。
- 浏览器清除站点数据会丢失卡片,请定期「备份 JSON」。
