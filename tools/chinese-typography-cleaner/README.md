# 中文排版清洁器

## 定位
粘贴 Markdown 或纯文本,按规则统一中文排版(中英文空格、全角标点、引号、省略号、破折号等),逐行显示改动,一键复制或导出 Markdown。纯前端,文字只在本机浏览器里处理。

## 目标用户
中文写作者、公众号编辑、做讲义的教师。付款人:本人(SPEC.md 的设定)。

## 核心任务
粘贴文字 → 逐条开关规则 → 看逐行差异与按规则的改动计数 → 复制结果或导出 Markdown;可添加保护词。

## 如何打开
双击 `index.html`(file:// 即可,无依赖、无联网)。`?` 参数不需要(产品不涉及日期)。

## 功能
- 九条规则,各自开关(默认全开),每条带说明与示例:中英文/中数字空格、全角标点(中文语境)、空格与空行整理、引号统一(「」或“”)、省略号、破折号、百分号、全角字母数字转半角、汉字与链接/行内代码之间加空格。
- 保护区:围栏代码块、行内代码、链接 URL(`](...)`,含尖括号包围的带空格地址,如 `[报告](<./中文 report.md>)`;以及裸 URL,裸 URL 含中文路径,到空白或中文标点为止)、引用式链接定义及目标标签、HTML 标签(识别属性引号,属性值里的 `>` 不会截断)与注释内部不处理;用户保护词原样保留。
- 逐行差异(左原右新,删除线 + 下划线 + 底色)与按规则计数;清洁结果幂等(跑两遍相同,测试含 600 条随机用例)。
- 本机保存(localStorage `zhclean.v1`);写入失败显示持续可见的「未保存」提示;读到不合法数据时提示并忽略。
- 载入示例(已有内容时先页内确认)、清空数据(先确认)。

## 口径(SPEC 未规定,本实现的选择)
- 计数:每次替换、插入或删除记 1 处;引号按被替换的引号字符计;全角字母数字按连续一段计。
- 「中文语境」:半角 `, ? ! : ;` 的前一个或后一个非空白字符是汉字或中文标点即转全角;`.` 仅在前一个字符是汉字或全角收尾标点、后面不是字母数字时转 `。`;括号成对判断(括号内、前、后有汉字即转)。
- 「汉字与链接、行内代码之间加空格」只处理它们与汉字的相邻处:链接地址和行内代码的内容不处理;链接的显示文字(方括号里)仍按各条排版规则处理,例如 `[中文English](...)` 会变成 `[中文 English](...)`。
- 引用式链接:常见顶层定义(行首最多三个空格)的标签、地址、可选标题原样保留;支持下一行地址及缩进标题。`[显示文字][id]` 只清洁显示文字;`[标签][]` 和 `[标签]` 的显示文字同时是匹配用的标签,所以整段保留。标签匹配忽略大小写与连续空白;没有对应定义的方括号仍按普通文字处理。
- 保存状态:每次保存尝试都更新「清洁结果」下方同一处状态——成功写「已保存到本机浏览器」,失败写「当前改动未保存」;顶部红色提示同时持续显示。
- 清空先尝试保存空白状态,成功后才重置页面;写入失败保留当前原文、结果、保护词、规则和旧存档,显示「清空失败」。载入示例时若保存失败,仍保留「当前改动未保存」提示。
- 载入示例会把原文、保护词替换为示例并把规则设置恢复默认;只要有原文、保护词或偏离默认值的设置(规则开关、引号风格、保留强制换行),就先页内确认并写明替换范围。
- 保护词:区分大小写;词两侧不自动加空格。
- 省略号:三个及以上 `.` 都换成 `……`(不区分语境,纯英文文本请关闭此规则)。
- 破折号:仅恰好两个 `-`;表格分隔行、分隔线、`--参数` 不动。
- 引号:只处理双引号;`"` 按每行成对匹配,落单的不动;单引号与撇号不动。同时把另一种风格的双引号统一过来。
- 空白:行首缩进保留;行尾空格(含全角空格)删除。默认连 Markdown 行尾两个空格(强制换行)也会被删,规则旁有明确说明;勾选「保留 Markdown 强制换行(行尾两个空格)」后,有正文、且下一行不是空行的行尾 2 个及以上空格会规整为恰好 2 个并保留,段尾、空行前、最后一行的行尾空格仍删除。该选项默认关闭(沿用 SPEC 的「行尾空格删除」),随本机存档保存,旧存档缺这个字段按关闭处理。
- 导出 Markdown 即清洁后的文本本身,不是表格,因此不做公式前缀处理。
- 裸 URL 之后紧跟汉字(无空格、无中文标点)时,汉字会被当成 URL 的一部分;请在 URL 后留空格或用中文标点。
- 差异显示最多 300 行,超出时提示,完整结果在结果框里。

## 已知限制
- 规则按常见中文排版约定,不是国家标准。
- 复杂嵌套 Markdown 的保护区识别可能不完整:缩进代码块、跨行行内代码、前置元数据不识别;文字里的 `<x ... >` 比较式可能被当成 HTML 标签。引用式链接不覆盖列表或引用块里的定义、跨多行的标签/标题、含多层括号的地址;这些复杂形式请先改成普通行内链接或加入保护词。
- 英文句末的 `.`(如 `用Python.`)不转 `。`;`Name: 张三` 这类英文标签后接中文也会转全角冒号。
- 不做错别字、语法、翻译;无导入功能。
- 导出的 Markdown 就是清洁后的文本本身,不能在文件里再标注「合成示例」;示例身份只在页面上由「当前是合成示例」标签持续提示(刷新后仍在),导出文件请自行区分。
