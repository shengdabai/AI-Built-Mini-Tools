# SPEC · 30 中文排版清洁器

灵感:李笑来公开文章中的相关概念(本工具是作者的理解,不代表其本人观点)。目标用户:中文写作者、公众号编辑、教师做讲义。付款人:本人。

## 核心任务(必须跑通)

1. 粘贴 Markdown 或纯文本;规则逐条开关(默认全开),每条规则有说明与示例:
   - 中英文/中数字之间加一个半角空格(「中文English中文」→「中文 English 中文」);
   - 全角标点后不加空格、半角标点在中文语境替换为全角(`,` → `,`、`.` 句末 → `。`、`?` → `?`、`!` → `!`、`:` → `:`、`;` → `;`、`()` → `()`);英文语境(前后都是英文/数字)保留半角;
   - 连续空格合并为一个;行尾空格删除;连续空行最多保留一个(Markdown 中段落分隔保留);
   - 引号统一:`"..."` → `「...」`或 `“...”`(用户选);
   - 省略号 `...` → `……`;破折号 `--` → `——`;
   - 数字与单位之间不加空格(`5kg` 保留),百分号 `5 %` → `5%`;
   - 全角字母数字 → 半角(`ＡＢＣ１２３` → `ABC123`);
   - 中文与链接/行内代码之间加空格,但代码块、行内代码、链接 URL、HTML 标签内部不处理(保护区)。
2. 差异视图:逐行显示改动(左原右新,改动字符高亮);改动计数按规则统计。
3. 一键复制结果;导出 Markdown。
4. 自定义:用户可添加「保护词」(如品牌名不改大小写、不加空格)。

## 不做

不做错别字、不做语法、不做翻译。

## core.js 暴露

`protectRegions(text)` → 分段 `{type: 'text'|'code'|'inline'|'url'|'html', value}`;各规则函数 `ruleSpacing`、`rulePunct`、`ruleQuotes`、`ruleEllipsis`、`ruleDash`、`ruleFullwidthAlnum`、`ruleWhitespace`、`rulePercent`;`clean(text, options)` → `{result, changes: [{rule, count}], diff: [{line, before, after}]}`;`diffLine(a, b)`(字符级 LCS 或简化);`protectedWords` 处理。

## 示例

合成一篇 25 行 Markdown(含代码块、行内代码、链接、HTML 标签、中英混排、全角数字、半角标点、多余空行);标注「合成示例」。

## 测试点(≥ 14)

中英间距;中数字间距;数字单位不加;百分号;全角标点替换(中文语境)与英文语境保留;小数点不替换(`3.14`);省略号;破折号;引号两种模式;全角字母数字;空格/空行合并;代码块/行内代码/URL/HTML 保护;保护词;clean 幂等(跑两次结果相同);changes 计数;空输入。

## 视觉方向

编辑器感:白 + 深灰蓝;差异用底色 + 下划线(不只靠颜色);手机端上下堆叠。

## 已知限制(写进 README)

规则按常见中文排版约定;复杂嵌套 Markdown 的保护区识别可能不完整。
