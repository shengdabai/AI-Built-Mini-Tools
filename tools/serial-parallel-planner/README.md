# 串并联统筹板

## 定位

把一天的事分成「需要我在场」和「放着跑」两条泳道(甘特图里各占一行)。烧水时可以洗茶具:把需要人在场的任务和可以自行运行的任务并行安排,比较总耗时。显示串联总时长、当前顺序下的总时长和节省百分比。

## 目标用户
一天要做十几件事的自由职业者、教师、小店主;付款人是本人。

## 如何打开
双击 `index.html`(file:// 可用,无依赖、无联网、无登录)。加 `?today=2026-10-20` 可固定“今天”(只影响模板名称与导出文件名;`2026-02-30` 这类非法日期回退真实今天)。

## 核心任务
1. 录入任务:名称、耗时(正整数分钟)、类型、前置任务(多选)、最早开始(可不填)。
2. 自动排程:甘特块的宽度由运行时数据按耗时比例生成(div,未用任何图表库);新增、改前置、上下移动都即时重排。
3. 循环依赖阻断并在任务列表与前置选项里高亮环成员;前置不存在阻断。
4. 上移/下移调整顺序,违反前置时给出原因并拒绝。
5. 「再多想一步」两条规则提示。
6. 模板(保存/载入/删除)、导出甘特 SVG / 任务 CSV / JSON、导入 JSON(整份校验)。

## 口径(SPEC 未规定,本实现的选择)
- 最早开始时间 = 从开工起算的第几分钟,非负整数,不填为 0。
- 排程:放着跑任务在前置全部完成(且不早于最早开始)后立即开始;在场任务一次只做一件,在场空闲时从已就绪的在场任务中按列表顺序取第一个。因此上下移动会改变在场任务的先后。
- 节省 = 串联总和 − 统筹后总时长;百分比四舍五入。若最早开始造成等待,节省可能为负,界面显示“多 X 分钟”。
- 提示规则的“可拆”:需要我在场的任务视为可拆,放着跑的不算。“连续 3 个在场任务”指在场泳道里时间上首尾相接的 3 个任务,合计 > 90 分钟才提示。
- 即时重排:表单里改耗时、类型、最早开始或勾选前置时,甘特、汇总与提示立刻按“若保存会怎样”重绘并标注“预览中,尚未保存”;点“添加任务/保存修改”才落盘,取消修改恢复已保存状态。预览中形成环会立即高亮环成员。
- 环成员用强连通分量识别:只有真正在环上的任务才高亮,连接两个环的中间任务不算。
- 时间轴刻度按总时长取 1/2/5×10^k 步长,最多约 24 个刻度,超大耗时不会卡页面。
- 修改任务时若新前置使列表顺序不合法(但无环),自动按前置关系重排并提示;有环则整次修改不保存。
- 删除任务先在页内确认,列出把它当前置的任务;确认后才删除任务并从这些任务的前置里移除它,确认前任务与统计不变。
- “当前顺序下的总时长”不是最短时间:排程按已就绪任务和列表顺序贪心安排,不保证最短。节省百分比 = 节省 ÷ 串联总和,四舍五入;没有任务时三个数字都是 0 分钟并写明原因。
- 表单有未保存内容(新增草稿、修改中、预览中)时,导出甘特 SVG / 任务 CSV / 普通 JSON 和“保存当前排程为模板”都禁用并提示先保存或取消;存储失败提示里的“导出当前内存中的全部任务与模板 JSON 备份”仍可用,导出内存中已保存的任务与模板,不含表单草稿。
- 载入示例后任务区、模板列表、CSV(“数据性质”列)、SVG 和 JSON(`sample` 字段)持续标注“合成示例”,刷新后仍在;清空、导入或载入非示例模板后消失。
- 地址加 `?today=` 生效时页面持续显示“基准日 YYYY-MM-DD(由地址参数固定)”。
- 导入统一为“校验 → 确认 → 写入”;载入示例、模板、导入、清空的确认以“任务 + 表单草稿”为判据并写明替换数量。
- 存储与导入共用同一个 `validateState`;存入的数据绝不含环或缺失前置。本机已存数据校验失败时不载入,并另存到 `tongbingban.v1.rejected` 备份键。
- 导出 SVG 的颜色在导出时从界面 CSS token 读取,`core.js` 里的 `DEFAULT_PALETTE` 只是 Node 下未传调色板时的兜底(导出文件需自带颜色,属 token 例外)。
- CSV 防公式:以 `=`、`@`、Tab、CR 开头,或以 `+`/`-` 开头且长度大于 1 的字段加单引号前缀。

## 示例
「合成示例:上午 8 件事」(烧水、泡茶、回邮件、跑测试、看测试结果、备课、打印、打电话),为合成数据,不是真实记录。

## 已知限制
- 只有两条泳道(在场/放着跑);不处理多人协作。
- 不接日历、不做提醒、不估算真实耗时。
- 排程是“已就绪优先 + 列表顺序”的贪心,不保证总时长全局最优,最优顺序靠用户上下移动调整。
- 环检测的 Tarjan 为递归实现,极端深的依赖链(上万层)可能超出调用栈。
- 只支持 JSON 导入,不支持 CSV 导入。
- 未做鼠标拖拽。窄屏甘特里很短的任务块只能看到颜色,详情在块的悬停提示与左侧时间文字里。
