# 一人公司组织图

## 定位

把「用 AI Agent 当员工」的一人公司画成一棵组织树:用节点记录每个 AI 岗位的职责、输入和输出,按状态着色,查数据流(谁的输出交给谁),估自动化度,再生成按目录树排好的 AGENT.md 文本骨架。页面只保存设计,不创建或运行 Agent,也不运行任何其他东西。

## 目标用户

用 AI Agent 当员工的个人创业者;付款人为本人。

## 核心任务

1. 节点录入:岗位名、职责、输入(从谁来)、输出(给谁)、触发(手动 / 定时 cron 文本 / 事件)、状态(设想 / 已配置 / 在跑 / 停用)、人工干预点(审批 / 校对 / 付款 / 无)、上级、在跑起始日(可选)、每周干预次数(自填)。
2. 组织图:运行时生成(绝对定位 div + 内联 SVG 连线,无图表库);悬停显示职责与干预点;折叠 / 展开子树即时重排;改状态即时换色;手机端是纵向缩进列表。
3. 自动化度:在跑节点数、含干预点节点占比、每周干预次数合计;给出「下一个可去掉的干预点」。
4. 数据流检查:产出没人用(警告)、输入来源或输出对象不存在(阻断,并禁用骨架导出)、环路(提示,允许)。
5. Markdown 骨架:每个节点(含根节点)一段 `岗位/AGENT.md`,路径从根节点名开始,可复制、可下载 `.md`。
6. 导出 SVG / CSV / JSON 备份;导入 JSON 校验后整份接受或整份拒绝。

## 如何打开

双击 `index.html`(纯前端,无需安装、联网、登录)。数据存在浏览器 localStorage(键 `orgchart.v1`)。「载入示例」载入 12 节点的**合成示例**;已有数据时会先在页内要求确认替换。地址加 `?today=2026-10-20` 可固定「今天」(非法或不存在的日期回退真实今天)。

## 口径(SPEC 没写死,按下面实现)

- 示例为 12 节点(根 + 4 个部门 + 7 个 Agent)。
- 「在跑节点数」「含干预点占比」的分母是除根节点外的全部节点,部门节点也算。
- 「产出没人用」只检查没有下级的节点(叶子);有下级的部门节点当作文件夹,不要求输出。一个节点有接收方 = 它的「输出给」里有存在的节点,或别的节点的「输入来自」里有它。
- 「下一个可去掉的干预点」:界面称“符合复核条件的校对环节”。条件:状态在跑 + 干预点含校对 + 起始日已填且距今天 ≥ 30 天;多个候选取跑得最久的,并列取每周干预次数多的。这里只按运行天数筛选,没有质量或错误率数据,是否取消校对要先核对实际错误记录。
- 每周干预次数是每个节点自填的非负整数,上限 100000(防止异常输入),合计显示。
- 节点表单里合法的改动(岗位名、上级、状态等)在提交前就会即时重绘组织图并标「预览,尚未保存」;点保存才落盘,取消选择则恢复。
- cron 文本只当文本保存,不校验语法。
- 骨架里根节点也生成 AGENT.md,子节点路径以根节点名为前缀;同级重名的文件夹对最终路径去重,依次加 `-2`、`-3` 后缀(同级 `dup`、`dup`、`dup-2`、`dup` 依次得到 `dup`、`dup-2`、`dup-2-2`、`dup-3`);岗位名里的 `\ / : * ? " < > |` 在路径里换成 `_`。
- CSV 里以 `= + - @`、制表符、回车开头的用户字段会加单引号前缀(单独的 `-` `+` 不加);CSV 下载带 BOM 方便 Excel。Markdown 骨架不含表格。
- SVG 导出的是当前画面(折叠的子树不画)。导出 SVG 的调色板取自页面 token;`core.js` 里的 `DEFAULT_PALETTE` 与 `METRICS`(布局坐标)是导出和运行时几何用的文档化例外,不是页面样式。
- 组织图表单里有未保存内容(新建草稿、修改中、预览中)时,骨架复制与下载、SVG / CSV / JSON 导出全部禁用并写明原因;保存失败提示里的“导出当前内存中的全部节点 JSON 备份”仍可用,导出内存里已保存的节点,不含表单草稿。
- 载入示例后页面持续显示“合成示例”提示条(刷新后仍在),CSV 加“数据性质”列,SVG 与骨架 Markdown 写明“合成示例”,JSON 带 `sample: true`;清空或导入非示例备份后消失。
- 载入示例、导入、清空的确认以“已保存节点 + 表单草稿”为判据,确认文案写明数量;删除节点的确认列出引用它的节点和处数。
- 地址加 `?today=` 生效时页面持续显示“基准日 YYYY-MM-DD(由地址参数固定)”。导入入口放在页面顶部,空状态也可见。
- 导入的备份里若输入 / 输出引用了不存在的节点,会被接受,并在数据流检查里显示为「阻断」(不静默修正);在编辑表单里这些悬空引用显示为「不存在的节点:xxx」的已勾选项,取消勾选保存即可移除;删除节点时才会同步移除其他节点对它的引用并提示数量。

## 已知限制

- 只是设计图与骨架:不连接任何 Agent 运行时、不执行 cron、不读本机文件。
- 每周人工干预次数靠自填,不是测量值。
- 不同浏览器 / 设备的数据不互通,靠 JSON 导出导入迁移。
- 组织树很宽时桌面图在容器内横向滚动;手机端用列表。
- 复制按钮依赖浏览器剪贴板权限,失败时会选中文本提示手动复制(shots 未覆盖复制动作)。
