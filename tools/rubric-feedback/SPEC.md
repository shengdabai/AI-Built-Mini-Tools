# SPEC · 17 作业量规反馈

目标用户:成人技能/语言培训教师。付款人:独立教师或培训机构。

## 核心任务(必须跑通)

1. 量规编辑:维度(名称、权重、等级 1–4 各自的描述与一句话反馈模板);可保存多套量规(如「口语作业」「写作作业」);内置一套合成示例量规。
2. 批改:选量规 → 输入学员代号与作业标题 → 每维度选等级(单选)+ 可选「原文引用」(粘贴学员原句)+ 教师补充一句 → 自动计算加权总分(0–100)与等级。
3. 反馈生成(确定性拼接):称呼 + 总评(按总分区间选模板)+ 各维度:等级描述 + 该等级反馈模板 + 引用原句(如有)+ 教师补充 + 「下次重点」(取等级最低的两个维度);支持中/英两套措辞模板(老师可编辑)。
4. 记录:每次批改保存;学员维度视图:同一学员历次各维度等级趋势(表格 + 条形)。
5. 导出:单次反馈 Markdown/纯文本复制;学员历次 CSV;JSON 备份。

## 不做

不自动判分、不调 AI、不做题库。

## core.js 暴露

`score(rubric, grades)` → `{total, level}`;`feedback(rubric, grading, lang)`;`weakest(grades, n)`;`trend(records, student)`;`validateRubric(json)`;`validateImport(json)`;`toCsv`。权重之和不为 100 时按比例归一(README 写明)。

## 示例

合成量规「中文口语作业」4 维度(发音、流利、词汇、语法)+ 3 位学员各 2 次记录;标注「合成示例」。

## 测试点(≥ 12)

加权总分与归一;等级区间边界;weakest 并列处理;feedback 包含各段且转义引用;双语模板;trend 排序;validateRubric 拒绝等级数不为 4 或权重负数;validateImport;公式防护;空记录不报错;`?today`。

## 视觉方向

教师批改感:暖白(不是米白)+ 深青;等级用 4 档可区分色;手机端单列。

## 已知限制(写进 README)

反馈是模板拼接,措辞由教师维护;不评判内容正确性。
