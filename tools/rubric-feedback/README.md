# 作业量规反馈

## 定位

成人技能/语言培训教师的作业反馈工具:老师定义量规（按评分项目、权重和等级组成的评分表）、逐维度选等级,工具按老师维护的措辞模板拼出一份完整反馈。不自动判分、不调 AI、不做题库。

## 目标用户

独立教师或培训机构(付款人设想,尚未验证)。

## 核心任务

1. 量规编辑:维度(名称、权重)、每维度 4 个等级各自的描述与一句话反馈模板;可存多套量规。
2. 批改:选量规,填学员代号与作业标题,每维度单选等级,可贴原句、补一句话;自动算加权总分(0–100)与等级。
3. 反馈生成:称呼 + 总评 + 各维度(等级描述 + 反馈模板 + 原句 + 教师补充)+「下次重点」(等级最低的两个维度,即使已是满级也列出,与 SPEC 一致);中/英两套措辞模板,老师可改。
4. 记录:每次批改保存;学员视图给出历次各维度等级表格与条形、首末变化。
5. 导出:单次反馈复制 Markdown/纯文本或下载 .md;学员或全部记录 CSV;JSON 备份与导入。

## 如何打开

双击 `index.html`(纯前端,无需安装、联网、登录)。数据存本机浏览器 localStorage(键 `rubricfb.v1`)。「载入示例」会加入 1 套合成量规「中文口语作业」和 3 位学员各 2 次记录。地址加 `?today=2026-10-20` 可固定默认日期。

## 计分规则

总分 = Σ(权重 × 等级) × 25 ÷ Σ权重。等级 1–4 对应 25/50/75/100 分。权重之和不为 100 时按比例归一(如 1:3 等同 25:75),界面显示归一后的占比。总分保留 1 位小数。等级区间:A 优秀 ≥85,B 良好 ≥70,C 合格 ≥55,D 待提高 <55(边界值归入较高一档)。「下次重点」取等级最低的两个维度(满级也列),并列时按量规里的顺序;只有一个维度的量规只列一个。

## 口径

- 界面在预览旁持续写明：总分＝Σ（权重×等级）×25÷Σ权重；等级 1、2、3、4 分别对应 25、50、75、100 分；A：总分 ≥ 85；B：70 至 84.9；C：55 至 69.9；D：< 55。文字由 `core.js` 的 `scoringRule()` 按同一份常量生成。
- 保存批改的按钮是关联批改表单的提交按钮：点击和在学员代号、作业标题、日期输入框里按 Enter 走同一套校验；信息不全时按钮禁用，按 Enter 会在状态行写明还差什么并聚焦第一个缺项。
- 措辞模板按语言保留未保存草稿：切换中/英文不丢，页内显示「未保存」及项数；离开「措辞模板」页签时若有未保存修改，先在页内选择保存、放弃或留下。
- 导入 JSON 备份：校验通过后先预览「新增/替换多少套量规、多少条记录，措辞模板是否被替换」，确认后才写入；取消不改动现有数据。导入入口在页头始终可见。
- 载入合成示例后页面持续显示「合成示例」标记（按示例量规和记录的 id 判断，刷新后仍在），导出的备份、CSV 文件名带「含合成示例」，CSV 末尾加一行说明；清空数据后消失。
- 日期旁持续显示基准日：地址带合法 `?today=` 时写明「由地址参数固定」。
- 单选按钮视觉尺寸 24 像素，等级卡片整张可点（高度远大于 32 像素）。

## 校验与安全

- 导入备份、保存量规都会校验:每维度必须正好 4 个等级、权重非负且和大于 0、id 唯一、日期有效、总分与等级与记录一致;任何一处不合法整份拒绝并说明原因。
- 每次写入 localStorage 前先对整份数据做与导入相同的完整校验,不通过则不写入并提示;读取时用同一套校验。复制量规时名称超过 60 字会截断再加「(副本)」。保存批改前也会校验该条记录;评分数据用无原型对象保存,维度 id 为 `__proto__` 也能正常评分。
- 再次载入示例时,若会覆盖你修改过的同 id 量规或记录,先在页内确认。
- 写入 localStorage 失败时,页面顶部出现持续可见的「未保存」提示并引导下载备份,不显示成功提示。
- CSV 中以 `=` `+` `-` `@` 开头的字段加单引号前缀;Markdown 反馈对学员姓名、标题、原句、补充做转义;所有输入渲染前用 textContent。
- 反馈未填全(有维度未选、缺学员或标题)时,保存与导出按钮禁用。

## 已知限制

- 反馈是模板拼接,措辞由老师维护;不评判内容正确性,不自动判分。
- 措辞模板为全局两套(中/英),不按量规单独保存;修改模板后,回看旧记录会用新模板重新生成文字。
- 记录保存了当时量规的快照,之后改量规不会改变旧记录。
- 数据只在当前浏览器,换设备靠 JSON 备份;导入按 id 合并。
- 「复制」依赖浏览器剪贴板权限,被拒绝时会提示改用「下载反馈 Markdown 文件」。
- 不支持图片/音频作业,不做多人协作。
