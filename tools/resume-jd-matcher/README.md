# 求职材料岗位对照

## 定位

把「岗位描述」和「简历文本」并排贴进来,逐个关键词核对简历有没有写到,把含数字的句子列成需要能举证的清单,并为同一岗位保存多个简历版本做行级对比。不生成、不改写简历内容。

## 目标用户

主动求职的成年人(使用者即付款人)。阶段性高频:集中投递期反复使用。

## 核心任务

1. 左贴岗位描述,右贴简历纯文本。
2. 点「提取关键词」得到可勾选、可增删、可切换「必须/加分」的 chip,保存为该岗位的关键词集。
3. 看覆盖率(总 / 必须 / 加分)、缺失清单、每个关键词在简历第几行命中;可定义同义词组。
4. 事实核验:自动抽出含 %、年、人、万、倍、亿、+ 的句子,逐条标「有证据 / 需修改」。
5. 版本:存多个简历版本,记录各自覆盖率,看趋势条,任意两版(含当前简历框)行级 diff。
6. 导出对照报告 Markdown、JSON 备份;导入入口(「导入 JSON 备份」)始终在页面顶部,空状态里还有「从 JSON 备份恢复」。

## 如何打开

双击 `index.html`(file:// 可用,无需安装、联网、登录)。数据存在当前浏览器 localStorage(键 `jobmatch.v1`)。地址加 `?today=2026-10-20` 可固定「今天」(用于报告日期与版本时间);非法值回退真实日期。「载入示例」载入两个合成示例岗位(对外汉语教师、前端工程师),各带两版简历。

## 功能与规则

- 要求行:含 熟悉/精通/掌握/了解/经验/年以上/优先/必须/具备/加分 或 required/proficient/experience/familiar/plus/preferred 等的行。
- 切词:按 `、,;/()` 和「和/与/及/或」及 and/or 切;英文词与缩写整体保留(SQL、Next.js、C++、CI/CD 等),相邻首字母大写的英文词合并(Google Meet);去停用词和「N 年以上」。
- 类型:以逗号分句判断;含 优先/加分/plus 的分句为「加分」,其余为「必须」(含 精通/required 的一定是必须)。
- 对照:NFKC 统一全半角、大小写不敏感、去空格;英文词按去空格规则匹配(`SQL` 命中 `S Q L`,`Google Meet` 命中 `GoogleMeet`),同时保留单词边界(SQL 不命中 NoSQL)。
- 存储失败不静默:写入 localStorage 失败时页面顶部持续显示「未保存」并引导下载 JSON 备份;成功提示只在真正写入后出现。
- 导入校验:字段类型、枚举、ID 唯一性不合法时整份拒绝并给出原因。
- 导出的 Markdown 表格对以 `=`、`+`、`-`、`@` 开头的用户文字加单引号前缀,并转义竖线。
- 岗位描述改动后若未重新提取关键词,Markdown 导出被禁用并说明原因。
- 再次点「载入示例」时,若同 ID 示例岗位已存在(可能已被你修改),先在页内确认再覆盖;确认前保持原状。
- 所有用户输入用 textContent 渲染;清空/删除/覆盖前用页内确认区。

## 口径
- 覆盖率 = 简历里出现的关键词数 ÷ 计入对照的关键词数(只算已勾选的关键词);必须项、加分项各自单独计算;没有这一类关键词时显示「—」,不当作 0%。
- 重新提取关键词:若你调整过列表(手动添加、改过必须/加分、删除、取消勾选,以上次提取时的岗位描述为基准),先出现页内选择——「保留我的调整并补入新词」(已删除的词不会加回来)、「用新提取结果替换整个列表」(调整全部丢弃,勾选全部恢复)、「取消」。没有调整时直接提取。
- 版本对比里的「当前草稿(尚未存为版本)」指简历框里的内容:它会自动保存在浏览器里,但还没有存成一个版本。
- 地址带合法 `?today=` 时页面顶部持续显示「基准日 …(由地址参数固定)」。
- 关键词的勾选、切换类型、删除后,键盘焦点留在同一关键词的同一控件;删除后转到相邻关键词。
- innerHTML 核对:app.js 全部用 `textContent` 渲染,没有 innerHTML 插值,无转义问题。

## 已知限制

- 关键词提取是规则切词,不理解语义;会混入「流程」「设计」这类泛词,需要手动删;「重新提取」遇到手动调整时会让你选择保留或替换,选「替换」会丢弃手动添加的词和改过的类型。
- 同义词靠用户自己维护。
- 只处理纯文本,不解析 PDF / Word;不联网查公司。
- 事实句只认数字加固定单位(%、年、人、万、倍、亿、+),「5 名」「3 个月」不会被抽出;含年份的句子(如「2019年毕业于某大学」)会保留在清单里,需要自己判断是否要举证。
- 版本覆盖率按保存当时的关键词集计算,关键词变化后各版本之间不严格可比。
- 英文多词短语只合并首字母大写的相邻词。
- 浏览器清除站点数据会丢失数据,请定期导出 JSON。
