名词解释
  • CSV / TSV:逗号分隔 / 制表符分隔的表格文件,可从 Excel 或 WPS 另存或直接复制粘贴。
  • 占位符:程序会替换的记号,如 {0}、{name}、%s、%d、HTML 标签 <b>…</b>;译文里必须原样保留。
  • 术语表:你规定某个原文词必须怎么译;译文里没有出现任何允许的译法就报警告。
  • 阻断 / 警告:阻断是几乎一定要改的问题(漏译、占位符或数字对不上),警告是需要人判断的提示。
  • 长度比:译文字符数 ÷ 原文字符数。

这些数字怎么算的

段数 = 双语表的行数(或两个文本框按行对齐后的行数);原文和译文都是空的段不检查,但仍计入段数。漏译数、占位符问题数、数字不一致数按命中的问题条数计;术语不一致数按「术语命中」计,一段里有两个术语不一致就算两条。阻断合计、警告合计也按问题条数计,一段可以有多条,所以合计可以大于段数。长度比 = 译文字符数 ÷ 原文字符数(去掉首尾空白,内部空格和标点计入),默认超过 3 或低于 0.3 报警告。「没有发现问题」只在所有检查完整运行、没有输入错误时显示。
